技術分野のガイダンス 先生用ガイド

中学校 技術・家庭(技術分野) 1年の最初(内容A〜D の前) ・ 生徒に配るファイル: G_技術分野のガイダンス.html

教科書の「技術分野のガイダンス」(1〜5)に合わせた、技術分野の最初の授業で使う教材です。製品の工夫を見つけ、技術の歩みをたどり、技術の見方・考え方(4つの視点)と問題解決の流れを体験して、3年間で学ぶ4つの分野の見通しを持ちます。1つのファイルで動き、インターネットへの接続やインストールは不要です。

どの分野にも入らない教材なので、記号は G(Guidance)にしています。A〜D の教材集とは別のファイルで、色は青緑です。

1. 配り方と開き方

Classroom で配る

  1. クラスルーム配布/生徒に配る/G_技術分野のガイダンス.html を Classroom・Google ドライブなどで配ります(元のファイルは G-guidance/dist/技術分野のガイダンス.html)。
  2. 生徒は端末にダウンロードしてから開きます(ドライブの画面の中では HTML は動きません)。

生徒用サイトで開く

生徒用サイト(https://okarin-netizen.github.io/Edu-IT/)のトップで「授業で使う」をえらぶと、いちばん上に「G 技術分野のガイダンス」のカードがあります。押すと g.html が開きます。

画面の上のバー

左に「G 技術分野のガイダンス」、右に「ふりがな」「文字 中」「使い方」が出ます(4分野のアプリと同じ形です)。教材は1つだけなので、メニューの画面と「◀ メニュー」はありません。下の帯のタブで「はじめに」〜「記録」を切りかえます。ふりがなは、はじめは出しません。

自習で進めるとき(自習モード)

  • 自習モードで開くと、右はしに「自習ガイド」が出ます。ねらい・時間の目安・進め方(どのタブで何をするか・ヒント・「この場所へ」・「できた」の印)・たしかめ問題(4問)を見ながら、1人で最後まで進められます。③ の「使う人を変えて、もう一度設計する」は発展にまとめてあります。
  • Classroom で配るとき: 生徒に配る/自習用/G_技術分野のガイダンス.html を配ります。
  • 生徒用サイトで使うとき: トップの入り口で「自習で使う」(jishu.html)をえらび、そこの「G 技術分野のガイダンス」を開くよう知らせます。
  • 自習ワークシート: 生徒に配る/ワークシート/G_技術分野のガイダンス_ワークシート.html(生徒用サイトでは「自習で使う」の入り口の「自習ワークシート」)。たしかめ問題の答えは 先生用/全分野_ワークシートの答え.html にあります。

振り返りを隠すとき

振り返りを Google フォームなどで集めるときは、生徒に配る/振り返りなし/G_技術分野のガイダンス.html を配ります。「振り返り」のタブが出なくなり、書き出すファイルにも振り返りは入りません。

2. 教材の一覧(基本編・発展編)

教材は1つで、全員が学ぶ内容です(基本編・発展編には分けていません)。タブと教科書の対応は次のとおりです。

タブ教科書生徒がすること
はじめにガイダンス・学習方法・安全技術とは何かを読み、「身の回りの技術」を3つ書く。学び方と、作業の安全(環境・行動・作業)を読む
① 工夫・創造ガイダンス 1アイデアの転用・逆転の発想・身の回りのヒント・自然からの発想の4つを知り、6つの製品(面ファスナー・付箋・カッターナイフ・ステイオンタブ・新幹線・回転ずし)がどの発想かを答える。手もとの製品の工夫を書く
② 歩みと未来ガイダンス 2明かり・情報通信・農業・住まいの技術を4つずつ古い順にならべる。未来の技術をえらび、「技術でかなえたい夢」を書く
③ 見方・考え方ガイダンス 3社会からの要求・安全性・環境への負荷・経済性の4つの視点を知り、LED電球と自転車の8つの文を仕分ける。使う人(通学の中学生・坂の町のお年寄り・レースの選手・シェアサイクル)をえらんで自転車の部品を組み合わせ、4つの視点の棒グラフでトレードオフと最適化を体験する。(発展)使う人を変えてくらべる
④ 問題解決ガイダンス 4問題(現状と目標のずれ)と課題のちがい、ニーズとシーズ、知的財産を知り、「問題?課題?」6問・問題解決の流れのならべかえ・「ニーズ?シーズ?」4問に答える。自分の身の回りの問題と課題を書く
⑤ 4つの分野ガイダンス 5A〜D の4分野と、めざす社会(循環型社会・自然共生社会・脱炭素社会・超スマート社会)、統合的な問題解決、身につける力を読む。8つの技術がどの分野かを仕分け、楽しみな分野と3年間の目標を書く
振り返り―4項目の自己評価(◎○△)と、「技術とは何か」「がんばりたいこと」を書く(はじめに書いた「身の回りの技術」が出るので、くらべて書ける)
記録―組・番号・名前を入れ、進み具合を見て、記録を書き出す

タブに ✓ が付くのは、そのタブの「やってみよう」に全部答え、「書いてみよう」を書いたときです。クイズは何度でも答え直せます(最後の答えが記録に残ります)。

3. 単元での使い方

  • 1時間で使うとき: はじめに → ① → ③ → ⑤ を中心に進め、② と ④ は「やってみよう」だけにします。書く欄は家庭学習にしてもかまいません。
  • 2時間で使うとき: 1時間目に はじめに・①・②(技術とは何か・技術の歩み)、2時間目に ③・④・⑤・振り返り(見方・考え方・問題解決・3年間の見通し)。
  • ③ の自転車の設計は、班で「使う人」を分けてえらばせ、組み合わせと理由を発表し合うと、「使う人や目的で最適な答えが変わる」ことが伝わりやすくなります。
  • ④ の「問題?課題?」と問題解決の流れは、各分野の問題解決ノート(A8・B6・C8・D11)の「① 問題の発見」とつながっています。分野の学習に入ったら、ガイダンスで書いた「自分の問題と課題」をふり返らせるとよいでしょう。
  • ⑤ の4分野のカードは、生徒用サイトの「授業で使う」「自習で使う」の入り口の A〜D の教材集の順番と同じです。

4. 記録の保存と提出

  • 書いたこと・クイズの答え・自転車の組み合わせは、その端末のブラウザの中(localStorage eduit.g.v1)に自動で保存されます。同じ端末・同じブラウザで開くと続きから使えます。
  • 提出は「記録」タブの「記録を書き出す(ファイル)」で作る JSON ファイル(G_ガイダンス_組-番号_名前_日付.json)です。先生用の「振り返り一覧」(先生用/全分野_振り返り一覧.html)に読みこむと、分野「G ガイダンス」として、書いたこと・自己評価・クイズの正解数が一覧になります。
  • 「印刷する」で、全部のタブを続けて印刷できます(PDF に保存して出すこともできます)。
  • 「はじめから(記録を消す)」で、その端末の記録を消せます。端末を共有するときは、提出のあとで消すよう伝えてください。

5. 授業で使うときの注意

  • 教科書の図や文章は使っていません。例の製品や歴史は、この教材のために短くまとめたものです。カッターナイフや回転ずしの「〜からヒントを得た」という話は、作った会社などが紹介している話をもとにしていますが、いくつかの説があるものもあります。
  • ③ の自転車の点(1〜5)は、考えるための目安で、実際の製品の値ではありません。「なぜこの点なのか」「自分ならどう付けるか」を話し合う材料にしてください。
  • ② の「古い順」は、おおまかな時代の順です(たとえば、たき火・ろうそくは今も使われています)。「いまも残っている古い技術は?」と問いかけるのもよいでしょう。
  • 名前などの個人情報は、先生の指示がないときは入れないよう伝えてください。

6. こまったとき

前に書いたことが消えた
ちがうブラウザ・シークレットウィンドウ・ちがうアドレス(ダウンロードしたファイルと生徒用サイト)で開くと、記録は別になります。前と同じ開き方で開いてください。
ファイルが書き出せない
ブラウザのダウンロードが止められていないか確かめてください。どうしても作れないときは「印刷する」で PDF にして出せます。
自習ガイドが出ない
自習用のファイル(生徒に配る/自習用/)か、?jishu=on を付けたアドレスで開いてください。
