# Edu-IT 技術分野 体験教材集

中学校技術・家庭科（技術分野）で使う体験教材です。どれもインターネット不要で、HTMLファイルをブラウザで開けば動きます。
作成: 羽生市立南中学校　技術　岡田 ／ 使ってよい条件は [`LICENSE.md`](LICENSE.md)

## フォルダの地図

```
Edu-IT/
├─ A-materials/      A 材料と加工の技術
├─ B-bio/            B 生物育成の技術
├─ C-energy/         C エネルギー変換の技術
├─ D-information/    D 情報の技術
├─ teacher-tools/    先生用の道具(4分野共通)
├─ shared/           4分野共通の枠(見た目・作成者・安全と個人情報・ライセンス・更新履歴)
├─ クラスルーム配布/  Classroom で配るファイル(生徒に配る/・先生用/)
├─ LICENSE.md        使ってよい条件
└─ README.md         この文書
```

**授業で配るだけなら [`クラスルーム配布/`](クラスルーム配布/) を見てください。** どれを配ればよいかは [`クラスルーム配布/README.md`](クラスルーム配布/README.md) にあります。

## 4つの分野の中は同じ形

```
<分野>/
├─ (アプリのフォルダ)   M1〜M6・B1〜B4・E1〜E5・各ラボ
├─ dist/       配布用の完成ファイル(作り直してできるもの)
├─ docs/       先生用の文書(手引き・使い方)
├─ build/      作る道具(ビルドのスクリプト)
├─ review/     レビュー・改善計画(ある分野だけ)
├─ eduit-info.js  その分野の版と更新履歴
└─ README.md   その分野の説明と、作り方・テストのしかた
```

| フォルダ | 分野 | 教材 | 配布用(`dist/`) | 作り直すコマンド |
|---|---|---|---|---|
| [`A-materials/`](A-materials/) | A 材料と加工 | M1 材料選択ナビ・M2 木材ラボ・M3 構造強化ラボ・M4 製図トレーナー・M5 木取り・M6 工具の安全・先生用ビューア | `材料と加工_教材アプリ.html` | `python3 A-materials/build/build-single.py` |
| [`B-bio/`](B-bio/) | B 生物育成 | B1 育成日誌・B2 育成環境コントローラ・B3 動物飼育・水産・B4 栽培暦ビルダー | `生物育成教材集.html`・`先生用ガイド.html`・zip | `node B-bio/build/rebuild.js` |
| [`C-energy/`](C-energy/) | C エネルギー変換 | E1 エネルギー変換ゲーム・E2 電気回路ラボ・E3 機構ラボ・E4 保守点検ラボ・E5 回路設計シート | `energy-apps.html`・zip | `python3 C-energy/build/build.py` |
| [`D-information/`](D-information/) | D 情報 | 体験教材集(デジタル化・仮想CPU・ネットワーク・セキュリティ・双方向・計測制御)・生成AIのしくみラボ | `情報の技術_体験教材集.html`・zip・`生成AIのしくみラボ.html` | [`D-information/README.md`](D-information/README.md) の順に |

## 4分野共通の枠 → [`shared/`](shared/)

すべてのアプリで、ヘッダー・ボタン・カード・色の「枠」と、画面の下の
「作成: 羽生市立南中学校　技術　岡田 ・ 版 ・ 安全と個人情報・ライセンス・更新履歴」をそろえています。
部品は `shared/`、各分野の版と更新履歴は各分野の `eduit-info.js` にあります。

## 教材を直したあとの流れ

1. 直した分野の「作り直すコマンド」を実行する(`dist/` が新しくなる)
2. `python3 クラスルーム配布/まとめる.py` を実行する(配布用のフォルダが新しくなる)

## 気をつけること

- フォルダの名前を変えても、生徒の記録(ブラウザに保存されたもの)や書き出したファイルはそのまま使えます。
  記録の保存名(`gijutsu.*`・`energyApps.*` など)や書き出しの id は、振り返り一覧が読むので変えないでください。
- フォルダのまま Web サーバーに置くときは、その分野のフォルダと `shared/` を同じ並びで置きます。
