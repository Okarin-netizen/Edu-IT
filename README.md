# Edu-IT 情報の技術 体験教材集

中学校技術・家庭科（技術分野）「D 情報の技術」で使う体験教材です。どれもインターネット不要で、HTMLファイルをダブルクリックすれば動きます。

## 生徒に配るファイル

- `kyozai-shu/release/情報の技術_体験教材集.html` … 6教材をメニューでまとめた1ファイル版（第1.3版）
- `kyozai-shu/release/情報の技術_体験教材集_第1.3版.zip` … 配布用一式（先生用の手引き付き）

## フォルダ

| フォルダ | 教材 |
|---|---|
| `kyozai-shu/` | 情報の技術 体験教材集（6教材のまとめ） |
| `digitization-lab/` | デジタル化ラボ |
| `virtual-cpu/` | 仮想CPUラボ |
| `network-sim/` | ネットワーク通信シミュレータ |
| `security-lab/` | 情報セキュリティ体験ラボ |
| `interactive-studio/` | 双方向コンテンツ制作スタジオ |
| `measure-control-sim/` | 計測・制御シミュレータ |
| `reviews/` | 中学生目線レビュー（2026-10-13、指摘143件と画面例） |

各教材の作り方・テストのしかたは、それぞれのフォルダの `README.md` を見てください。
