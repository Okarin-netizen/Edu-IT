# 実装計画 I5「双方向性コンテンツ制作スタジオ」

## 1. 概要
- **教科書・指導要領との対応**: 情報の技術『双方向性のあるコンテンツのプログラミングによる問題解決』。指導要領 D(2)
- **ねらい**: 問題を見いだして、入力→処理→表示のあるコンテンツ(クイズ・アンケート・診断)を、プログラムで制作・改善する。
- **形態**: PWA(Service Worker+IndexedDB)の単一Webアプリ。外部通信なし、オフライン完結。共通基盤は [README.md](README.md) を参照。
- **関連**: I6、I3

## 2. 機能要件
### MVP
1. ブロック式エディタ(順次・分岐・反復・変数・入出力)で、クイズやアンケートを作成
2. ブロック⇔テキストコード(JS風の簡易言語)の相互表示
3. 実行ビュー: 入力ボックス・ボタン・表示ラベルのUI部品を配置して動かす
4. 擬似サーバー: ブラウザ内の『サーバ役』(localStorage)で、回答の集計・ランキング・ログを保存して表示
5. デバッグ機能: ステップ実行、変数ウォッチ、エラーの日本語メッセージ
### 発展
- 他端末への配布(単一HTML書き出し→Classroom配布)
- 複数端末でのリアルタイム集計(オンライン時のみ、任意)
- メディア複合(画像・音・テキスト)の部品

## 3. 技術設計
- 言語: 自作の小さなインタプリタ(ASTを評価、サンドボックス内で実行)
- UI部品はHTML、擬似サーバーはIndexedDB
- 生成コンテンツは `sandbox iframe` で実行し、端末へ影響させない

## 4. 画面構成
- エディタ / 実行 / デバッグ / 作品管理

## 5. 受け入れ基準・テスト
- 無限ループ・巨大出力でUIがフリーズしない(実行時間制限)
- 作品をJSON/HTMLで保存・読み込みできる

## 6. リスクと対策
- セキュリティ → 生徒作品の実行はサンドボックス化。外部スクリプト・通信は不可

## 7. 工数目安
約4〜5週間(最も大きい)
