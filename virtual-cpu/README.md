# 仮想CPUラボ

作成：技術 岡田

中学校技術・家庭科（技術分野）D「情報の技術」の「コンピュータの仕組み」（入力・記憶・演算・制御・出力）向けの体験教材です。計画書 `plan-I2-virtual-cpu.md` の MVP を実装しています。

## すぐに使う

- **いちばん簡単**: `dist/virtual-cpu.html` をダブルクリックしてブラウザで開くだけ。1つのファイルなので、USBメモリや校内の共有フォルダで配れます。インターネット接続は不要です。
- **PWAとして配信する場合**: このフォルダ全体を校内のWebサーバーに置き、`index.html` を開きます。一度開くとオフラインでも動きます。

## 中身

| # | ページ | 内容 |
|---|---|---|
| ① | 図解: 5つの装置 | 「3 + 5 を計算して表示する」までのデータの流れ（実線）と制御の信号（点線）をアニメで表示。身のまわりの機器の仲間分けクイズ |
| ② | 仮想CPU | 10命令（LOAD / STORE / ADD / SUB / JUMP / JZ / JN / IN / OUT / HALT）・記憶装置32番地の小さなCPU。「1段階すすむ」で取り出し→解読→実行を1つずつ、PC・いまの命令・ACC・記憶装置の変化と、装置の間をデータが動くようすを表示。実行中の行と番地をハイライト。速さ5段階 |
| ③ | 課題（8問） | 数を表示 → たし算 → ひき算と順番 → カウントダウン → 1から10の合計 → 1からNの合計 → 最大値さがし → チャレンジ（2倍して表示）。課題1〜4 が必修、5〜7 が発展、8 がチャレンジ。途中まで書いたプログラムの「???」を埋める形で、ヒントは「考え方 → 一部の答え」の順に出て、最後に答えの例（自分で打ちこむ。開いたことは記録に残る）。答え合わせはちがう入力で何回もためす |
| ④ | 手計算 vs プログラム | 1〜20の合計を手で計算して時間をはかり、同じ計算を仮想CPUで。N を100万まで大きくして、命令の数と「1秒1命令／昔のパソコン／いまのCPU（3GHz）」での実行時間の目安をくらべる |

- 無限ループは 10,000 命令で自動停止し、その理由を表示します。HALT 忘れ・入力切れ・書きまちがい（行番号つき）も日本語で知らせます。
- 全角で書いた命令（ＬＯＡＤ　＃５ など）もそのまま読めます。
- 図解・仮想CPU・課題・手計算くらべの各ページの下に「ふりかえり」欄があり、「ふりかえり・記録」ページで名前を入れて JSON/CSV に書き出せます（ほかの教材と同じ形）。
- 進み具合・書いたプログラム・ふりかえりは、その端末のブラウザ内（localStorage）にだけ保存されます。外部のサイトには一切接続しません（Content-Security-Policy で禁止。ブラウザでの自動テストで外部リクエスト0件を確認）。

## 課題や命令を変える

`data/tasks.json`（課題: はじめのプログラム `starter`、テスト `tests`、ヒント、答えの例。`minSteps` で「くり返しを使ったか」も判定）と `data/isa.json`（命令表の説明・記憶装置の大きさ・自動停止の回数）を編集し、`npm run build` で単一HTMLを作り直します。

## 開発者向け

```
npm test        # 各命令の動作・エラー・自動停止と、全課題の「答えの例が正解／はじめのプログラムは不正解」のテスト（Node.js 20以上）
npm run build   # dist/virtual-cpu.html を作り直す
npm run serve   # http://localhost:8080 で確認
```

構成: `js/vm.js`（仮想CPU本体。画面に依存しない）、`js/sim.js`（シミュレーター画面）、`js/diagram.js`（図解）、`js/tasks.js`（課題）、`js/auto.js`（手計算くらべ）、`js/app.js`（画面の切りかえ）、`data/`（命令表と課題）、`sw.js`（オフライン用キャッシュ）。
