# D10 ハッシュ化体験ラボ

作成：技術 岡田

中学校技術・家庭科（技術分野）D「情報の技術」向けの体験教材です。文をハッシュ化して、ハッシュ関数の性質（同じ文なら同じ値・長さはいつも同じ・1文字変えると全体が変わる・元にもどせない）を体験し、パスワードの保存や改ざんの見つけ方まで学びます。

## すぐに使う

`dist/hash-lab.html`（配布用に同じものを `../dist/ハッシュ化体験ラボ.html` にも書き出します）をダブルクリックしてブラウザで開くだけです。1つのファイルなので、USBメモリや Classroom で配れます。インターネット接続は不要です。

## 中身

教材集での記号は **D10**。全部が発展編です。

各ステップに「チャレンジ」があり、できると ✓ が付きます（記録に入ります）。

| ステップ | 内容 | チャレンジ | 目安 |
|---|---|---|---|
| はじめに | 元のデータ → ハッシュ関数 → ハッシュ値の流れ。授業の進め方の例 | — | 5分 |
| ① ハッシュ値を作ってみよう | 文を SHA-256 でハッシュ化。同じ文 → 同じ値、長さはいつも 64 文字 | 短い文・長い文をふくめ3つ以上ハッシュ化する | 10分 |
| ② 1文字だけ変えると？ | 2つの文のハッシュ値をくらべ、ちがう文字・ビットを色で示す（なだれ効果） | 文Bを1文字だけ変える | 10分 |
| ③ 手作りハッシュの弱点 | 文字コードの合計 ÷ 100 の余りで作る「手作りハッシュ」。本物との差 | 衝突する2つの文を見つける | 10分 |
| ④ もとにもどせる？ | 3けたの暗証番号のハッシュ値から、予想・総当たりで元を見つける。文字の種類と長さで総当たりの時間を計算 | 暗証番号を見つける | 15分 |
| ⑤ パスワードの守り方 | ハッシュ値でのログイン。もれた会員表、よく使われるパスワード辞書、ソルト | 同じパスワードの2人を見つける | 15分 |
| ⑥ 改ざんを見つける | 公式のハッシュ値と、出回っている3つのファイルをくらべる。自分で書きかえてためす | 本物・書きかえを見分ける | 10分 |
| ⑦ クイズとふりかえり | 8問のクイズと、3つのふりかえり（端末の中だけに保存） | — | 10分 |
| ふりかえり・記録 | 進み具合・チャレンジ・ふりかえりの一覧。組・番号を入れて JSON/CSV に書き出す、またはコピーして提出。「はじめからやり直す」でこの端末の記録をすべて消す | — | — |

2時間（①〜④／⑤〜⑦）で行う想定です。1時間のときは ①・②・④・⑤・⑦ を中心にします。

## 記録の書き出し（振り返り一覧で読める）

「記録を書き出す」で `ハッシュ化体験ラボ_組_番号_名前.json` ができます。先生用の「振り返り一覧」（`teacher-tools/furikaeri-ichiran/`）で読みこめます。

```
{ "app": "ハッシュ化体験ラボ", "exportedAt": "…", "student": { "cls", "num", "name" },
  "steps": [{ "no", "title", "opened" }], "challenges": [{ "id", "no", "title", "cleared", "at" }],
  "quiz": { "answered", "correct", "total" }, "reflection": { "r1", "r2", "r3" } }
```

`steps[].no`・`challenges[].no` は画面と同じ「①」の形です。`app` の名前と `reflection` の r1〜r3 は、振り返り一覧が読むので変えないでください。端末の中の保存名は `eduit-hash-lab` です。

## 模型について

- ハッシュ値は本物の SHA-256 です（`js/hash.js` でブラウザの中で計算。文字は UTF-8）。ほかの SHA-256 の計算ツールと同じ値になります。
- 総当たりの時間は「1秒に100億回ためせるコンピュータ」としたときの目安です。
- 会員表・ユーザー名・パスワード・お知らせの文はすべて架空です。パスワードの欄は練習用のアカウントだけで、自分のパスワードを入れる場所はありません（総当たりの計算は、文字の種類と長さをえらぶだけ）。

## 開発者向け

```
npm test        # SHA-256（node の計算とくらべる）・手作りハッシュ・教材のデータの点検（Node.js 20以上）
npm run build   # dist/hash-lab.html と ../dist/ハッシュ化体験ラボ.html を作り直す
npm run e2e     # 1ファイル版をブラウザで開いて、6つのチャレンジ・書き出し・はじめからやり直すを確かめる（playwright が必要。SHOTS=1 で tests/shots/ に画面の例）
npm run serve   # http://localhost:8080/D-information/hash-lab/ で確認（共通の枠 ../../shared/ を読むため、リポジトリのいちばん上から配る）
```

画面の枠（上のバー・左のメニュー・カード・ボタン・「ふりかえり・記録」のページ・「はじめからやり直す」）は、生成AIのしくみラボなど、ほかの情報の教材と同じ形にそろえています。

構成: `js/hash.js`（SHA-256・手作りハッシュ・総当たりの計算）、`js/data.js`（例の文・会員表・ファイル・クイズ）、`js/app.js`（画面）、`css/style.css`。色・ヘッダー・フッターは4分野共通の枠（`shared/`）を使います。
