# D8 火星探査ロボット・シミュレータ

作成：技術 岡田

中学校技術・家庭科（技術分野）D「情報の技術」の「計測・制御のプログラミングによる問題解決」と、教科書の **統合的な問題解決**「未知の場所への調査ロボットを開発しよう」（4編3章、p.270-271 の火星探査ロボット）向けの教材です。上から見た火星のフィールドで、距離センサ・色センサ・左右のモーターを選んでロボットを設計し、D7 計測・制御シミュレータと同じブロックのプログラムで走らせます。いろいろなケースで自動テストし、レーダーチャート（機能・利便性・費用・安全性・環境への配慮）で評価して振り返ります。

## すぐに使う

- `dist/火星探査ロボット.html` をダブルクリックしてブラウザで開くだけ。1つのファイルで、インターネット接続は不要です。
- 教材集（`../dist/情報の技術_体験教材集.html`）の中では **D8**。1つずつ配るときは `クラスルーム配布/生徒に配る/1つずつ配るとき/D8_火星探査ロボット・シミュレータ.html`。

## 教科書の流れとページ

| ページ | 教科書の流れ | 内容 |
|---|---|---|
| はじめに | 1 問題の発見・課題の設定 | 火星を調べるロボットの問題と課題を考え、課題を書く |
| ① まっすぐ走って止まる（基本） | 2 構想 → 3 制作 → 動作確認 | 前進して、調査地点で止まる（時間で止める） |
| ② 岩の前で止まる・よける（基本） | 〃 | 前の距離センサで岩に近づいたら止まる・回ってよける。岩の位置が3通りのケースでテスト |
| ③ 迷路のような谷を探査する（基本） | 〃 | 岩壁の谷で調査地点をめぐって基地へ。センサの数と向き・速さを考える。谷A・谷B の2コース |
| ④ 色センサで線をたどる（発展） | 〃 | 左右の色センサで線をたどって調査地点へ。2コース |
| ⑤ 自由なコースで記録に挑戦（発展） | 〃 | 3コースで点数（調査地点 100 点・基地 100 点・電池の残り・残り時間、ぶつかると −50）を競い、端末内のランキングに残す |
| 評価・振り返り | 4 評価 | レーダーチャート（改善の前・あと）、テストの結果のまとめ、4つの問い（構想・デバッグ・改善・社会への生かし方） |
| 記録 | | 組・番号・名前、JSON（先生に出す）・CSV の書き出し |

各ステージの画面は「2 解決策の構想（ロボットの設計）→ 3 プログラムの制作 → 動作確認・デバッグ → テスト」の順です。

- **設計**: 距離センサ（前・左前・右前・左・右から3つまで）、色センサ（なし・1つ・左右2つ）、モーターの速さ（ゆっくり・ふつう・速い）。部品で費用と電池の減り方が変わります。
- **プログラム**: `ずっと` / `もし〜なら・でなければ` / `N 秒待つ` / `走行 = 前進・後退・右に回る・左に回る・止まる` / `左のモーター = 前へ・後ろへ・止める` など。ブロックとフローチャートで同じプログラムを見られます。
- **動作確認**: 実行・一時停止・1ステップ（次の命令が光る）・はじめから・速さ ×0.5〜×10、センサの値・電池・時間のメーター、コンピュータの中の値の表、ログ。

先生用ページ（模範の設計とプログラム）は、単体のファイルで `#/teacher`、教材集の中では画面をクリックしてから `teacher` と打ちます。

## 開発者向け

```
npm test        # センサ・動き・テストの判定、全ステージで模範が合格すること（Node.js 20以上）
npm run build   # dist/火星探査ロボット.html を作る
node tests/e2e.browser.cjs  # （build のあと・playwright があるとき）ブラウザでの確認
npm run serve   # http://localhost:8080/D-information/mars-rover/ （リポジトリのいちばん上から配る）
```

構成: `js/world.js`（センサ・動き・ぶつかる判定・電池・費用）、`js/rsim.js`（0.1秒きざみのシミュレーション・テストの判定・点数）、`js/stages.js`（5つのステージ）、`js/rblocks.js`（ブロック）、`js/draw.js`（フィールドの絵）、`js/radar.js`（レーダーチャート）、`js/app.js`（画面）、`js/store.js`（端末内保存。キー `rover.v1`）。

テキスト言語・インタプリタ・フローチャート・画面の部品は D7 の `../measure-control-sim/js/`（`lang.js`・`interp.js`・`flow.js`・`ui.js`・`autosave.js`）と `css/style.css` をそのまま使います。D7 のこれらを直したら、この教材も `npm run build` で作り直してください。
