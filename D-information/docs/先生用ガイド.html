1. 配り方と開き方

配り方

  1. D_情報の技術_統一版.html を、校内の共有フォルダ・USBメモリ・各端末にコピーします(元のファイル名は D-information/dist/情報の技術_体験教材集.html。zip の中では 情報の技術_体験教材集.html です。中身は同じです)。
  2. ブラウザ（Chrome・Edge など）で開きます。端末の種類による開き方のちがいは、下の「端末ごとの開き方」を見てください。

1つの教材だけを配りたいときは、1つずつ配るとき フォルダ(zip の中では「個別の教材」フォルダ)のファイルを使ってください。中身は教材集と同じです。

校内のWebサーバーに置いて使うこともできます（教材集のファイルを置くだけで動きます）。

端末ごとの開き方

配る前に、生徒と同じ端末で一度開いて確かめてください。

  • Chromebook：Google ドライブの画面でファイルを開くと「プレビュー」になり、教材は動きません。次の手順で開きます。
    1. Google ドライブ（またはクラスルーム）で、ファイルをダウンロードします。
    2. ランチャーから「ファイル」アプリを開き、「ダウンロード」フォルダの D_情報の技術_統一版.html をダブルクリックします。Chrome で開きます。
    3. 記録はその端末の Chrome に残ります。次の時間も同じ端末で開けば、続きから使えます。
    デジタル化ラボの録音では、Chrome がマイクを使ってよいか確認してくるので「許可」を押させます。
  • Windows：ファイルを端末か共有フォルダに置き、ダブルクリックで開きます。
  • iPad：「ファイル」アプリでファイルをタップすると「プレビュー」になり、教材が動かないことがあります。校内の Web サーバー（できれば https）にファイルを置き、Safari でその URL を開く方法をおすすめします。デジタル化ラボの録音も、https のページでないとマイクが使えません。

画面の使い方

  • メニューの上のバーの左に「D 情報の技術 教材集」、右に「ふりがな」「文字 中」(文字の大きさ)「先生用」が出ます。「先生用」を押すと、メニューの下の先生用のところ（学習指導要領との対応など）へ移ります。
  • メニューの「基本編」「発展編」のタブを選び、カードから教材を選びます。カードには記号（D1〜D10）・名前・説明・「使うところ」（その編で使うページの名前）・「ひらく ▶」が出ます。カードのどこを押しても開きます。基本編の上には「おすすめの順番: D1 → D2 → … → D8 → D10」の1行が出ます。
  • メニューの下は、基本編・発展編のカード → 記録（「記録をまとめて書き出す」「はじめからやり直す」）→ 先生用 の順です。前回開いた教材は、メニューの上の「前回のつづき」から開けます。
  • 教材を開くと、上のバーの左に「◀ メニュー」と「D2 仮想CPUラボ」のような記号と名前が出ます。「◀ メニュー」でメニューに戻ります。ほかの教材へは、上のバーの右の「D1 デジタル化」「D2 CPU」…のボタンで切りかえます（はばがせまい画面では「教材をかえる ▾」を押すと記号と名前の一覧が出ます）。
  • 教材の中のページには、基本編のページから順に ①②③… の番号が付いています。発展編のページは、そのあとの続きの番号です（例: 仮想CPUラボは ① 図解・② 手計算くらべ が基本編、③ 仮想CPUを動かす・④ 課題 が発展編）。「はじめに」「ふりかえり・記録」「理解度チェック」には番号を付けていません。
  • 切りかえても、開いていた教材の作業はそのまま残ります。ふりかえりの文は書いている途中で自動で保存されるので、ページを再読みこみしても消えません。再読みこみをしても、それぞれの教材はさいごに開いていたページから始まります（同じタブの中だけ）。
  • 上のバーの「ふりがな」「文字 中」は、10の教材とメニューにまとめてかかります。「ふりがな」で漢字の言葉に読みがなが付き、「文字 中」を押すと「文字 大」になって文字が大きくなります(もう一度押すと「中」にもどります)。プログラムを書く欄・入力欄・図の中の文字には、ふりがなは付きません。この設定は「はじめからやり直す」でも消えません。教材集の中では、各教材にもともとある「ふりがな」「文字 中」のボタンは、上のバーのボタンにまとめています（情報セキュリティ体験ラボの「やさしい日本語のまとめ」は教材の中に残ります）。

振り返りを隠すとき

振り返りを Google フォームなど別の方法で集めるときは、教材の中の振り返り（振り返りを書くページ・欄、記録の画面の振り返り、カードの「書いた」の印など）を出さないようにできます。

  • Classroom で配るとき：生徒に配る/振り返りなし/ の中の、同じ名前のファイルを配ります。中身は同じで、振り返りだけが出ません。1つずつ配るときのファイルも 振り返りなし/1つずつ配るとき/ にあります。
  • 生徒用サイトで使うとき：アドレスの最後に ?furikaeri=off を付けて開くよう、生徒に知らせます（例: https://okarin-netizen.github.io/Edu-IT/?furikaeri=off）。一度開くと、その端末で覚えています。?furikaeri=on を付けて開くと元にもどります。
  • 隠しても、それまでに書いた振り返りは消えません（記録の書き出しにもそのまま入ります）。

2. 教材の一覧(基本編・発展編)

3. 単元での使い方

基本編のカードは、おすすめの順（D1 デジタル化ラボ → D2 仮想CPUラボ → D3 ネットワーク通信シミュレータ → D4 情報セキュリティ体験ラボ → D5 ネット詐欺 追体験ラボ → D6 双方向コンテンツ制作スタジオ → D7 計測・制御シミュレータ → D8 生成AIのしくみラボ → D10 火星探査ロボット・シミュレータ）です。カードは教科書の章ごとに区切って出るので、D10 は「技術による問題解決(つくる)」の区切りの D7 のあとに出ます。D9 ハッシュ化体験ラボは発展編だけです。授業の進め方に合わせて、どこから始めてもかまいません。

教材ごとの進め方の例

  • D1 デジタル化ラボ：1時間目「はじめに・① 画像・② 音」、2時間目「③ 2進数・④ データ量の計算ドリル・ふりかえり」。⑤ 圧縮のしくみは発展で、早く終わった生徒や次の時間に使います。動画のデータ量は「発展」で、ドリルの「動画」のときだけ出ます（電卓を使ってよい）。
  • D2 仮想CPUラボ：基本編は1時間で「① 図解（25分）・② 手計算くらべ・ふりかえり・記録の書き出し（25分）」。② 手計算くらべは、課題をしていなくても取り組めます（使うプログラムは用意してあります）。発展編は「③ 仮想CPUを動かす・④ 課題」で、課題は1〜4が必修、5〜7が発展、8がチャレンジです。
  • D3 ネットワーク通信シミュレータ：1時間目「① 組み立て・② Webページが届くまで」、2時間目「③ 故障・④ のぞき見・⑤ ドリル（発展）」。ドリルの /25・/28 は「チャレンジ問題」で、クリアには関係ありません。
  • D4 情報セキュリティ体験ラボ：D4_情報セキュリティ体験ラボ_先生用ガイド.html（zip の中では「先生用ガイド_情報セキュリティ体験ラボ.html」）の7時間の計画のとおりです。暗号ラボは2回に分けて（1回目ステップ1〜3、2回目ステップ4〜7）行います。RSA の計算は「発展」です。デジタル化ラボとネットワーク通信シミュレータを先に使った場合は、「① デジタル化と情報量」と「⑤ ネットワーク通信の模擬」を省いて5時間にできます（下の「内容が重なっている単元」を見てください）。⑪ ハッシュ体験は発展で、⑩ まとめ・行動宣言のあとにあります。
  • D5 ネット詐欺 追体験ラボ：① ワンクリック詐欺 〜 ⑤ にせの通販サイトの5つの詐欺（各10分）を体験し、⑥ まとめとふりかえり（10分）で共通の手口と自分の行動をまとめます。
  • D6 双方向コンテンツ制作スタジオ：ひな形（カウンター・クイズ・バグを直そう・アンケート集計）で操作としくみをつかみ、企画・改善メモを書いて制作し、友だちに使ってもらって改善します（くわしくは教材の README）。作品には、サーバーとのやりとり（server の命令）を1つ以上入れさせます（学習指導要領 D(2) のネットワークを利用した双方向性のため）。作品一覧で「📡 サーバーあり」と表示されます。
  • D7 計測・制御シミュレータ：1時間目「① 街灯・② 自動ドア（各20分）」、2時間目「③ 信号機（40分）」、3時間目「④ 押しボタン式信号機（25分）・⑤ 自由に作る（発展。10〜15分）」。
  • D8 生成AIのしくみラボ：基本編は1時間で「① もっともらしいまちがい・② 個人情報が出てしまう？・③ クイズとふりかえり」。発展編は「④ つぎの言葉あて・⑤ トークン・⑥ ミニ文章AI・⑦ ノイズをまぜる・⑧ ノイズから絵をつくる」。③ のクイズ（6問）は、基本編の内容（もっともらしいまちがい・個人情報・使うときのルール）だけです。
  • D10 火星探査ロボット・シミュレータ：D7 のあと、計測・制御の単元のまとめ（統合的な問題解決）に使います。1時間目「はじめに（問題の発見・課題の設定 10分）・① まっすぐ走って止まる（15分）・② 岩の前で止まる・よける（前半）」、2時間目「② の後半・③ 迷路のような谷を探査する（どのセンサをどこに付けるかを考える）」、3時間目「③ のテストと改善・評価・振り返り（レーダーチャート）・記録の書き出し」。発展は「④ 色センサで線をたどる・⑤ 自由なコースで記録に挑戦」で、⑤ は班で点数・時間・電池の残りをくらべると盛り上がります。各ステージは「2 解決策の構想（ロボットの設計）→ 3 プログラムの制作 → 動作確認・デバッグ → テスト」の順にならび、教科書の流れと同じです。実際のロボットを作る前の構想・試行や、ロボットの台数が足りないときに使えます。
  • D9 ハッシュ化体験ラボ（発展編だけ）：1時間目「① ハッシュ値を作る 〜 ④ もとにもどせる？」、2時間目「⑤ パスワードの守り方・⑥ 改ざんを見つける・⑦ クイズとふりかえり」。

内容が重なっている単元

情報セキュリティ体験ラボの次の2つの単元は、ほかの教材と内容が重なります。どちらも残してあり、教材集の中で開いたときだけ、単元のさいご（ふりかえりのあと）に「もっとくわしく学びたいとき」の案内とボタンが出ます。移った先のページの上と下に「← 情報セキュリティ体験ラボにもどる」が出て、押すと同じ単元にもどれます。

情報セキュリティ体験ラボの単元くわしく扱う教材使い分けの目安
① デジタル化と情報量D1 デジタル化ラボセキュリティの単元の導入として短く扱うならラボのまま。D(1)の授業としてじっくり扱うならデジタル化ラボ。
⑤ ネットワーク通信の模擬D3 ネットワーク通信シミュレータ（「④ のぞき見と暗号化」が開きます）HTTPとHTTPSの違いだけなら単元のまま。ネットワークのしくみから扱うならシミュレータ。

授業で片方だけを使う場合、情報セキュリティ体験ラボの「先生用ページ」で使わない単元を非表示にできます（開き方は 4. の「先生用ページの開き方」を見てください）。

4. 記録の保存と提出

保存

  • 学習の記録は、その端末のブラウザの中にだけ保存されます（ほかの端末とは共有されません）。外部には送られません。
  • 第1.7版で記号と番号を付け直しましたが、保存の場所（保存名）は前の版と同じなので、前の版の記録もそのまま続きから使えます。書き出したファイルの中のページの名前は、新しい番号（「① 画像のデジタル化」など）になります。

提出

  • 提出させるときは、メニューの「記録をまとめて書き出す」で、組・番号・名前を1回入れて「JSONで書き出す（先生に出す）」を押させてください。10の教材の記録（進み具合・ふりかえり・作品の計画や改善メモ・もとのデータ）が1つの JSON ファイルになります（ファイルの中の app は「情報の技術 教材集」、kind は「記録まとめ」です）。ファイル名は「情報の技術_記録まとめ_3組7番_2026-10-13.json」のように、組・番号・日付が入ります。
  • 組か番号が空のときは書き出せません。まだ使っていない教材は「まだ記録なし」と表示されます。
  • 「CSVで書き出す（表計算ソフト用）」は、表計算ソフトで見るためのものです。提出は JSON にします。教材ごとの「ふりかえり・記録」からも、これまでどおり書き出せます。
  • Chromebook では、書き出したファイルは「ファイル」アプリの「ダウンロード」フォルダに入ります。クラスルームの課題に添付させると集めやすくなります。
  • 仮想CPUラボの記録には、課題ごとのプログラムと「答えの例を見たか」が入ります。情報セキュリティ体験ラボの判断ロールプレイは「最初に選んだ結末」と「いちばんよかった結末」が残ります。どちらも成績に使わないことを生徒に伝えてあります。

提出されたファイルを見る

  • 4分野共通の 全分野_振り返り一覧.html で、ほかの分野と同じように、提出された JSON のふりかえりを一覧にできます。
  • 情報セキュリティ体験ラボの完了人数や事前・事後テストの伸びは、ラボの先生用ページの「クラスの記録を集計する」で見られます（D4_情報セキュリティ体験ラボ_先生用ガイド.html の 4. を見てください）。

記録を消す

端末を共有している場合は、提出したあと、メニューのいちばん下の「はじめからやり直す」で「この端末の記録をすべて消す」を押すと、10の教材の記録がまとめて消えます（「記録をまとめて書き出す」の組・番号・名前も消えます。ふりがな・文字の大きさなどの表示の設定と、差し替えた問題データは残ります）。1つの教材だけ消すときは、その教材の「ふりかえり・記録」のページから消せます。

5. 授業で使うときの注意

  • デジタル化ラボの「聞きくらべ」：音が出ます。イヤホンを使うか、先生の画面で全員いっしょに聞き、生徒の端末は音を消してグラフを見させます。
  • 情報セキュリティ体験ラボの理解度チェック：事前テストと事後テストは、それぞれ最初の1回の点が記録に残ります（2回目からは練習）。事前テストのあとは点数だけが出て、答えと解説は事後テストのあとに見られます。先生用ページで、両方受けた生徒の伸びが見られます。
  • 相談窓口：情報セキュリティ体験ラボに相談窓口の電話番号が出ます（2026年10月13日に公式ページで確認）。年度ごとに確かめてください。変え方は、情報セキュリティ体験ラボの先生用ガイドにあります。
  • 双方向コンテンツ制作スタジオのアンケート作品：この教材のサーバーは端末ごとの模型なので、ほかの端末の答えは集まりません。クラスのアンケートは、班の中で1台の端末を回して答えてもらいます。
  • 双方向コンテンツ制作スタジオの作品の保存：作品は自動で保存されます。端末をかえるときや念のために残すときは「ファイルに保存（.json）」を使います。
  • 登場する会社名・アドレス・地名・学校名はすべて架空です。

6. こまったとき

Chromebook で開くと教材が動かない
Google ドライブの画面で開くと「プレビュー」になり、教材は動きません。ファイルをダウンロードしてから、「ファイル」アプリの「ダウンロード」フォルダでダブルクリックして開きます（1. の「端末ごとの開き方」）。
iPad で開くと教材が動かない
「ファイル」アプリでタップすると「プレビュー」になることがあります。校内の Web サーバー（できれば https）にファイルを置き、Safari でその URL を開いてください。
デジタル化ラボで録音できない
Chrome がマイクを使ってよいか確認してきたら「許可」を押させます。断ってしまったときのやり直し方は、デジタル化ラボの録音の前の説明にあります。iPad では、https のページでないとマイクが使えません。
前の時間の記録が見えない
記録はその端末のブラウザの中にだけ残ります。前と同じ端末・同じブラウザで開いているか確かめてください。
先生用ページが開かない
アドレスに # から後ろがすでに付いているときは、それを消してから #/security-lab/teacher などを足します（4. の「先生用ページの開き方」）。
