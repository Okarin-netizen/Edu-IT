情報の技術 体験教材集　先生用の手引き

中学校 技術・家庭科（技術分野）D「情報の技術」　第1.5版 2026年10月
作成：技術　岡田

6つの体験教材を、メニュー付きの1つのHTMLファイルにまとめたものです。インターネットへの接続やインストールは不要で、外部のサイトには一切つながりません。入力した内容や学習の記録は、その端末のブラウザの中にだけ保存されます。

1. 使い方

  1. 情報の技術_体験教材集.html を、校内の共有フォルダ・USBメモリ・各端末にコピーします。
  2. ブラウザ（Chrome・Edge など）で開きます。端末の種類による開き方のちがいは、下の「端末ごとの開き方」を見てください。
  3. メニューのカードから教材を選びます。上のバーの左端の「◀ メニュー」（または教材集の名前）を押すとメニューに戻ります。ほかの教材へは、上のバーの右の教材の名前を押して切りかえます（はばがせまい画面では「教材をかえる ▾」を押すと名前の一覧が出ます）。
  4. 切りかえても、開いていた教材の作業はそのまま残ります。ふりかえりの文は書いている途中で自動で保存されるので、ページを再読みこみしても消えません。再読みこみをしても、それぞれの教材はさいごに開いていたページから始まります（同じタブの中だけ）。
  5. 上のバーの「ふりがな」「大きな文字」は、6つの教材とメニューにまとめてかかります。漢字の言葉に読みがなが付き、文字が大きくなります。プログラムを書く欄・入力欄・図の中の文字には、ふりがなは付きません。この設定は「はじめからやり直す」でも消えません。教材集の中では、各教材にもともとある「ふりがな」「大きな文字」のボタンは、上のバーのボタンにまとめています（情報セキュリティ体験ラボの「やさしい日本語のまとめ」は教材の中に残ります）。

端末ごとの開き方（配る前に、生徒と同じ端末で一度開いて確かめてください）

  • Chromebook：Google ドライブの画面でファイルを開くと「プレビュー」になり、教材は動きません。次の手順で開きます。
    1. Google ドライブ（またはクラスルーム）で、ファイルをダウンロードします。
    2. ランチャーから「ファイル」アプリを開き、「ダウンロード」フォルダの 情報の技術_体験教材集.html をダブルクリックします。Chrome で開きます。
    3. 記録はその端末の Chrome に残ります。次の時間も同じ端末で開けば、続きから使えます。
    デジタル化ラボの録音では、Chrome がマイクを使ってよいか確認してくるので「許可」を押させます。
  • Windows：ファイルを端末か共有フォルダに置き、ダブルクリックで開きます。
  • iPad：「ファイル」アプリでファイルをタップすると「プレビュー」になり、教材が動かないことがあります。校内の Web サーバー（できれば https）にファイルを置き、Safari でその URL を開く方法をおすすめします。デジタル化ラボの録音も、https のページでないとマイクが使えません。

1つの教材だけを配りたいときは、ZIPの中の「個別の教材」フォルダのファイルを使ってください。中身は教材集と同じです。

生徒向けのメニューのカードには学習指導要領の記号を出さず、メニューの「先生へ」に対応の一覧があります。すべて使うと 20〜22 時間です。各教材の「はじめに」に、1時間ごとの進め方の例があります。

  • デジタル化ラボ：1時間目「はじめに・画像・音」、2時間目「2進数・圧縮・ふりかえり」。データ量の計算ドリルは、次の時間のはじめや復習に使います。動画のデータ量は「発展」で、ドリルの「動画」のときだけ出ます（電卓を使ってよい）。
  • 仮想CPUラボ：1時間目「図解（20分）・ステップ実行（30分）」、2時間目「課題（30分）・手計算くらべ・ふりかえり・記録の書き出し（20分）」。課題は1〜4が必修です。2時間目の後半は、課題の途中でも全員が手計算くらべに移ります。
  • ネットワーク通信シミュレータ：1時間目「1 組み立て・2 Webページが届くまで」、2時間目「3 故障・4 のぞき見・5 ドリル」。ドリルの /25・/28 は「チャレンジ問題」で、クリアには関係ありません。
  • 情報セキュリティ体験ラボ：同梱の「先生用の手引き_情報セキュリティ体験ラボ.html」の7時間の計画のとおりです。暗号ラボは2回に分けて（1回目ステップ1〜3、2回目ステップ4〜7）行います。RSA の計算は「発展」です。デジタル化ラボとネットワーク通信シミュレータを先に使った場合は、「1 デジタル化と情報量」と「6 ネットワーク通信の模擬」を省いて5時間にできます（下の3.を見てください）。
  • 双方向コンテンツ制作スタジオ：ひな形（カウンター・クイズ・バグを直そう・アンケート集計）で操作としくみをつかみ、企画・改善メモを書いて制作し、友だちに使ってもらって改善します（くわしくは教材の README）。作品には、サーバーとのやりとり（server の命令）を1つ以上入れさせます（学習指導要領 D(2) のネットワークを利用した双方向性のため）。作品一覧で「📡 サーバーあり」と表示されます。
  • 計測・制御シミュレータ：1時間目「場面1・2（各20分）」、2時間目「場面3（40分）」、3時間目「場面4（25分）・場面5（10〜15分）」。

3. 内容が重なっている単元

情報セキュリティ体験ラボの次の2つの単元は、ほかの教材と内容が重なります。どちらも残してあり、教材集の中で開いたときだけ、単元のさいご（ふりかえりのあと）に「もっとくわしく学びたいとき」の案内とボタンが出ます。移った先のページの上と下に「← 情報セキュリティ体験ラボにもどる」が出て、押すと同じ単元にもどれます。

情報セキュリティ体験ラボの単元くわしく扱う教材使い分けの目安
1 デジタル化と情報量デジタル化ラボセキュリティの単元の導入として短く扱うならラボのまま。D(1)の授業としてじっくり扱うならデジタル化ラボ。
6 ネットワーク通信の模擬ネットワーク通信シミュレータ（「のぞき見と暗号化」が開きます）HTTPとHTTPSの違いだけなら単元のまま。ネットワークのしくみから扱うならシミュレータ。

授業で片方だけを使う場合、情報セキュリティ体験ラボの「先生用ページ」で使わない単元を非表示にできます（開き方は 5. を見てください）。

4. 記録の提出

  • 提出させるときは、メニューの「記録をまとめて書き出す」で、組・番号・名前を1回入れて「JSONで書き出す（先生に出す）」を押させてください。6つの教材の記録（進み具合・ふりかえり・作品の計画や改善メモ・もとのデータ）が1つの JSON ファイルになります。ファイル名は「情報の技術_記録まとめ_3組7番_2026-10-13.json」のように、組・番号・日付が入ります。
  • 組か番号が空のときは書き出せません。まだ使っていない教材は「まだ記録なし」と表示されます。
  • 「CSVで書き出す（表計算ソフト用）」は、表計算ソフトで見るためのものです。提出は JSON にします。教材ごとの「ふりかえり・記録」からも、これまでどおり書き出せます。
  • Chromebook では、書き出したファイルは「ファイル」アプリの「ダウンロード」フォルダに入ります。クラスルームの課題に添付させると集めやすくなります。
  • 仮想CPUラボの記録には、課題ごとのプログラムと「答えの例を見たか」が入ります。情報セキュリティ体験ラボの判断ロールプレイは「最初に選んだ結末」と「いちばんよかった結末」が残ります。どちらも成績に使わないことを生徒に伝えてあります。
  • 端末を共有している場合は、提出したあと、メニューのいちばん下の「はじめからやり直す」で「この端末の記録をすべて消す」を押すと、6つの教材の記録がまとめて消えます（「記録をまとめて書き出す」の組・番号・名前も消えます。ふりがな・文字の大きさなどの表示の設定と、差し替えた問題データは残ります）。1つの教材だけ消すときは、その教材の「ふりかえり・記録」のページから消せます。

5. 先生用のページの開き方

先生用のページは、生徒が開かないようにメニューには出していません。先生の端末で、ファイルのアドレスの最後に次の文字を足して開きます。

ページ教材集で開くとき個別の教材で開くとき
情報セキュリティ体験ラボの先生用ページ（使うモジュールの設定・問題データの差し替え・クラスの集計）情報の技術_体験教材集.html#/security-lab/teacher情報セキュリティ体験ラボ.html#/teacher
計測・制御シミュレータの先生用ページ（3時間の計画・4つの場面の模範プログラム）情報の技術_体験教材集.html#/measure-control-sim/teacher計測制御シミュレータ.html#/teacher
  • アドレスに # から後ろがすでに付いているときは、それを消してから足します。
  • 計測・制御シミュレータは、教材を開いた状態で画面をクリックし（入力欄の外）、キーボードで teacher と打っても開きます。
  • 情報セキュリティ体験ラボの設定を変えた端末は、先生用ページの「標準に戻す」で元にもどせます。

6. 授業での注意

  • デジタル化ラボの「聞きくらべ」：音が出ます。イヤホンを使うか、先生の画面で全員いっしょに聞き、生徒の端末は音を消してグラフを見させます。
  • 情報セキュリティ体験ラボの理解度チェック：事前テストと事後テストは、それぞれ最初の1回の点が記録に残ります（2回目からは練習）。事前テストのあとは点数だけが出て、答えと解説は事後テストのあとに見られます。先生用ページで、両方受けた生徒の伸びが見られます。
  • 相談窓口：情報セキュリティ体験ラボに相談窓口の電話番号が出ます（2026年10月13日に公式ページで確認）。年度ごとに確かめてください。変え方は、情報セキュリティ体験ラボの手引きにあります。
  • 双方向コンテンツ制作スタジオのアンケート作品：この教材のサーバーは端末ごとの模型なので、ほかの端末の答えは集まりません。クラスのアンケートは、班の中で1台の端末を回して答えてもらいます。
  • 双方向コンテンツ制作スタジオの作品の保存：作品は自動で保存されます。端末をかえるときや念のために残すときは「ファイルに保存（.json）」を使います。

7. 注意

  • 校内のWebサーバーに置いて使うこともできます（教材集のファイルを置くだけで動きます）。
  • 登場する会社名・アドレス・地名・学校名はすべて架空です。

  • 上のバー（白地に青い線）、「ふりがな」「大きな文字」などのボタン、メニューのカード、色と文字を、4分野で共通の形にしました。教材を開いているときは、上のバーの左に「◀ メニュー」が出ます。

10. 第1.3版で直したこと（2026年10月13日）

レビューで「直すともっとよくなる」とした所（30件）を直しました。授業で気をつけたい変更は次のとおりです。

  • デジタル化ラボ：データ量の計算ドリルのステップ2は、「いろいろ」で8問以上のときだけクリアになります（前にクリアした生徒の ✓ は残ります）。録音の前に「許可」を押すことと、断ってしまったときのやり直し方を書きました。
  • 仮想CPUラボ：手計算くらべの「昔のパソコン」の時間を、1命令に合図4回で計算するようにしたので、前の4倍の時間が出ます。答え合わせでまちがえた入力を、そのまま試せるボタンを付けました。
  • ネットワーク通信シミュレータ：店の名前を情報セキュリティ体験ラボとそろえて「クモストア（kumo-store.example）」にしました。図の文字を大きくしました。
  • 情報セキュリティ体験ラボ：練習は、モジュールを選んでから、1回10問までになりました。理解度チェックの問題は単元の順に出ます（点数のつけ方は同じです）。著作権クイズでは、△のときによりよい答えが出て、同じ場面をやり直せます。
  • 計測・制御シミュレータ：不合格になった時刻をグラフに赤い点線で出し、記録にセンサの値を書くようにしました。押しボタンを短く押しても、プログラムが気づくようにしました。
  • 双方向コンテンツ制作スタジオ：「バグを直そう」の見本に使い方の説明を入れ、「エディタで直す」でまちがいの行へ移るようにしました。デバッグとサーバーのページに、次にすることの案内を付けました。
  • 教材集：再読みこみしても、さいごに開いていたページから始まります。メニューのカードから学習指導要領の記号を外し、「先生へ」にまとめました。

11. 第1.2版で直したこと（2026年10月13日）

レビューで「多くの生徒がつまずく・迷う」とした所を直しました。

  • 教材集：上のバーに「ふりがな」「大きな文字」を付け、6教材にまとめてかかるようにしました。教材の切りかえボタンに名前を付け、上のバーを低くしました。6教材の記録を1つのファイルで出せる「記録をまとめて書き出す」を足しました。タブレットの縦向きで、教材の中のメニューが全部見えるようにしました。
  • 6教材すべて：記録を書き出すとき、組・番号が空なら書き出さず、書き出したらファイル名を表示するようにしました。答えをまちがえたときにもう一度選べるクイズを増やしました。時間の目安と、1時間ごとの進め方の例を付けました。
  • デジタル化ラボ：動画のデータ量を「発展」にし、聞きくらべに音のグラフと「何が起きているか」の説明を付けました。単位の決まり（8ビット＝1バイト、1KB＝1024バイト）を、はじめて出る所に書きました。
  • 仮想CPUラボ：課題を必修・発展・チャレンジに分け、ヒントが答えそのものにならないように直しました。「この答えをプログラム欄に入れる」ボタンをなくしました。✓ は、本当にできたときだけ付くようにしました（前に開いただけで付いた ✓ は消えます）。
  • ネットワーク通信シミュレータ：ドリルを授業で説明する範囲（/24）にし、2進数の読み方のカードを付けました。アニメーションの一時停止と「1つずつ進む」、機器を消すときの確認と「1つもどす」を足しました。届かないわけを、くわしく出すようにしました。
  • 情報セキュリティ体験ラボ：暗号ラボを2回に分け、RSA の計算を発展にしました。とても大きな数を「10の◯乗」と「宇宙の年齢の◯倍」で表すようにしました。先生用ページをメニューから外し、相談窓口を足しました。ふりがなの言葉を82語ふやしました。
  • 双方向コンテンツ制作スタジオ：ブロックを入れる場所が見えるようにし、「もし」の条件を3つの欄に分けました。ブロックと実行画面を並べて見られる表示と、「大きな文字」を足しました。
  • 計測・制御シミュレータ：ブロックを入れる場所と、ブロックを「もし」の中や外へ動かすボタンを付けました。テストのボタンをプログラムの上に置きました。模範プログラムを先生用ページへ移しました。場面4は、はじめのプログラムを少し進めた形にしました（場面4をすでに始めた生徒は、「はじめのプログラムにもどす」を押したときだけ変わります）。
