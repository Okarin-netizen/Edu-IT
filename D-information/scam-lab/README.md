# ネット詐欺 追体験ラボ

作成：技術 岡田

中学校技術・家庭科（技術分野）D「情報の技術」向けの体験教材です。インターネットの詐欺を、スマホやパソコンの画面を自分で操作して「追体験」します。だまされそうになったとき、正しい手順を最後までやりきるとクリアです。

## すぐに使う

`dist/scam-lab.html`（配布用に同じものを `../dist/ネット詐欺_追体験ラボ.html` にも書き出します）をダブルクリックしてブラウザで開くだけです。1つのファイルなので、USBメモリや Classroom で配れます。インターネット接続は不要です。

## 中身

| ステップ | 場面 | 正しい手順(やることリスト) | 目安 |
|---|---|---|---|
| 1 | ワンクリック詐欺(スマホ) | 「お客様の情報」で個人は知られていないと気づく → 1回押しただけでは契約していないと気づく → 連絡も支払いもせずに閉じる → 通知を止め、履歴を消す → 家の人に話す | 10分 |
| 2 | 「当選しました」メール(スマホ) | 応募したか思い出す → 公式アプリで確かめる → 迷惑メールとして報告して削除 | 10分 |
| 3 | ウイルス付きメール(パソコン) | 差出人のアドレスを確かめる → メール以外の方法で本人に聞く → 添付を開かずに先生に知らせる | 10分 |
| 4 | にせのウイルス警告(パソコン) | Webページにパソコンの中は調べられないと気づく → Esc で全画面を終わらせる → タブを閉じる → 家の人・先生に伝える | 10分 |
| 5 | にせの通販サイト(スマホ) | 値段をくらべる → 特定商取引法に基づく表記を確かめる → 店名で評判を検索 → 買わずに閉じて家の人に話す | 10分 |
| 6 | まとめとふりかえり | どの詐欺にも共通する3つの手口、「とまる → たしかめる → そうだんする」、相談先(188・#9110・24時間こどもSOSダイヤル)、ふりかえり3問 | 10分 |
| — | ふりかえり・記録 | 組・番号・名前を入れて JSON/CSV に書き出す、またはコピーして提出。「はじめからやり直す」でこの端末の記録をすべて消す | — |

- 左の画面(スマホ・パソコンの模型)の中のボタンも押せます。押すとだまされることもあり、そのときは「どうなった？」「どうすればよかった？」を読んで、その前の場面からやり直せます。
- 右の「あなたの行動」から次の行動をえらびます。よい行動をすると「やることリスト」の「？」が開きます。リストを全部うめないと、最後の行動をしてもクリアになりません。
- 「💡 ヒント」で、つぎにやることの手がかりが出ます。クリア・だまされた回数・ヒントの回数を記録します。

1時間(50分)で行う想定です。時間がないときは 1・3・4 を中心にします。

## 情報セキュリティ体験ラボとのちがい

情報セキュリティ体験ラボの「フィッシング見分け」(SMS・銀行メール・ゲームのログイン画面などで、怪しい所を見つける)と「判断ロールプレイ」(知らない人のDM・アプリの権限・パスワードを聞かれた・知ってしまった)とは、場面が重ならないようにしています。あちらは「見分ける・判断する」、こちらは「だまされる画面を自分で操作し、ぬけ出す手順をやりきる」体験です。続けて使うと「見分ける → 行動する」の流れになります。

## 安全のための設計

- 外部のサイトには一切接続しません(Content-Security-Policy で外部通信を禁止。ブラウザでの自動テストで外部リクエスト0件を確認)。
- 会社名・サイト名は架空で、アドレスは例示用に予約された `.example`、IPアドレスは説明用の `203.0.113.x`、電話番号・口座番号は実在しない番号だけを使っています(`npm test` で確認)。
- 入力欄は見た目だけで、名前やカード番号を入力する場所はありません。

## 記録(振り返り一覧で読める)

「記録を書き出す」でできる JSON は、ほかの情報の教材と同じく `student: { cls, num, name }` を持ち、先生用の振り返り一覧(`teacher-tools/furikaeri-ichiran/`)で読み込めます。

```json
  "reflection": { "r1": "…", "r2": "…", "r3": "…" } }
```

## 開発者向け

```
npm test        # 場面のデータの点検(行き先・やることリスト・クリアできるか・架空のアドレスだけか)（Node.js 20以上）
npm run build   # dist/scam-lab.html と ../dist/ネット詐欺_追体験ラボ.html を作り直す
npm run e2e     # 1ファイル版をブラウザで開いて、5つの場面をクリアできるか・レビューで直した所を確かめる（playwright が必要）
npm run serve   # http://localhost:8080/D-information/scam-lab/ で確認（共通の枠 ../../shared/ を読むため、リポジトリのいちばん上から配る）
```

構成: `js/engine.js`（場面を進めるしくみ。画面を使わない）、`js/data.js`（5つの場面・まとめ・相談先）、`js/app.js`（画面）、`css/style.css`。場面は「画面(node)」と「おわり(end)」のつながりで書き、くわしい書き方は `js/engine.js` のはじめにあります。場面を直したら `npm test` でつながりを確かめます。

中学生目線レビューと改善の記録は `../review/2026-10-16_ネット詐欺_追体験ラボ_中学生目線レビュー/` にあります。

画面の枠（上のバー・左のメニュー・カード・ボタン・「ふりかえり・記録」のページ）は、生成AIのしくみラボなど、ほかの情報の教材と同じ形にそろえています。色・ヘッダー・フッターは4分野共通の枠（`shared/`）を使います。
