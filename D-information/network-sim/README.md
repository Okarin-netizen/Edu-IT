# D3 ネットワーク通信シミュレータ

作成：羽生市立南中学校 技術 岡田

中学校技術・家庭科（技術分野）D「情報の技術」4章「情報通信ネットワークの仕組み」向けの体験教材です（学習指導要領 D(1)(2)：D(1)「生活や社会を支える情報の技術」、D(2)「ネットワークを利用した双方向性のあるコンテンツのプログラミングによる問題の解決」。とくに D(2)ア「情報通信ネットワークの構成と、情報を利用するための基本的な仕組み」）。計画書 [`../review/計画/plan-I3-network-sim.md`](../review/計画/plan-I3-network-sim.md) の MVP（5つの機能）を実装しています。

## すぐに使う

- **いちばん簡単**: `dist/network-sim.html` をダブルクリックしてブラウザで開くだけ。1つのファイルなので、USBメモリや校内の共有フォルダで配れます。インターネット接続は不要です。
- **PWAとして配信する場合**: このフォルダ全体を校内のWebサーバーに置き、`index.html` を開きます。一度開くと端末にキャッシュされ、オフラインでも動きます。

## 中身

教材集での記号は **D3**。①〜④が基本編、⑤が発展編です。

| # | 画面 | 内容 | 目安 |
|---|---|---|---|
| ① | ネットワークを組み立てる | パソコン・スマホ・ルータ・Webサーバ・DNSサーバをドラッグ（またはクリック）で置き、線でつなぐ。名前・IPアドレスの変更、IPの書き方や重複の点検、「つながりチェック」 | 15分 |
| ② | Webページが届くまで | DNSへの問い合わせ → IPアドレス → お願い（GET）→ ページをパケットに分割 → 別々の経路 → 届いた順がばらばらでも番号順に組み立て、をアニメで表示 | 15分 |
| ③ | 回線が切れたら？ | 回線を切る／ルータやサーバを止める → いちばん近い道が変わる（迂回）・到達不能になる。DNSサーバを止めると名前で開けないことも確かめる | 15分 |
| ④ | のぞき見と暗号化 | 途中の回線にいる「のぞき見する人」に見える内容を HTTP と HTTPS で比較。のぞき見の場所も変えられる | 10〜15分 |
| ⑤ | IPアドレス・ドリル（発展編） | IPアドレスを2進数で見る道具と、毎回変わる10問ドリル（書き方、同じネットワーク、2進数⇔10進数、つなげる台数、機器の役目） | 10〜15分 |

①で作ったネットワークは②〜④でも使われます（「はじめの形にもどす」で元にもどせます）。各画面にステップの進み具合、確認クイズ、ふりかえりがあり、「ふりかえり・記録」から JSON / CSV で書き出せます。「大きな文字」の切りかえ、キーボード操作（機器は矢印キーで移動、線は選んでつなぐフォーム）、ダークモードにも対応しています。

## 安全のための設計

- 外部のサイトには一切接続しません（Content-Security-Policy で外部通信を禁止。ブラウザでの自動テストで外部リクエスト0件を確認）。すべてブラウザの中の模型のネットワークで、本物のネットワークにはさわりません。
- サイト名は例示用に予約された `.example`、外側のIPアドレスは説明用に予約された 203.0.113.x・198.51.100.x、家の中はプライベートアドレス 192.168.1.x を使っています。
- のぞき見で使うIDとパスワードは架空の固定値で、生徒に入力させません。HTTPS の暗号文は意味のない16進数を表示する模型であることを画面に明記しています。盗聴の具体的な方法には触れず、概念のレベルにとどめています。

## 開発者向け

```
npm test        # 経路（ダイクストラ・迂回・到達不能）、DNS、IPアドレス・サブネット、パケットの分割と組み立て、ドリル問題、外部通信がないことのテスト（Node.js 20以上）
npm run build   # dist/network-sim.html を作り直す
npm run serve   # http://localhost:8080/D-information/network-sim/ で確認（共通の枠 ../../shared/ を読むため、リポジトリのいちばん上から配る）
```

構成: `js/`（app.js=画面とルーティング, netlib.js=ネットワークの計算, netview.js=ネットワーク図とアニメ, drilllib.js=ドリル問題, store.js=端末内保存, ui.js=共通部品）、`modules/`（各画面）、`sw.js`（オフライン用キャッシュ）。見た目は「情報セキュリティ体験ラボ」と共通です。
