# D1 デジタル化ラボ

作成：技術 岡田

中学校技術・家庭科（技術分野）D「情報の技術」、教科書3章「情報のデジタル化」向けの体験教材です。学習指導要領の内容の取扱い「情報のデジタル化の方法と情報の量」に対応し、アナログ→デジタル（標本化・量子化・符号化）のしくみと、情報量・画質・音質の関係を体験で学びます。計画書は [`../review/計画/plan-I1-digitization-lab.md`](../review/計画/plan-I1-digitization-lab.md)。

## すぐに使う

- **いちばん簡単**: `dist/digitization-lab.html` をダブルクリックしてブラウザで開くだけ。1つのファイルなので、USBメモリや校内の共有フォルダで配れます。インターネット接続は不要です。
- **PWAとして配信する場合**: このフォルダ全体を校内のWebサーバーに置き、`index.html` を開きます。一度開くと端末にキャッシュされ、オフラインでも動きます。

## 中身

教材集での記号は **D1**。ページは基本編（①〜④）→ 発展編（⑤ 圧縮のしくみ）の順で、①②③… の番号は画面の番号と同じです。

| # | モジュール | 内容 | 目安 |
|---|---|---|---|
| ① | 画像のデジタル化 | 8×8の画素を塗って0と1に（符号化・復号のお題）、解像度と階調（白黒→グレー→カラー）を変えて見た目とデータ量（計算式つき）、くらべる表、自分の写真でも試せる、RGBの色づくり | 20〜25分 |
| ② | 音のデジタル化 | 標本化・量子化の波形グラフ、メロディと鈴の音を設定を変えて聞きくらべ（低い標本化周波数→こもる・高い音が消える。イヤホンで各自、または先生の画面でいっしょに聞く。音を出せなくても「残る音の高さ」と「波の形」の図で確かめ、気づいたことを選ぶ問題に正解でクリア）、発展としてマイクで自分の声、音のデータ量 | 20分 |
| ③ | 2進数と文字コード | ビットカードで数を作るお題、10進⇔2進の変換パズル、文字コード（UTF-8）の表示と0と1の暗号の解読 | 20〜25分 |
| ④ | データ量の計算ドリル | 単位・ビット数・画像・音の問題を毎回自動で作る10問ドリル（動画は「動画（発展）」を選んだときだけ。電卓を使ってもよい）、最高点の記録 | 15〜20分 |
| ⑤ | 圧縮のしくみ（発展編） | ランレングス圧縮を手作業で→自動で、絵ごとの圧縮率の比較表、文字の圧縮、可逆・非可逆 | 20分 |

各モジュールにステップごとの「できた」表示とふりかえりがあり、「ふりかえり・記録」ページから名前・進み具合・ドリルの最高点・ふりかえりを JSON/CSV に書き出せます。画面右上の「大きな文字」で文字を大きくできます。

データ量は 1バイト＝8ビット、1KB＝1024バイト、1MB＝1024KB で計算しています（ドリルの画面にも明記）。

## 安全のための設計

- 外部のサイトには一切接続しません（Content-Security-Policy で外部通信を禁止。ブラウザでの自動テストで外部リクエスト0件を確認）。
- 読み込んだ写真は、その画面の中で計算に使うだけで、保存・送信・書き出しのどれにも含まれません。
- マイクは「3秒録音する」を押したときだけ使い、3秒後に止めます。録音は保存せず、ページを離れると消えます。画面にプライバシーの注意を表示しています。

## 開発者向け

```
npm test        # データ量・2進数・圧縮・ドリルの計算テスト（Node.js 20以上）
npm run build   # dist/digitization-lab.html を作り直す
npm run serve   # http://localhost:8080/D-information/digitization-lab/ で確認（共通の枠 ../../shared/ を読むため、リポジトリのいちばん上から配る）
```

構成: `js/`（app.js=画面とルーティング, catalog.js=モジュール一覧, store.js=端末内保存, ui.js=共通部品, records.js=記録, digilib.js=計算）、`modules/`（各モジュール）、`sw.js`（オフライン用キャッシュ）。見た目は情報セキュリティ体験ラボと共通です。
