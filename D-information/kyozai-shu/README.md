# 情報の技術 体験教材集

6つの体験教材（デジタル化ラボ・仮想CPUラボ・ネットワーク通信シミュレータ・情報セキュリティ体験ラボ・双方向コンテンツ制作スタジオ・計測・制御シミュレータ）を、メニュー付きの1つのHTMLにまとめたもの。

作成：羽生市立南中学校　技術　岡田

## できあがったもの

できあがったものは、このフォルダではなく `D-information/` の `dist/` と `docs/` に置く。

- `../dist/情報の技術_体験教材集.html` … 生徒に配る1ファイル版（ダブルクリックで開く。インターネット不要）
- `../dist/情報の技術_体験教材集_第1.5版.zip` … 配布用。上のHTML、先生用の手引き2つ、個別の教材6ファイル、はじめにお読みください
- `../docs/先生用の手引き.html` … 教材集の使い方、学習指導要領との対応、重なる単元の使い分け（画面の例は `../docs/画面例/`）

## しくみ

- 各教材の1ファイル版（それぞれのフォルダの `dist/`）を、そのまま `iframe`（srcdoc）の中で開く。教材の中身は書きかえていない。
- 一度開いた教材は閉じずに隠すだけなので、メニューや別の教材に移っても作業は残る。
- 教材集のCSPは各教材と同じ（外部通信なし）。iframe には `allow="microphone *"` を付けて、デジタル化ラボの録音が使えるようにしている。
- 記録の保存場所（localStorage のキー）は教材ごとに別なので、まとめてもぶつからない。

## つぎはこれ（学習の案内）と見やすさの調整

教材集の中だけで、次の2つを足している（元の教材ファイルは変えない）。

- メニューの「つぎはこれ」: おすすめの順番（`data/materials.json` の materials の並び）で、まだ開いていない教材と前回のつづきを出す。開いた教材には ✓ がつく（このブラウザの localStorage `kyozai.seen.v1`）。
- 教材の中の「つぎはこれ」: ページの下に次の単元・場面へのボタンを出し、教材のさいごのページでは次の教材を開くボタンを出す。行き先は `data/materials.json` の `guides`、スクリプトは `src/guide.js`。教材にもともと同じ行き先の「次へ」ボタンがあるページでは出さない。
- 見やすさ: `src/assist.css` で、入力欄・進み具合のバーなどの線を背景との差 3:1 以上の色にし、いま開いているページの印に青い線を足す。上のバーの教材の切りかえは、はば1280px以上でアイコン＋短い名前、それより狭いと「教材をかえる ▾」の一覧（短い名前は materials.json の `short`）。

## ふりがな・大きな文字・記録のまとめ書き出し（第1.2版）

- 上のバーの「ふりがな」「大きな文字」は、メニューと6教材にまとめてかかる（localStorage `kyozai.prefs.v1`。全リセットでも残す）。
  - `src/display.js`: 教材にもともと同じボタンがあればそれを押し（ボタンは教材集の中では隠す）、なければ `html.large-text` を付ける。
  - `src/ruby.js`: ふりがなの辞書で漢字の言葉に `ruby.kz-ruby` を付ける。辞書は情報セキュリティ体験ラボの `data/ruby.json` ＋ `src/ruby-words.json`。入力欄・プログラム欄・図などは付けない（materials.json の `rubySkip`）。情報セキュリティ体験ラボは自分のふりがな（`ownRuby`）を使う。
- メニューの「記録をまとめて書き出す」: 組・番号・名前（`kyozai.student.v1`、全リセットで消す）を1回入れて、6教材の記録を1つの JSON／CSV にする。各教材の記録は resetKeys と `storagePrefix` から読むだけで、書きかえない。
- アドレスの `#/教材のid/中の場所`（例 `#/security-lab/teacher`）で、教材の中の場所を直接開ける。先生用ページを開くため。
- 教材ごとにさいごに開いていた中のページ（`#/crypto` など）を sessionStorage `kyozai.place.v1` に覚え、再読みこみのあとはそこを開く（SEC-23。このタブの中だけ。全リセットでも消す）。
- 学習指導要領との対応（materials.json の `tag` と `curriculum`）は、生徒向けのカードには出さず、メニューの「先生へ」に出す（KS-09）。

## 重なる単元

情報セキュリティ体験ラボの「デジタル化と情報量」「ネットワーク通信の模擬」は、どちらも残した。教材集の中で開いたときだけ、単元のさいご（ふりかえりのあと、「次へ」の前）に「もっとくわしく学びたいとき」の案内と白いボタンを出し、デジタル化ラボ／ネットワーク通信シミュレータ（「のぞき見と暗号化」）を開く。

- 案内から移った先では、ページの上と下に「← 情報セキュリティ体験ラボにもどる」を出す（`src/guide.js` の `kyozaiBack`。どこから来たかは shell.js が kyozai-open の `back` から覚える）。メニューや上のバーから開き直すと消える。
- 案内の文と行き先は `data/materials.json` の `bridges`
- 案内を出すスクリプトは `src/bridge.js`（ビルド時にセキュリティラボの写しの末尾に足す。元のファイルは変えない）

## 4分野共通の枠（第1.5版）

- 色・ヘッダー・ボタン・カード・フッターは、4分野で共通の `../../shared/eduit-frame.css` に合わせている（情報の技術は青 `#1a5fc8`）。
- 作成者・版・「安全と個人情報・ライセンス・更新履歴」のフッターとダイアログは `../../shared/eduit-frame.js`。版・更新履歴・この分野だけの安全の説明は `../eduit-info.js`（`window.EDUIT_INFO`）。
- `tools/build.mjs` がこの3つを教材集の中に入れる。6教材の1ファイル版にも、それぞれの `tools/build-standalone.mjs` が入れている（`../build/eduit-inline.mjs`）。
- メニューではいちばん下に共通のフッター、教材を開いているときは教材の中のいちばん下に同じフッターが出る（教材集のフッターはかくす）。
- 版を上げるときは、`../eduit-info.js` の version・updated・history、`tools/make-zip.py` の版、`../docs/先生用の手引き.html` を直し、6教材→教材集の順に作り直す。

## 作り直し方

教材を直したら、先にその教材のフォルダで `npm run build` してから、このフォルダで:

```
node tools/build.mjs        # ../dist/情報の技術_体験教材集.html を作る
python3 tools/make-zip.py   # ../dist/…_第1.5版.zip を作る（版は make-zip.py・../eduit-info.js・../docs/先生用の手引き.html の中）
node tests/e2e.browser.cjs  # ブラウザで確認（playwright が必要。94項目）
```

教材の並び・説明文・グループは `data/materials.json` で変えられる。

## ファイル

- `data/materials.json` … 教材の一覧、グループ、重なる単元の案内
- `src/shell.html` `src/shell.css` `src/shell.js` … メニューと切りかえバー
- `src/bridge.js` … 重なる単元の案内
- `src/guide.js` `src/assist.css` … つぎはこれの案内と見やすさの調整
- `src/hashlinks.js` … 教材の中のリンク（#/…）を教材集の中でも動かす。iframe の srcdoc では、そのままだと親のファイルのURLへ移ろうとして教材が「開けない」画面になるため（ビルド時に全教材の末尾に足す）
- `tools/build.mjs` `tools/make-zip.py` … ビルドと配布用ZIP
- `src/ruby.js` `src/display.js` `src/ruby-words.json` … ふりがなと大きな文字
- `tests/e2e.browser.cjs` … file:// で開いて、6教材が開く・戻れる・案内で移れる・書き出し・まとめ書き出し・ふりがな・マイク・外部通信なし・エラーなし を確認
