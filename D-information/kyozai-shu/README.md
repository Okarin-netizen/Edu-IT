# 情報の技術 教材集（kyozai-shu）

10の体験教材（D1 デジタル化ラボ・D2 仮想CPUラボ・D3 ネットワーク通信シミュレータ・D4 情報セキュリティ体験ラボ・D5 ネット詐欺 追体験ラボ・D6 双方向コンテンツ制作スタジオ・D7 計測・制御シミュレータ・D8 生成AIのしくみラボ・D9 ハッシュ化体験ラボ・D10 火星探査ロボット・シミュレータ）を、「基本編」「発展編」のタブのメニュー付きの1つのHTML（統一版）にまとめたもの。

作成：羽生市立南中学校　技術　岡田

## できあがったもの

できあがったものは、このフォルダではなく `D-information/` の `dist/` と `docs/` に置く。

- `../dist/情報の技術_体験教材集.html` … 生徒に配る1ファイル版（ダブルクリックで開く。インターネット不要）
- `../dist/情報の技術_体験教材集_第1.7版.zip` … 配布用。上のHTML、先生用ガイド2つ、個別の教材9ファイル（`個別の教材/D1_デジタル化ラボ.html` の形）、はじめにお読みください
- `../docs/先生用ガイド.html` … 教材集の配り方と開き方、教材の一覧（基本編・発展編）、重なる単元の使い分け、記録の提出（画面の例は `../docs/画面例/`）
- `../docs/情報セキュリティ体験ラボ_先生用ガイド.html` … 情報セキュリティ体験ラボの先生用ガイド
- 先生用ガイドは4分野で同じ章立て・見た目（`../../shared/eduit-guide.css`）。共通の CSS・JS を読むので、`tools/make-zip.py` が中に入れてから ZIP に入れる

## しくみ

- 各教材の1ファイル版（それぞれのフォルダの `dist/`）を、そのまま `iframe`（srcdoc）の中で開く。教材の中身は書きかえていない。
- 一度開いた教材は閉じずに隠すだけなので、メニューや別の教材に移っても作業は残る。
- 教材集のCSPは各教材と同じ（外部通信なし）。iframe には `allow="microphone *"` を付けて、デジタル化ラボの録音が使えるようにしている。
- 記録の保存場所（localStorage のキー）は教材ごとに別なので、まとめてもぶつからない。

## メニューと上のバー（第1.7版。4分野共通の形）

- 記号: `data/materials.json` の各教材の `code`（D1〜D10）。番号の順 = おすすめの順 = materials の並び = カードの順。`id`・`storagePrefix` には記号を入れていない。
- メニューの上のバー: 左に「D 情報の技術 教材集」（`EduitFrame.menuTitle`）、右に「ふりがな」「文字 中」（文字の大きさ。押すと「文字 大」）「先生用」（メニューの下の先生用のところへ移る）。D には「使い方」のページがないので、そのボタンはない。
- カード: `EduitFrame.card`（記号・アイコン・名前・説明・使うところ・「ひらく ▶」）。アイコンは教材の SVG を入れる。開いたことのある教材は「✓ 開いたことがある」（localStorage `kyozai.seen.v1`）。
- 基本編の上に「おすすめの順番: D1 → D2 → … → D8」の1行（`EduitFrame.levels` の `code`）。上の説明の下に「前回のつづき」の1行。
- メニューの下の順: 基本編・発展編のカード → 記録（記録をまとめて書き出す・はじめからやり直す）→ 先生用。
- 教材を開いたときの上のバー: 「◀ メニュー」＋「D2 仮想CPUラボ」（記号の印＋名前）、右に「ふりがな」「文字 中」と教材の切りかえ。切りかえは、はば1280px以上で「D2 CPU」のような記号の印＋短い名前（materials.json の `short`）、それより狭いと「教材をかえる ▾」で記号と名前の一覧。
- 各ラボを1つずつ開いたときも、ラボの上のバーの名前に記号が出る（各ラボの `index.html` と `<meta name="eduit-app">`）。

## 教材の中の「つぎはこれ」と見やすさの調整

教材集の中だけで、次の2つを足している（元の教材ファイルは変えない）。

- 教材の中の「つぎはこれ」: ページの下に次の単元・場面へのボタンを出し、教材のさいごのページでは次の教材（「つぎの教材「D2 仮想CPUラボ」を開く」）のボタンを出す。行き先と名前（①②… の番号つき）は `data/materials.json` の `guides`、スクリプトは `src/guide.js`。教材にもともと同じ行き先の「次へ」ボタンがあるページでは出さない。
- 見やすさ: `src/assist.css` で、入力欄・進み具合のバーなどの線を背景との差 3:1 以上の色にし、いま開いているページの印に青い線を足す。

## ふりがな・大きな文字・記録のまとめ書き出し（第1.2版）

- 上のバーの「ふりがな」「文字 中」は、メニューとすべての教材にまとめてかかる（localStorage `kyozai.prefs.v1`。全リセットでも残す）。
  - `src/display.js`: 教材にもともと同じボタンがあればそれを押し（ボタンは教材集の中では隠す）、なければ `html.large-text` を付ける。
  - `src/ruby.js`: ふりがなの辞書で漢字の言葉に `ruby.kz-ruby` を付ける。辞書は情報セキュリティ体験ラボの `data/ruby.json` ＋ `src/ruby-words.json`。入力欄・プログラム欄・図などは付けない（materials.json の `rubySkip`）。情報セキュリティ体験ラボは自分のふりがな（`ownRuby`）を使う。
- メニューの「記録をまとめて書き出す」: 組・番号・名前（`kyozai.student.v1`、全リセットで消す）を1回入れて、すべての教材の記録を1つの JSON／CSV にする。各教材の記録は resetKeys と `storagePrefix` から読むだけで、書きかえない。
- アドレスの `#/教材のid/中の場所`（例 `#/security-lab/teacher`）で、教材の中の場所を直接開ける。先生用ページを開くため。
- 教材ごとにさいごに開いていた中のページ（`#/crypto` など）を sessionStorage `kyozai.place.v1` に覚え、再読みこみのあとはそこを開く（SEC-23。このタブの中だけ。全リセットでも消す）。
- 学習指導要領との対応（materials.json の `tag` と `curriculum`）は、生徒向けのカードには出さず、メニューの下の「先生用」に出す（KS-09）。
- 記録まとめの JSON は `app: "情報の技術 教材集"`・`kind: "記録まとめ"`。ページの名前（`page`）は materials.json の `recordNames`（新しい ①②… の番号つき）から付ける。

## 重なる単元

情報セキュリティ体験ラボの「① デジタル化と情報量」「⑤ ネットワーク通信の模擬」は、どちらも残した。教材集の中で開いたときだけ、単元のさいご（ふりかえりのあと、「次へ」の前）に「もっとくわしく学びたいとき」の案内と白いボタンを出し、D1 デジタル化ラボ／D3 ネットワーク通信シミュレータ（「④ のぞき見と暗号化」）を開く。

- 案内から移った先では、ページの上と下に「← 情報セキュリティ体験ラボにもどる」を出す（`src/guide.js` の `kyozaiBack`。どこから来たかは shell.js が kyozai-open の `back` から覚える）。メニューや上のバーから開き直すと消える。
- 案内の文と行き先は `data/materials.json` の `bridges`
- 案内を出すスクリプトは `src/bridge.js`（ビルド時にセキュリティラボの写しの末尾に足す。元のファイルは変えない）

## 基本編・発展編と、3つのラボ（第1.6版）

- メニューの教材カードは、共通の枠の `EduitFrame.levels`（`../../shared/eduit-frame.js`）で「基本編」「発展編」のタブに分けて出す。分け方は `../eduit-info.js` の `levels`（教材の id・その編で使うページの名前 `parts`・学習指導要領 `curr`・理由 `why`）。1つの教材が両方の編に出てもよい。カードには `parts` を「使うところ」として出し、`curr` は出さない（KS-09）。選んだ編は localStorage `eduit.level.D`（表示の設定なので全リセットでも残す）。
- 生成AIのしくみラボ・ネット詐欺 追体験ラボ・ハッシュ化体験ラボも materials に入れた。この3つは記録を1つのキー（`eduit-genai-lab` など。`storagePrefix` と同じ）に入れ、ふりかえりは `refl` に問いの id（r1〜r3）ごとに入る。まとめ書き出しでは `reflNames` で問いの名前（振り返り一覧の名前と同じ）を `question` に入れ、`page` は空にする（1つずつの書き出しと同じ行として振り返り一覧で1行になる）。
- 3つのラボはページを `#guess` のように「/」なしで切りかえるので、`plainHash: true` を付け、`src/hashlinks.js` でその形のリンクも教材の中で移れるようにしている。
- 全リセットでは、3つのラボのキーのうち `resetKeep` にある表示の設定（ふりがな `furigana`・大きな文字 `big`）だけを残す（各ラボの「はじめからやり直す」と同じ）。

## 4分野共通の枠（第1.5版）

- 色・ヘッダー・ボタン・カード・フッターは、4分野で共通の `../../shared/eduit-frame.css` に合わせている（情報の技術は青 `#1a5fc8`）。
- 作成者・版・「安全と個人情報・ライセンス・更新履歴」のフッターとダイアログは `../../shared/eduit-frame.js`。版・更新履歴・この分野だけの安全の説明は `../eduit-info.js`（`window.EDUIT_INFO`）。
- `tools/build.mjs` がこの3つを教材集の中に入れる。各教材の1ファイル版にも、それぞれの `tools/build-standalone.mjs` が入れている（`../build/eduit-inline.mjs`）。
- メニューではいちばん下に共通のフッター、教材を開いているときは教材の中のいちばん下に同じフッターが出る（教材集のフッターはかくす）。
- 版を上げるときは、`../eduit-info.js` の version・updated・history、`tools/make-zip.py` の版、`../docs/先生用ガイド.html` の 7. 更新履歴を直し、各教材→教材集の順に作り直す。

## 作り直し方

教材を直したら、先にその教材のフォルダで `npm run build` してから、このフォルダで:

```
node tools/build.mjs        # ../dist/情報の技術_体験教材集.html を作る
python3 tools/make-zip.py   # ../dist/…_第1.7版.zip を作る（版は make-zip.py・../eduit-info.js・../docs/先生用ガイド.html の中。古い版の zip は消す）
node tests/e2e.browser.cjs  # ブラウザで確認（playwright が必要。135項目）
```

教材の並び・記号（`code`）・説明文は `data/materials.json` で変えられる。並びを変えたら `code` の番号も付け直す（番号の順 = おすすめの順）。

## ファイル

- `data/materials.json` … 教材の一覧（記号 `code`・短い名前 `short`・記録のページ名 `recordNames`）、教材の中の案内 `guides`、重なる単元の案内 `bridges`
- `src/shell.html` `src/shell.css` `src/shell.js` … メニューと切りかえバー
- `src/bridge.js` … 重なる単元の案内
- `src/guide.js` `src/assist.css` … 教材の中の「つぎはこれ」の案内と見やすさの調整
- `src/hashlinks.js` … 教材の中のリンク（#/…）を教材集の中でも動かす。iframe の srcdoc では、そのままだと親のファイルのURLへ移ろうとして教材が「開けない」画面になるため（ビルド時に全教材の末尾に足す）
- `tools/build.mjs` `tools/make-zip.py` … ビルドと配布用ZIP
- `src/ruby.js` `src/display.js` `src/ruby-words.json` … ふりがなと大きな文字
- `tests/e2e.browser.cjs` … file:// で開いて、上のバーの名前・カードの記号と順・おすすめの順番の1行・メニューの下の順・基本編・発展編のタブ・9教材が開く・戻れる・案内で移れる・書き出し・まとめ書き出し・ふりがな・マイク・外部通信なし・エラーなし を確認
