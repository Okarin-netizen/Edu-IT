# D4 情報セキュリティ体験ラボ

作成：技術 岡田

中学校技術・家庭科（技術分野）D「情報の技術」向けの体験教材です。計画書 [`../review/計画/plan-4-security-lab.md`](../review/計画/plan-4-security-lab.md)（学習指導要領との照合の付録を含む）の全11モジュールと、理解度チェック・先生用設定・ふりがな表示まで実装しています。モジュールは指導要領の言葉にそって「情報のデジタル化と情報量」「情報セキュリティのしくみ」「サイバーセキュリティ」「情報モラル・知的財産・発信の責任」「まとめ」の5つのまとまりと、最後の「発展（先生に言われたら）」で並んでいます。

## すぐに使う

- **いちばん簡単**: `dist/security-lab.html` をダブルクリックしてブラウザで開くだけ。1つのファイルなので、USBメモリや校内の共有フォルダで配れます。インターネット接続は不要です。
- **PWAとして配信する場合**: このフォルダ全体を校内のWebサーバーに置き、`index.html` を開きます。一度開くと端末にキャッシュされ、オフラインでも動きます（ホーム画面に追加も可）。
- **先生用ガイド**: [`../docs/情報セキュリティ体験ラボ_先生用ガイド.html`](../docs/情報セキュリティ体験ラボ_先生用ガイド.html)（7時間の計画など）。

## 中身

教材集での記号は **D4**。アプリの番号は、画面の上から順の通し番号です（①〜⑩ が基本編、⑪ ハッシュ体験が発展編。第1.7版でハッシュ体験を最後へ移したので、計画書の番号とはちがいます）。

| # | モジュール | 内容 | 目安 |
|---|---|---|---|
| ① | デジタル化と情報量 | 画像の解像度・階調、音の標本化・量子化（音も聞ける）、ランレングス圧縮と可逆・非可逆、データ量の計算 | 15〜20分 |
| ② | パスワード強度ラボ | 解読時間の表示、長さ×文字種のグラフ、パスフレーズ作り、クイズ | 15分 |
| ③ | 暗号ラボ | シーザー暗号 → 総当たり → 頻度分析 → ヴィジュネル暗号 → 鍵の受け渡し → 小さな素数でRSA | 15〜30分 |
| ④ | フィッシング見分け（サイバーセキュリティ） | 5つの場面（SMS・銀行メール・ゲームのログイン画面・本物の注文メール・SNSのDM） | 15分 |
| ⑤ | ネットワーク通信の模擬（サイバーセキュリティ） | HTTP と HTTPS で送りくらべ、のぞき見に見えるものをアニメで比較 | 10〜15分 |
| ⑥ | SNS投稿の個人情報チェック | 写真と文章から手がかり探し、情報の組み合わせ、安全な投稿への直し方 | 15分 |
| ⑦ | デジタルタトゥー | 拡散シミュレーション、削除してもコピーが残る体験、発信者としての責任（投稿・再投稿） | 10〜15分 |
| ⑧ | 著作権・利用ルールクイズ | 6つの場面の分岐クイズ（歌詞・レポート・録画・フリー素材・写真・授業）、発信者としての責任と知的財産権 | 15分 |
| ⑨ | 判断ロールプレイ | 4つの分岐ストーリー（知らない人のDM・アプリの権限・パスワードを聞かれた・知ってしまった） | 15分 |
| ⑩ | まとめ・行動宣言 | 3つの対策を選んで宣言、印刷できる宣言カード | 10〜15分 |
| ⑪ | ハッシュ体験（発展編） | なだれ効果、固定長・一方向、改ざんの見つけ方、パスワードのハッシュ保存 | 10〜15分 |

共通の機能:

- 章ナビ、進み具合、解説カード、「立ち止まる→確認する→相談する」の3ステップ、各モジュールのふりかえり
- **理解度チェック**: 事前テスト・事後テスト（各モジュール1問・計11問、同じ問題で伸びを比較）、練習（選んだモジュールから1回10問まで）、まちがえた問題だけの復習。まちがえた問題からは、そのステップへ直接戻れます。選択肢の順番は毎回入れかわります。
- **ふりかえり・記録**: JSON/CSVへの書き出し（事前・事後テストの結果も含む）
- **先生用ページ**（章ナビには出さない。アドレスの最後に `#/teacher` を付けて開く）: 生徒のJSONを複数読み込んで集計（完了人数、事前・事後の平均正答率、両方を受けた生徒の伸び）、設定（使うモジュール、表示、攻撃速度の初期値）、問題データの差し替え
- **表示の切りかえ**: ふりがな、やさしい日本語のまとめ、大きな文字（画面右上のボタン）

## 安全のための設計

- 外部のサイトには一切接続しません（Content-Security-Policy で外部通信を禁止。ブラウザでの自動テストで外部リクエスト0件を確認）。
- パスワード強度ラボやハッシュ体験で入力した文字は、保存・送信・書き出しのどれにも含まれません（自動テストで確認）。
- フィッシングや通信の模擬に出る会社名・アドレスはすべて架空で、アドレスは例示用に予約された `.example` だけを使っています。SNSの写真もイラストで、地名・学校名は架空です。
- RSAや通信の暗号は、しくみを見せるための模型であることを画面に明記しています。攻撃に使えるツールは含みません。

## 問題や設定を変える

方法は2つあります。

1. **先生用ページから（その端末だけ）**: 「今のデータを書き出す」→ 編集 →「読み込んで差し替える」。設定は「この端末に反映」。
2. **ファイルで（配布するすべての端末）**: `data/` の JSON を編集し、単一HTML版を使う場合は `npm run build` で作り直します。先生用ページの「設定ファイルを書き出す」でできた `config.json` を `data/` に置けば、設定も配布できます。

| ファイル | 中身 |
|---|---|
| `config.json` | 使うモジュール、ふりがな・やさしい日本語・大きな文字の初期値、名前を入力させるか、攻撃速度の初期値 |
| `quiz.json` | 理解度チェックの問題（`core: true` が事前・事後テスト用） |
| `phishing.json` | フィッシングの場面（`suspicious: true` が怪しい点） |
| `copyright.json` / `roleplay.json` | 著作権クイズ・ロールプレイの分岐 |
| `crypto.json` | 頻度分析で解く文章、RSAで選べる素数 |
| `common-passwords.json` / `passphrase-words.json` | パスワード辞書、パスフレーズ用の単語 |
| `ruby.json` | ふりがなを付ける言葉と読み |
| `consult.json` | 相談窓口（年度ごとに公式ページで番号と受付時間を確かめて直す） |

## 開発者向け

```
npm test        # 暗号・パスワード計算の既知ベクタと、教材データの整合性のテスト（Node.js 20以上）
npm run build   # dist/security-lab.html を作り直す
npm run serve   # http://localhost:8080/D-information/security-lab/ で確認（共通の枠 ../../shared/ を読むため、リポジトリのいちばん上から配る）
```

構成: `js/`（app.js=画面とルーティング, catalog.js=モジュール一覧, store.js=端末内保存, ui.js / branch.js=共通部品, settings.js=設定とふりがな, check.js=理解度チェック, records.js=記録と先生用ページ, cryptolib.js / passwordlib.js=計算）、`modules/`（各モジュール）、`data/`（問題と設定）、`sw.js`（オフライン用キャッシュ）。
