# D11 問題解決ノート

中学校技術・家庭科（技術分野）D「情報の技術」の、問題解決の **はじめ**（問題の発見と課題の設定）と **おわり**（評価、改善・修正）、4編4章1「情報の技術の最適化」で使うノートです。A〜D の4分野で同じ形のノート（`../../shared/mondai-note/`）を、情報の技術の観点と例で使います。

## すぐに使う

- `dist/問題解決ノート.html` をダブルクリックしてブラウザで開くだけ。1つのファイルで、インターネット接続は不要です。
- 教材集（`../dist/情報の技術_体験教材集.html`）の中では **D11**。1つずつ配るときは `クラスルーム配布/生徒に配る/1つずつ配るとき/D11_問題解決ノート.html`。

## ページ

| ページ | 教科書 | 内容 |
|---|---|---|
| はじめに | | ノートの使い方、組・番号・名前 |
| ① 問題の発見（基本） | 4編2章・3章「2 問題の発見と課題の設定」 | 「不便だな」を付箋に集める（社会・安全・環境・経済のアイコン）、「問題?課題?」クイズ、課題の設定 |
| ② 評価、改善・修正（基本） | 4編2章・3章「5 問題解決の評価、改善・修正」 | 機能・使いやすさ・安全性・他者の権利・費用・環境への配慮を5段階で評価、目標とレーダーチャートでくらべる、制作の過程の振り返り、改善・修正 |
| ③ 技術の最適化（発展） | 4編4章1 | スマートフォンのロック・車の運転・動画の配信の3つの案を、重みと制約条件を変えてくらべる |
| 振り返り（基本） | | 自己評価・学んだこと・次に生かすこと |
| 記録 | | 印刷（A4 の問題解決シート）、ファイルに書き出す・読みこむ、消す |

D6・D7・D8 の **制作の前** に ①、**制作のあと** に ② を開きます。

- 端末内保存のキー: `mondainote.v1`
- 書き出し: `問題解決ノート_情報_<組>_<番号>_<名前>.json`（`{app:'問題解決ノート', version:1, student, note}`）。振り返り一覧（`teacher-tools/furikaeri-ichiran/`）で読めます。

## 開発者向け

```
npm run build   # dist/問題解決ノート.html を作る（../../shared/mondai-note/ を中に入れる）
npm run serve   # http://localhost:8080/D-information/mondai-note/ （リポジトリのいちばん上から配る）
```

ノートの中身（画面・データ・印刷）は `../../shared/mondai-note/` にあります。この教材が持っているのは `js/app.js`（ページの切りかえ・保存・書き出し）と `css/style.css` だけです。共通のノートを直したら、この教材を `npm run build` で作り直し、教材集（`../kyozai-shu/`）も作り直してください。
