# D 情報の技術

中学校技術・家庭科（技術分野）D「情報の技術」の体験教材です。どれもインターネットにつながずに、ブラウザだけで動きます。

作成：技術　岡田

## 生徒に配るもの・先生が読むもの

- `dist/情報の技術_体験教材集.html` … 9つの教材を「基本編」「発展編」のメニュー付きの1つのファイルにまとめたもの（統一版「情報の技術 教材集」。生徒に配る）
- `dist/情報の技術_体験教材集_第1.7版.zip` … 配布用のまとめ（上のHTML、先生用ガイド2つ、個別の教材9つ（`D1_デジタル化ラボ.html` 〜 `D9_ハッシュ化体験ラボ.html`）、はじめにお読みください）
- `dist/生成AIのしくみラボ.html` … 生成AIのしくみラボの1ファイル版（教材集にも入っている。これだけを配りたいとき）
- `dist/ネット詐欺_追体験ラボ.html` … ネット詐欺 追体験ラボの1ファイル版（教材集にも入っている。これだけを配りたいとき）
- `dist/ハッシュ化体験ラボ.html` … ハッシュ化体験ラボの1ファイル版（教材集にも入っている。これだけを配りたいとき）
- `docs/先生用ガイド.html` … 教材集の配り方と開き方、教材の一覧（基本編・発展編）、単元での使い方、記録の提出（画面の例は `docs/画面例/`）。4分野で同じ章立て・見た目（`../shared/eduit-guide.css`）
- `docs/情報セキュリティ体験ラボ_先生用ガイド.html` … 情報セキュリティ体験ラボの詳しい先生用ガイド

## 記号と番号

9つの教材には D1〜D9 の記号があります（`kyozai-shu/data/materials.json` の `code`）。番号の順 = おすすめの順 = メニューのカードの順です。
フォルダ名・保存名（localStorage のキー）・`materials.json` の `id` には記号を入れていません。
教材の中のページは、基本編のページから順に ①②③…、発展編のページはそのあとの続きの番号です（「はじめに」「ふりかえり・記録」「理解度チェック」には番号なし。双方向コンテンツ制作スタジオのタブは番号なし）。

| 記号 | 教材 | 基本編 | 発展編 |
|---|---|---|---|
| D1 | デジタル化ラボ | ①〜④ | ⑤ 圧縮のしくみ |
| D2 | 仮想CPUラボ | ① 図解・② 手計算くらべ | ③ 仮想CPUを動かす・④ 課題 |
| D3 | ネットワーク通信シミュレータ | ①〜④ | ⑤ IPアドレス・ドリル |
| D4 | 情報セキュリティ体験ラボ | ①〜⑩・理解度チェック | ⑪ ハッシュ体験 |
| D5 | ネット詐欺 追体験ラボ | ①〜⑥ | ― |
| D6 | 双方向コンテンツ制作スタジオ | 全部のタブ | ― |
| D7 | 計測・制御シミュレータ | ①〜④ | ⑤ 自由に作る |
| D8 | 生成AIのしくみラボ | ①〜③ | ④〜⑧ |
| D9 | ハッシュ化体験ラボ | ― | ①〜⑦ |

## 基本編と発展編

教材集のメニューは「基本編」「発展編」のタブに分かれています。どのページがどちらに入るかは `eduit-info.js` の `levels` にあり、
学習指導要領の項目と理由つきの一覧は `../teacher-tools/kihon-hatten/`（`クラスルーム配布/先生用/全分野_基本編と発展編(先生用).html`）です。
教材を足したときは `kyozai-shu/data/materials.json` と `levels` の両方に入れてください。

## 作り直す順番

教材を直したら、次の順に作り直します（Node.js 20以上。ブラウザのテストには playwright が必要）。

```
# 1. 直した教材のフォルダで（例: security-lab）
npm test             # 点検
npm run build        # dist/ の1ファイル版を作る（genai-lab・scam-lab・hash-lab は ../dist/ の配布用も作る）

# 2. kyozai-shu で
node tools/build.mjs        # ../dist/情報の技術_体験教材集.html を作る
node tests/e2e.browser.cjs  # ブラウザで確認

# 3. kyozai-shu で（配布用ZIP）
python3 tools/make-zip.py   # ../dist/情報の技術_体験教材集_第1.7版.zip を作る
```

`kyozai-shu` は兄弟のフォルダ（`security-lab/` など）と `docs/` を読むので、`D-information/` の中はまとめて動かしてください。共通の枠は `../shared/` にあります。
