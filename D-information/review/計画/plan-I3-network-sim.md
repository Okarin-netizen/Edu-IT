# 実装計画 I3「ネットワーク通信シミュレータ」

## 1. 概要
- **教科書・指導要領との対応**: 情報の技術 4章「情報通信ネットワークの仕組み」。指導要領 D(2)ア『情報通信ネットワークの構成と、情報を利用するための基本的な仕組み』
- **ねらい**: パケット通信、IPアドレス、DNS、サーバとクライアントなどの仕組みを、模擬的なネットワークで体験する。
- **形態**: PWA(Service Worker+IndexedDB)の単一Webアプリ。外部通信なし、オフライン完結。共通基盤は [README.md](README.md) を参照。
- **関連**: I4、I5

## 2. 機能要件
### MVP
1. ネットワーク構築: PC・スマホ・ルータ・サーバ・DNSをドラッグ配置して配線
2. 通信の可視化: Webページを見る操作で、DNS問い合わせ→IP→パケット分割→経路→組み立てをアニメ表示
3. 障害体験: 回線を切る/ルータを止める → 別経路・到達不能の確認
4. 盗聴者モード: 暗号化なし/ありで、途中の通信者に見える内容を比較(HTTP/HTTPS)
5. IPアドレス・サブネットの基礎ドリル
### 発展
- Wi-Fi・無線LANのセキュリティ(パスワード・暗号化方式)の比較
- 遅延・帯域のゲーム(混雑でパケットが遅れる)

## 3. 技術設計
- グラフ構造+最短経路(ダイクストラ)
- パケットはキューで簡易表現
- すべてブラウザ内の仮想世界(実ネットワークに触れない)

## 4. 画面構成
- 構築 / 通信アニメ / 障害・盗聴 / ドリル

## 5. 受け入れ基準・テスト
- 経路が切れた場合に迂回する/到達不能となる挙動が正しい
- 外部への通信が発生しない

## 6. リスクと対策
- 現実の脅威を詳細に教えすぎない → 概念レベルに留める
