# 実装計画 I2「コンピュータの仕組み(仮想CPU)」

## 1. 概要
- **教科書・指導要領との対応**: 情報の技術 2章「コンピュータの仕組み」(入力・記憶・演算・制御・出力)
- **ねらい**: プログラムがどのようにコンピュータ内で処理されるかを、可視化して理解する。
- **形態**: PWA(Service Worker+IndexedDB)の単一Webアプリ。外部通信なし、オフライン完結。共通基盤は [README.md](README.md) を参照。
- **関連**: I6

## 2. 機能要件
### MVP
1. 5大装置の図: 入力→記憶→演算→制御→出力のデータの流れをアニメ表示
2. 仮想CPU: 8命令程度の簡単な命令セット(LOAD/ADD/SUB/STORE/JUMP/JZ/OUT/HALT)をステップ実行
3. レジスタ・メモリの値をリアルタイム表示、実行中の命令をハイライト
4. 課題: 足し算、1から10までの合計、最大値探しなどをプログラムする
5. 『処理の自動化』の体験: 手計算 vs プログラム
### 発展
- アセンブリ風→ブロック風→Pythonライク言語の対応表示
- クロック速度と実行時間の疑似表示

## 3. 技術設計
- JS実装の小型VM(数百行)
- メモリ16〜32語
- 命令表はJSON

## 4. 画面構成
- 図解 / ステップ実行 / 課題

## 5. 受け入れ基準・テスト
- 各命令の動作が仕様どおり(単体テスト)
- 無限ループは自動停止

## 6. リスクと対策
- 難しすぎる → 段階的な課題と、部分的に完成済みのプログラムから始める
