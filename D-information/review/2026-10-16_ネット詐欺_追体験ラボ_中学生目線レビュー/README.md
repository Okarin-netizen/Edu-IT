## 確かめて問題がなかった所

- 5つの場面は、どれもやることリストを全部やるとクリアでき、手順を飛ばして最後の行動をしてもクリアにならない(`npm test`)。
- だまされたあと「その前の場面にもどって、やり直す」で、それまでの ✓ が残る。
- 書き出した JSON は、組・番号・名前が入り、振り返り一覧(先生用)で読める。「はじめからやり直す」で記録が消え、ふりがな・文字の大きさは残る。
- 1366×650・810×1080・390×800(大きな文字でも)で、横にはみ出さない。外部への通信は0件。
