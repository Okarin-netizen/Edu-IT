# 生成AIのしくみラボ 中学生目線レビューと改善計画（2026-10-15）

`D-information/genai-lab/dist/genai-lab.html`（初版）を、中学2年生になったつもりで全8ステップ操作して確かめた記録と、改善計画です。

- **やり方**: Chromium で開き、ノートPC 1366×650 と タブレット縦 810×1080（指の操作）で全ページを操作した。生徒3人の目で見た: Aさん（読むのが苦手）、Bさん（ふつう）、Cさん（早く進む）。
- **重要度**: A＝まちがい・授業のねらいがくずれる・授業が止まる。B＝多くの生徒がつまずく・迷う。C＝直すともっとよくなる。
- **状態**: 28件すべてを 2026年10月15日に直しました。直した所は `genai-lab/tests/e2e.browser.cjs`（ブラウザの自動テスト39項目）で確かめています。
- **件数**: 28件（A 3・B 15・C 10）。重要度Aの3件は、画面とソースでもう一度再現して確かめた。

## いちばん大きい問題（先に直す）

1. **ボタンを押すたびに、画面がいちばん上にもどる（GL-01）**。クイズのQ6を押すと、スクロール位置が 1490 → 0 になった（PC・タブレットとも）。AIの答えチェック、送る前チェック、ミニ文章AIの候補の言葉でも同じ。長いページほど、押したあとに自分の場所を見失う。原因は、押すたびにページ全体を作り直して `scrollTo(0,0)` していること（`js/app.js` の `go()`）。
2. **クイズ8問の正解が、すべて2番目（GL-02）**。Cさんは2問目あたりで気づき、読まずに2番目を押すようになる（`js/data.js` の `quiz` の `c` がすべて 1）。
3. **ハルシネーションの体験で、自分で考える前に答えが出ている（GL-03）**。「文を10本つくる」を押すと、本当/まちがいを押す前から下に「新しい文はどれも事実ではありません」と表示される。

## 改善計画

### 第1段　授業で使う前に必ず直す（7件: GL-01〜07）

- **1-A 押しても場所がとばない（GL-01・GL-04）**: ステップの中の操作では、ページを作り直してもスクロール位置とフォーカスを保つ（`go()` を「ページの移動」と「同じページの描き直し」に分ける）。メニューやつぎへで移ったときだけ上にもどす。
- **1-B クイズの答えの位置（GL-02）**: 正解の位置を問題ごとにばらばらにする（データの並びを変える）。テストに「正解の位置が全部同じでない」を足す。
- **1-C 自分で考えてから答え（GL-03）**: ハルシネーションAのまとめは、新しい文をすべて判定したあとに出す。
- **1-D 押せる所を押せるように見せる（GL-05・GL-06・GL-07）**: AIの答えの文に点線の枠と「あやしい文をおしてね」の印。「AIに送る」のあと②へ自動で移る。はじめの「AIの予想」に「まだ予想していません」と出す。

### 第2段　多くの生徒がつまずく所（11件: GL-08〜18）

- **2-A 記録を出せる（GL-08）**: ほかの教材と同じ「記録を書き出す」（クイズの点数・ふりかえり・名前）を付ける。
- **2-B ふりがな（GL-09）**: 体験教材集と同じしくみで、むずかしい言葉全部にふりがなを付ける。
- **2-C ハルシネーションAを短く（GL-10・GL-11）**: 作る文を5本にし、判定は「新しい文」から3本だけ。このページでは1語/2語の切りかえを出さない。
- **2-D ミニ文章AIの説明（GL-12〜14）**: 文のはじめは「はじめの言葉」のボタンだけにする。表の上に「○回 → ランダムさをかけて → えらばれる割合」の1行。スライダーを動かすあいだも割合を変える。
- **2-E 画像AIと個人情報の言葉（GL-15〜17）**: まぜたときは「ねこ○%・家○%がまざった絵」と出す。送ったあとに「入れる情報を変える」ボタンを①に置く。「直す」→「送らない（直す）」。
- **2-F 文字の大きさ（GL-18）**: いちばん小さい文字を 14px 以上にする。

### 第3段　直すともっとよくなる（10件: GL-19〜28）

- 「文のおわりまで自動」を1語ずつ表示（GL-19）。トークンの「知らないかけら」の説明を足す（GL-20）。プロンプトの番号に「ステップ2のトークン」へのリンク（GL-21）。
- タブレット縦のメニューを2段に折り返す（GL-22）。メニューに「やった」印（GL-23）。作った文・クイズの答えも端末に保存（GL-24）。
- ノイズの大きい絵を 200px にする（GL-25）。おすすめのはじめの言葉に印（GL-26）。できあがったら「1ステップ進める」を止める（GL-27）。割合の例を、表の見出しに入れる（GL-28）。

## 直すときの手順

1. 段ごとに直し、`D-information/genai-lab` で `npm test` を通す。重要度Aには、もどってこないことを確かめるテストを足す（スクロール位置はブラウザの自動テストで確かめる）。
2. `npm run build` で `dist/genai-lab.html` を作り直し、`クラスルーム配布/生徒に配る/D_生成AIのしくみラボ.html` にコピーする。
3. 生徒の役で、1366×650 とタブレット縦で直した所をもう一度操作する。
4. 配る前に、先生が学校の端末で一度開いて確かめる。
