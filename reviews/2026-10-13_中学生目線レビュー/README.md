## レビューのやり方

- 配布ファイルを Chromium で開き、メニューから6教材の全ページを操作した。画面の大きさは ノートPC 1366×650、タブレット横 1080×810、タブレット縦 810×1080（指の操作）。
- 生徒3人の目で見た: Aさん（読むのが苦手）、Bさん（ふつう）、Cさん（早く進む）。
- 重要度: A＝まちがい・先に進めない・授業が止まる。B＝多くの生徒がつまずく・迷う。C＝直すともっとよくなる。
- 重要度Aは、すべてソースと画面でもう一度再現して確かめた。
- ふりかえりが消える件（DL-06・NW-06・MC-07・IS-10）は、6教材に共通の問題として A にそろえた。担当者の判定は B。

## 直るまでの注意（第1版を使う場合。第1.1版からは不要）

- 双方向コンテンツ制作スタジオは、教材集を開き直すと作品・企画メモ・ふりかえりが消える（IS-01）。直るまでは、授業の終わりに「JSONで保存」、次の時間の始めに「ファイルから読み込む」をさせる。開き直した直後に「元に戻す」を押さないことも伝える（IS-02）。
- どの教材も、ふりかえりは「保存」を押してからページを移るよう声をかける。

## 直すときの手順（計画が決まったあと）

1. 教材ごとに直し、その教材のフォルダで `npm test` を通す。Aの指摘には、同じ不具合がもどってこないことを確かめるテストを足す。
2. その教材で `npm run build`。続けて `kyozai-shu` で `node tools/build.mjs` と `python3 tools/make-zip.py` を実行し、dist の html を release/ にコピーして、`node tests/e2e.browser.cjs`（48項目）を通す。
3. 生徒の役で、上の3つの画面の大きさで直した所をもう一度操作し、直す前と後の画面をくらべる。
4. 配る前に、先生が学校の端末で一度開いて確かめる。
