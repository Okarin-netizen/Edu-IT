# 計測・制御シミュレータ

作成：羽生市立南中学校 技術 岡田

中学校技術・家庭科（技術分野）D「情報の技術」の「計測・制御のプログラミングによる問題解決」向けの教材です。センサ（計測）の値に応じてアクチュエータ（制御）を動かすプログラムを、実機がなくても画面の中の仮想世界で作り、想定したケースで自動テストして、改善を記録できます。計画書 I6 の MVP（自動ドア・信号機・街灯）を実装しています。

## すぐに使う

- **いちばん簡単**: `dist/計測制御シミュレータ.html` をダブルクリックしてブラウザで開くだけ。1つのファイルなので、USBメモリや校内の共有フォルダで配れます。インターネット接続は不要です。
- **PWAとして配信する場合**: このフォルダ全体を校内のWebサーバーに置き、`index.html` を開きます。一度開くと端末にキャッシュされ、オフラインでも動きます。

## 場面

| # | 場面 | 使うもの | テスト |
|---|---|---|---|
| 1 | 街灯 | 明るさセンサ → 街灯のLED | 夕方→夜、夜→朝、★夜に車のライトが当たる（そのあと朝に消えるかも確かめる） |
| 2 | 自動ドア | 距離センサ → ドアのモーター（開く/閉じる/止める） | 人が通りぬける、だれも来ない、店の前を通りすぎる（早く開きすぎ）、ドアの前で立ち止まる。しきい値 約105〜245cm で全部合格 |
| 3 | 信号機（時間で切りかえ） | （センサなし）タイマー → 車用3灯・歩行者用2灯 | 1分間うごかす（順番・黄3秒以上・歩行者の青4秒以上・全赤1秒以上・「危ない！」がない・くり返す など） |
| 4 | 押しボタン式信号機 | 押しボタン → 車用3灯・歩行者用2灯 | 押さない、1回押す、2回押す（どれも歩行者の青4秒以上・全赤1秒以上・「危ない！」がないことも確かめる） |
| 5 | 自由に作る（仮想マイコン） | 明るさ・温度・距離・ボタン・人感 → LED・ブザー・モーター・サーボ・表示 | なし（スライダで自由に試す） |

各場面には、はじめのプログラム（わざと不十分なもの）と、ヒント、模範プログラムがあります。場面4のはじめのプログラムには、車の信号を 青→黄→赤 にするところまで（場面3と同じ手順）が入っています。

### 授業の時間の割り当て（3時間。はじめにと各場面に目安を表示）

| 時間 | 内容 |
|---|---|
| 1時間目 | はじめに（5分）、場面1 街灯（20分）、場面2 自動ドア（20分）、ふりかえり（5分） |
| 2時間目 | 場面3 信号機（40分）、ふりかえり（10分） |
| 3時間目 | 場面4 押しボタン式信号機（25分）、場面5 自由に作る（10〜15分）、ふりかえり・記録の書き出し（10分） |

目安は `data/scenarios.json` の `time`・`period` で変えられます。

### 先生用ページ（模範プログラム）

生徒用のメニューには出しません。次のどちらかで開きます。

- 単体のファイル（`dist/計測制御シミュレータ.html`）を開き、アドレスの最後に `#/teacher` をつける。
- 教材集の中などアドレスを変えられないときは、教材の画面をクリックしてから（文字を入れる欄の外で）キーボードで `teacher` と続けて打つ。

## 機能

- **プログラミング**: ブロック（タブレットでも使える「① ＋ ここに入れる を押す → ② 命令のボタン」方式。「↔」で「もし」の中などへ動かせる。中身のあるブロックを消すときは確認。元にもどす記録は場面ごとに残る）／フローチャート（JIS記号、自動作図）／簡易テキスト言語（日本語）。どれで見ても同じプログラムです（ブロックとテキストで編集でき、フローチャートは自動でかかれます）。
- **仮想世界**: スライダ・押しボタンでセンサの値を動かす「手動」と、テストのケースを再生する「ケース再生」。速さ ×0.5〜×5。
- **デバッグ**: 1ステップ実行（次に実行する命令がブロック・フローチャート・テキストの行で光る）、センサ・出力・変数のグラフ（同じ時間軸のレーン表示）、出力の変化とエラーのログ。
- **評価**: 想定ケースの自動判定（合格/不合格と理由・時刻）。テストのたびに記録され（「ふりかえり・記録」ページ）、場面ごとの「ふりかえり」と「改善メモ」を付けられます（書いたそばから自動でこの端末に保存。ページを移るとき・閉じるときにも保存）。改善記録はJSON/CSVで書き出せます（組と番号が空のときは書き出さずに知らせる。先生に出すのは JSON）。プログラムのすぐ上にも「テストを実行」と○×のまとめがあります。
- **入力**: ブロックの数の欄は、全角・空白・桁区切り・うしろの単位（「150cm」「2秒」など）を取りのぞいて読みます。読めないときは欄のすぐ下とまちがいの箱に直し方を出し、直すまでテストと実行を止めます。
- **安全**: 止まらないくり返しは 0.1秒きざみで進むので固まりません（1きざみ1000命令まで）。0で割るなどのエラーは行番号つきでログに出て止まります。
- 表示: 大きな文字、ダークモード対応、スマホ幅対応。

## テキスト言語

```
ずっと
  もし 明るさ < 30 なら
    街灯 = オン
  でなければ
    街灯 = オフ
  おわり
  0.5 秒待つ
おわり
```

`ずっと` / `N 回くり返す` / `条件 のあいだくり返す` / `もし 条件 なら … でなければ … おわり` / `N 秒待つ` / `名前 = 式` / `# メモ`。条件は `< > <= >= == !=`（条件の中の `=` は「等しい」）と `かつ` `または`。全角の数字・記号も読めます。詳しくはアプリの「書き方ガイド」。

## 場面やテストを変える

`data/scenarios.json` を編集し、`npm run build` で単一HTML版を作り直します。テストのケースは「センサ入力の時系列（`timeline`）」と「確認（`checks`）」で書きます。

| 確認の種類 | 意味 |
|---|---|
| `always` | ずっと（`when` が `delay` 秒続いたら）`expect` が成り立つ |
| `transitions` | 値の切りかわりが `allowed` の順番だけ（`ignore` に書いた値は飛ばして見る） |
| `minDuration` | ある値（例: 黄）が `min` 秒以上続く |
| `visits` | 決まった値が一度は現れる |
| `respond` | `trigger` が起きてから `within` 秒以内に `expect` になる |
| `at` | 時刻 `t` に `expect` が成り立つ |

仮想世界の絵とセンサ・出力のしくみは `js/models.js` にあります。信号機のモデルは、テストで使う値として `交差点`（車が青／車が黄／全赤／歩行者が青／そのほか）と `危ない`（絵の「危ない！」と同じ条件。1 か 0）を出します。`msg` の中の `{t}` `{len}` や `{ドアの開き}` のような名前は、そのときの値に置きかわります。

## 開発者向け

```
npm test        # 言語・インタプリタ・判定のテスト、全場面で模範プログラムが全テスト合格することの確認（Node.js 20以上）
npm run build   # dist/計測制御シミュレータ.html を作り直す
node tests/stage2.browser.cjs  # （build のあと・playwright があるとき）ブラウザでの画面の確認
npm run serve   # http://localhost:8080 で確認
```

構成: `js/lang.js`（テキスト⇔プログラムの木、式）、`js/interp.js`（インタプリタ）、`js/sim.js`（0.1秒きざみのシミュレーションと合否判定）、`js/models.js`（仮想世界）、`js/blocks.js`（ブロック）、`js/flow.js`（フローチャート）、`js/chart.js`（グラフ）、`js/app.js`（画面）、`js/store.js`（端末内保存）。

ブラウザでの確認（2026-10-12）: 全場面で実行・1ステップ・3つの表示・テスト・ケース再生・記録の書き出し画面を操作し、コンソールエラー0件・外部へのリクエスト0件、スマホ幅（390px）で横スクロールなし。
