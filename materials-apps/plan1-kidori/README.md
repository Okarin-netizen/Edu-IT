# 木取り・構想シミュレータ(plan-1 / M5)

板から部品を無駄なく取る「木取り」を画面で試し、製作図と強度の見通しを立てるアプリです。

## 開き方
- `materials-apps/index.html`(メニュー)から「木取り・構想シミュレータ」を選ぶ。
- フォルダごとダウンロードして `plan1-kidori/index.html` を Chrome で開いても動きます(この場合オフライン用のキャッシュは使われませんが、保存はできます)。
- 学校のWebサーバーや GitHub Pages など https で配ると、一度開いたあと機内モードでも使えます(PWA)。

## タブ
1. 材料・部品: 板の規格(プリセットあり)・材質・枚数・値段・切りしろ。部品表の入力。ひな形(本立て・箱・棚)から部品表を自動作成。
2. 木取り: ドラッグで配置(タッチ可)。矢印キー1mm/Shiftで10mm、R回転、Delete外す、PageUp/Down板の移動、Nで次の部品。重なり(切りしろ未満)・はみ出し・木目違反は斜線と「!」で表示。歩留まり・右はしの残り・材料費。ヒントは3段階(考え方 → 次の1個の場所 → 全体の案)で、使った回数をふりかえりに記録。
3. 製作図: ひな形から等角図と第三角法(正面図・平面図・右側面図、寸法付き)。部品図。接合の参考カード(ほぞ接ぎ・あり継ぎなど伝統的な技法を含む)。PNG保存・印刷。
4. 強度: 選んだ部品を梁として、たわみ・強さの余裕・重さ(g)の目安(common/beam.js)。応力(N/mm²)・安全率・式は「くわしく見る(発展)」の中。厚さ・補強材・材料の比較、実験値との比較。
5. ふりかえり: 問題解決の流れ、検査・点検チェック、自己評価、記述、技術の見方・考え方のレーダー。

## テスト
