# M6 工具の使い方・安全トレーナー

作業の前に、工具の正しい使い方・姿勢・安全確認を手順として確かめるアプリです。
**実技の代わりにはしません**(画面の上に常に表示)。共通基盤 `../common/` を使います。

## 画面
| タブ | 内容 |
|---|---|
| 1 工具の手順 | のこぎり・かんな・げんのう・きり・やすり・けがき針・さしがね・クランプの8種。手順カード(自作SVG)を1枚ずつ。←→キーでも移動 |
| 2 作業前チェック | 服装・髪・保護具・作業台・工具点検など8項目。チェックボックスは1項目に1つ。すべてチェックするまで「完了」は押せない。途中の状態は端末に保存(日付が変わるとリセット) |
| 3 危険を見つける | KYT。3場面(のこぎり・工作室・くぎ打ち)。絵をタップして印をつけ、答え合わせ。危険は場面ごとに4〜5こ、1つの危険に正解の場所が複数あってもよい。キーボードは矢印で十字を動かして Enter |
| 4 手順ならべかえ | 工具ごとの手順を↑↓ボタンで正しい順に。位置ごとに ○/× と正しい番号を表示 |
| 5 実技の評価 | 自己評価・相互評価。観点「姿勢・安全・精度」を A/B/C で。コメント付きで保存 |
| 6 記録 | チェック完了・KYT・ならべかえ・評価の記録一覧。「ファイルに書き出す」「ファイルから読み込む」(JSON。`gijutsu-bundle/1`、app 名 `tool-safety`) |

## ファイル
- `tools-data.js` … 手順・注意・図・クイズ・チェックリスト・KYT・ルーブリック・ルビ辞書(`window.M6_DATA`)。`file://` でも読めるように JS にしている
- `tools.json` … 上と同じ内容。`tools-data.js` を直したら `node tests/sync-json.js` で作り直す
- `figures.js` … 図の部品(作業台・板・のこぎり・かんな…・矢印・角度・手・目)と KYT の場面。手順の図はデータ側の `fig: [[部品名, {…}], …]` で組み立てる
- `logic.js` … 判定(KYT、ならべかえ、チェックリスト、評価)。画面に依存しない
- `app.js` / `style.css` / `index.html`

## テスト
`node --test tests/` … 判定ロジック、データの形、tools.json との一致、総ルビ(画面に出る漢字すべてに読みがあるか)、図の中の文字がかなだけか。

## メモ
- 図の中(SVG)にはルビが付かないので、図のラベルはかなで書く(テストで確認)
- 危険行為は簡単な図形だけで表し、けがの様子は描かない
