# 振り返り一覧(先生用)

4分野(A〜D)の教材で生徒が書き出した JSON ファイルを、まとめて読み込んで1つの表にする先生用の道具です。
インターネット不要の1ファイル `dist/振り返り一覧.html` をブラウザ(Chromebook など)で開いて使います。

## 使い方

1. Classroom などで集めた生徒の JSON ファイルを、1つのフォルダにダウンロードする。
2. `振り返り一覧.html` を開き、「ファイルを選ぶ」(いくつでも選べる)か「フォルダごと読み込む」で読み込む。ドラッグでもよい。
3. **振り返り一覧**: 1行に「生徒・教材・場面・問い・書いた内容」。分野・教材・組・種類(ふりかえり/自己評価/成績)・ことばで絞りこめる。
4. **提出状況(生徒 × 教材)**: 数字はふりかえりの文の数、○ は提出あり(ふりかえりの文なし)、－ は未提出。
5. 「表を CSV で保存」で、いま見ている表を CSV にする(Excel・スプレッドシートで開ける)。

読み込んだ内容は画面の中だけで使い、どこにも送らず、保存もしません。

## 読める教材と、読むところ

| 分野 | 教材(書き出すファイル) | 生徒(組・番号・名前) | 読むところ |
|---|---|---|---|
| A | メニューの「すべてファイルに書き出す」(`技術_材料と加工_…json`) | ○ | M1〜M7 のふりかえり・自己評価(M4・M5・M6・M7)・成績 |
| A | M1〜M7 を1つずつ書き出したファイル | ○(メニューで入れた組・番号・名前。前の版のファイルは M4 だけ名前) | 同上 |
| B | B1 育成日誌「すべて書き出す」 | ○ | ふりかえり q1〜q6・自己評価・評価シート |
| B | B3「すべてのデータを書き出す」 | ○ | ふりかえり・自己評価・クイズの最高点 |
| B | B4 バックアップ | ○ | ふりかえり q1〜q4・自己評価 |
| C | E5 回路設計シート | ○(組・番号は1つの欄) | 目的・条件・構想・うまくいったこと・改善案 |
| C | E3 機構ラボ・E4 保守点検ラボ | ○(E5 で書いた名前。なければ保存のときにたずねる。前の版のファイルは×) | 提出ありとして数える(ふりかえりの欄がない) |
| D | デジタル化・仮想CPU・ネットワーク・セキュリティ・双方向・計測制御・生成AI・ハッシュ化体験ラボ の各「記録を書き出す」 | ○ | ふりかえり・ドリルやテストの結果 |
| D | 体験教材集の「記録まとめ」 | ○ | 6教材のふりかえり |
| D | 双方向スタジオの作品ファイル(`interactive-studio-work`) | × | 改善・ふりかえり |

- B2・E1・E2 は JSON を書き出さないので読めません(B2 の振り返りは .txt)。
- 中に名前がないファイルは、ファイル名に「2組15番」のような書き方があればそこから読み取ります。
- 組と番号が同じなら同じ生徒としてまとめます(名前を書かなかったファイルも)。
- 体験教材集の「記録まとめ」と1つずつの書き出しを両方読み込んでも、同じ振り返りは1行になります。
- 自己評価の値は教材ごとにちがうので、言葉(◎ よくできた・できた・A など)に直して表示します。

## 作り方・テスト

```
python3 teacher-tools/furikaeri-ichiran/build.py                 # dist/振り返り一覧.html を作る
node --test teacher-tools/furikaeri-ichiran/tests/parse.test.js  # 読み取りのテスト
node teacher-tools/furikaeri-ichiran/tests/e2e.browser.cjs       # ブラウザのテスト(playwright が必要)
```

- 読み取りは `parse.js`。教材の書き出しの形を変えたら、`parse.js` の ADAPTERS と `tests/samples/` も直す。
- 共通の枠(`shared/`)と版・更新履歴(`teacher-tools/eduit-info.js`)は、ビルドで中に入れます。
- できたファイルは `クラスルーム配布/まとめる.py` で `クラスルーム配布/先生用/` にもコピーされます。
