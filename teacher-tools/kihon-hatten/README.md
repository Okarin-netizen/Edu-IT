# 基本編と発展編の分け方(先生用)

4分野の統一版(`クラスルーム配布/生徒に配る/` の A〜D のファイル)のメニューは「基本編」「発展編」のタブに分かれています。
この道具は、その分け方(どの教材のどのタブ・ページがどちらの編か)を、学習指導要領の項目と分けた理由つきの一覧にして、
インターネット不要の1ファイル `dist/基本編と発展編.html` にします(印刷できます)。

## 分け方のもと

各分野の `eduit-info.js` の `levels` です。メニューのタブ(`shared/eduit-frame.js` の `EduitFrame.levels`)と、この一覧は同じデータを使います。

```js
window.EDUIT_INFO.levels = {
  basic:    { title: '基本編', lead: '…', items: [{ id: 'M1 などのメニューの id', parts: ['生徒の画面のタブの名前', …], curr: 'A(1)ア', why: '分けた理由' }, …] },
  advanced: { title: '発展編', lead: '…', items: [ … ] }
}
```

- 基本編: 学習指導要領(平成29年告示)の各内容の項目にあり、教科書(東京書籍・開隆堂・教育図書)で本文として扱われる内容
- 発展編: 教科書の「発展」「コラム」にあたる内容、数値での設計・計算、しくみの中まで調べる内容、新しい技術
- 1つの教材が両方に入ってよい。`parts` は生徒のカードに「使うところ」として出る。`curr`・`why` はこの一覧だけに出る
- 分け方は目安です。教科書や授業の計画に合わせて `levels` を直し、その分野の dist と、この一覧を作り直してください

## 作り方

```
python3 teacher-tools/kihon-hatten/build.py   # dist/基本編と発展編.html を作る(node で各分野の eduit-info.js を読む)
```

`クラスルーム配布/まとめる.py` を実行すると、これも作り直して `クラスルーム配布/先生用/全分野_基本編と発展編(先生用).html` にコピーします。
`levels` の id がメニューにない教材のときは、ビルドがエラーで止まります。
