# M3 構造強化ラボ

入口: `index.html`(`../common/` の core.js・materials.js・beam.js を使う。file:// でも動く)

| 画面 | 内容 |
|---|---|
| 1 梁(はり) | 材料・支え方(両端支持/片持ち)・荷重(集中/分布)・支点間距離・断面(板/リブ付き/L形/コの字/箱形)を変えて、たわみ・強さの余裕(○余裕あり/△注意 など)・重さ(g)を表示。応力(N/mm²)・安全率・断面二次モーメントは「くわしく見る(発展)」の中。断面の形に関係する入力欄だけを出す。「比べる前」を固定して重ねて比較。実験で測ったたわみとの比較欄つき |
| 2 枠と筋かい | 四角い枠をドラッグ(または ← → キー)でおす。補強なし/すみ板/筋かい/たすき掛け/面材 で変形の違いを体感 |
| 3 接合 | くぎ・木ねじ・接着剤・ほぞ接ぎ・金具の解説カード(ゆるみにくさ 1〜5 の目安。多いほどゆるみにくい)と6問の選択クイズ |
| 4 設計課題 | 3つの棚板課題。たわみと強さの余裕(安全率3以上)の条件を満たし、できるだけ軽くする。最軽量に近いほど星(★1〜3)。試行の記録とふりかえり |

- 保存: 自動で IndexedDB(共通スキーマ `gijutsu-artifact/1`、app 名 `structure-lab`)。「ファイルに書き出す」「ファイルから読み込む」で JSON ファイルにできる。
- ファイル: `app.js`(画面)、`frame.js`(枠の変形モデル)、`challenge.js`(設計課題)、`joints.js`(接合の文章とクイズ)、`app.css`。
- テスト: `node --test`(このフォルダ: 枠・課題 7件)、`cd ../common && node --test beam.test.js`(梁の計算 15件)。
- 数値はすべて目安(`common/materials.js` の代表値)。文章・図はすべて独自に作成。
