# A2 木材の繊維・収縮ラボ

入口は `index.html`。共通基盤 `../common/`(ruby-dict.js, core.js, base.css)を読み込み、`G.initApp({app:'wood-lab'})` で起動する。common がなくても単体で動く(ヘッダーとJSON読み込みだけ簡易になる)。

## 画面
- ① 断面ビューア:年輪・心材/辺材・早材/晩材。板をドラッグ(矢印キー可)すると柾目/追柾目/板目を判定し、板の面の木目を描く。
- ② 収縮ラボ:「乾燥の度合い」スライダーに今の値(%)を表示。数値は丸めて0のとき「−0.0%」でなく「0.0%」(A2.signedPct / A2.shrinkPct)。板目板・柾目板・角材・丸棒・丸太・背割り丸太を乾燥させる。接線:半径:繊維 = 10:5:0.5(%)。図は×1〜×3で強調、数値は強調なし。
- ③ 反りの予測:問題ごとに板目板(木表が上/木裏が上)と柾目板が同じ数ずつ混ざって出る(答えが偏らない)。予測 → 乾燥アニメで確認。結果は結論を1〜2行で示し、理由は「くわしく」(details)を開くと読める。結果は記録に残る。
- ④ 強度比較:荷重スライダで7種類の力のかけ方を比べる(繊維方向の引張を100とした目安)。
- ⑤ 集成材・合板:製造の手順アニメと、繊維方向をそろえる/直交させる効果(縮み・反り・たて/よこの強さ)。
- まとめ・記録:メモ、クイズ記録、「ファイルに書き出す」「ファイルから読み込む」(JSON)。

## データ
共通スキーマの artifact 1件(`id: wood-lab-record`, `app: wood-lab`, `kind: record`)を `G.store` に保存。`data = { notes: {nt1,nt2,nt3}, quizLog: [{at, board, faceUp, answer, correct}] }`。

## モデルの前提(目安)
- 収縮:髄を中心に、半径方向は sR、接線方向は sT 縮むとして、角度を (1−sT)/(1−sR) 倍に閉じる簡易幾何モデル(js/wood.js `deformer`)。
- 強さ:針葉樹乾燥材のおよその比(引張100・曲げ75・圧縮42・せん断9・めりこみ8・横曲げ5・横引張4)。
- どちらも実物の観察・実験と併用する前提。教科書の図・文章は使っていない(図はすべて Canvas / SVG で自作)。
