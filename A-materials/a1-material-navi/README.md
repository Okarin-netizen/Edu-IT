# A1 材料選択ナビ

使用目的・使用条件から材料を比べて選び、「選んだ理由」「選ばなかった理由」を書くアプリです。
入口は `index.html`。共通基盤(`../common/`)があればそのヘッダー・ルビ辞書・保存・オフラインを使い、なくても単体で動きます(`file://` でも可)。

## 画面
- ① 材料カード … 14材料(木材5・金属4・プラスチック5)。自作SVG・要点・8観点の5段階評価(●が多いほどその性質が大きい)・密度・熱の目安。出典・目安の注意はカード一覧の下に1つにまとめて表示
- ② 条件設定 … 初めて開いたときは用途「本立て」(保存した条件があればそれを使う)。用途プリセット(いす・本立て・スマホスタンド・屋外のプランター・なべしき・電気を通す部品・自由)と重み0〜5のスライダー。右に順位がすぐ出る
- ③ 比較結果 … 計算式の表示、上位3つのレーダーチャート(色・線種・マーカーで区別)、よいところ/弱いところ、1位との比較、全材料の比較表
- ④ 理由を書く … ワークシート。保存(IndexedDB、app 名 `material-navi`)、「ファイルに書き出す」「ファイルから読み込む」(JSON)、印刷

## 点数
点数 =(重み×評価 を全部たしたもの)÷(重み×5 を全部たしたもの)× 100。評価は1〜5の目安値(画面でも Σ を使わず、このことばの式で表示)。
「電気・熱を通しにくい方がよい」を選ぶと、通しやすさを 6 − 評価 に反転して計算します。

## データを直すとき
- アプリが読むのは `materials-data.js`(`file://` でも読めるようにするため)。`materials.json` は同じ内容です。
- 両方を同じ内容に保ってください(`materials.json` を直したら、`materials-data.js` の `window.A1_DATA = ` 以降を同じ JSON に置き換える)。
- 文中の `{漢字|かんじ}` はルビになります。
- 5段階評価はこのアプリ用の目安で、教科書の数値ではありません。授業前に先生が確認・調整してください。
