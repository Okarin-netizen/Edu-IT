# 第三角法 立体メーカー(M7) 中学生目線レビューと改善(2026-10-15)

M7「第三角法 立体メーカー」(初版)を、中学2年生になったつもりで操作して確かめた記録です。

- **やり方**: Chromium で、ノートPC 1366×650・Chromebook 1280×800・タブレット縦 810×1080(指の操作)で全タブを操作した。白紙から自分でかく、お手本から始める、大きな図(16マス)をかく、図面を印刷・PDF・STL にする、ふりかえりを書いて書き出す、の流れ。お手本9つの図面もすべて出して確かめた。生徒3人の目で見た: Aさん(読むのが苦手)、Bさん(ふつう)、Cさん(早く進む)。
- **重要度**: A＝まちがい・授業のねらいがくずれる・提出できない。B＝多くの生徒がつまずく・迷う。C＝直すともっとよくなる。
- **状態**: 12件すべてを直しました。直した所は `m7-solid-maker/tests/e2e.browser.cjs`(ブラウザの自動テスト15項目)で確かめています。

## 確かめて問題がなかったこと

- お手本9つは、すべて3つの図が合っていて、STL はすき間のない形になる(`tests/geom.test.js`)。
- 図面: 9つのお手本と大きな形(160×120×100mm)で、外形線・かくれ線・寸法・尺度(1:1・1:5)が正しく出る。印刷は A4 横1ページ。
- 1ファイル版・単体版で、外に通信しない。
- 3つの図だけでは形が1つに決まらないとき(中央だけの補強リブなど)は、見えている形からできるいちばん大きな立体になる。これは三面図の性質なので、使い方の説明に書いている(直していない)。
