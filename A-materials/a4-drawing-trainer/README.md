# A4 製図トレーナー

立体と三面図(第三角法)・等角図の対応を、クイズと作図練習で身に付けるアプリです。入口は `index.html`。共通基盤 `../common/` を使います(classic script なので `file://` でも動きます)。

## 画面
| タブ | 内容 |
|---|---|
| ① 三面図クイズ | 回せる立体を見て、正しい三面図を4つから選ぶ。やさしい・ふつう・むずかしい 各10問(計30問)。まちがいの選択肢は「右側面図の左右逆」「平面図の上下逆」「かくれ線ぬけ」「かくれ線を実線」「形ちがい」から作り、選んだまちがいに合わせて説明を出す。「形ちがい」の図にも同じ種類のまちがいを入れた図を混ぜ、図が似ている2つにしぼるだけでは当たらないようにしている。ア〜エの順は生徒ごとにちがう(記録の `quizSalt` で決まる) |
| ② 立体づくり | 三面図を読んで、台のマスにブロックを積む(逆問題)。3つの図がすべて一致すれば正解(積み方が複数あっても正解になる)。10問 |
| ③ 三面図をかく | 方眼に外形線・かくれ線を引いて、正面図・平面図・右側面図をかく。自動判定(○足りない・×余分・△線の種類ちがいを記号で表示)。ヒント3段階(外形の範囲→線の本数→足りない線1本)。10問 |
| ④ 等角図をかく | 三角格子に3軸方向の線を引いて等角図をかく。ボードに基準線(箱の手前の下の角 ● ・水平線・30°・横/奥行き/高さの向き)を表示。ヒント3段階(立体が入る箱の補助線→回せる立体→足りない線1本)。8問 |
| ⑤ 線と記号 | 線の種類(外形線・かくれ線・中心線・寸法線・寸法補助線・想像線)と寸法の記入・記号(φ □ t R C)の10問テスト(22問から出題) |
| 記録・ふりかえり | 進み具合の一覧、ファイルに書き出す・ファイルから読み込む(JSON)、記録の消去 |

操作: 線はドラッグ(タッチ・ペン・マウス)。キーボードでは矢印キーで点を動かし、スペースで始点と終点(等角図は Q E Z C でななめ)。1/2/3 で道具を切り替え、Ctrl+Z でもどす。立体は矢印キーでも回せます。

## しくみ
- `js/drawing-core.js`: 立体(ボクセル)、三面図の線(外形線・かくれ線)、等角図の線、作図の判定、問題づくり。DOM に依存しない(Node でも動く)。
  - 判定は、描いた線を長さ1の線分に分けて集合で比べる。書き順・向き・分け方・描いた位置(平行移動)によらない。
  - 何も描いていないときや、合わせた位置だと正解の線がボードからはみ出すときは、ボードのまん中(基準線の位置、`centerOffset`)で比べる。「答えを見る」・ヒント・答え合わせの表示はいつもボードの中に出る。
- 「答えを見る」は押すたびに表示と「答えをかくす」を切りかえる。答えは別の層に出すので、線をかいても消えない(答えを見ながらかき直せる)。答え合わせをすると答えは消える。
- 「ヒント」は3段階まで出したあと「ヒントを消す」になる。「ぜんぶ消す」は線がなくても、答え・ヒント・答え合わせの表示を消す。
- 三面図・等角図のボードには基準線(かき始めの ● と基準になる線)を表示する。ボード上の「基準線」で消せる。
- `js/view3d.js` 立体表示(Canvas) / `js/svgviews.js` 図の SVG / `js/sketch.js` 作図ボード / `js/terms-data.js` ミニテストの問題 / `js/ruby-words.js` このアプリの読み(元データは `js/ruby-words.src.txt`)
- 問題は決まった種から作るので、全員が同じ問題になる。
- 保存: `G.store` に1件(`id: drawing-trainer-record`, `app: drawing-trainer`, `kind: progress`)。

## テスト
```
node tests/run-tests.js
```
- ランダム立体100件(張り出しのある立体を含む)で、三面図の線を別の方法(表面の稜線を集めて投影し、視線でかくれを調べる)でも求め、アプリの計算と一致することを確認
- 外形(シルエット)の一致、第三角法での幅・高さ・奥行きの対応
- 書き順・向き・分け方・位置を変えた作図がすべて正解になり、1本ぬけ・線の種類ちがいは不正解になること
- 等角図の基本形の線の本数と、書き順違いの判定
- 「三面図をかく」10問・「等角図をかく」8問の正解を別の方法で求めて一致を確認(等角図は視線を少しずつ進めて面を調べる方法)。等角図の8問は、三面図から立体が1通りに決まることも、箱の中のブロックの置き方を全部ためして確認
- クイズ30問すべてで、正解の選択肢が三面図と一致し、まちがいの選択肢が正解と異なること
