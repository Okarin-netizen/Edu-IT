# M7 第三角法 立体メーカー

三面図(第三角法)をマス目にかくと、立体にして **等角図・キャビネット図・3D(回して見る)** で見せるアプリです。
寸法・表題欄・部品欄の入った A4 横の図面を **印刷・PDF で保存**でき、3Dプリンタ用の **STL** も書き出せます。

## できること

| タブ | 内容 |
|---|---|
| 1 三面図をかく | 平面図(上)・正面図・右側面図(右)のマスをぬる。◣◢◥◤ でななめの半マスもかける。お手本の形(L字・階段・みぞ・穴・くさび・屋根・ブラケットなど)。位置がそろう行・列を色で示し、ほかの図と合わないマスは赤い点線と「!」で知らせる |
| 2 立体を見る | 等角図・キャビネット図(かくれ線の表示も)、3D(ドラッグ・矢印キーで回す)。PNG・STL で保存 |
| 3 図面・印刷 | 正面図・平面図・右側面図(外形線・かくれ線)、全体と区切りごとの寸法、等角図(参考)、部品欄、表題欄(図名・尺度・第三角法の記号・単位・年組番号・日付・氏名)。尺度は自動(2:1〜1:10)か指定。「印刷する」(送り先「PDF に保存」も可)と「PDF で保存」(300dpi) |
| 4 ふりかえり | 自己評価(4項目・3段階)とふりかえり(3つ)。先生用の振り返り一覧・提出ファイル一覧ビューアで読める |

## しくみ(geom.js)

- 立体 = 3つの図をそれぞれの向きにのばした柱の共通部分(見えている形からできる、いちばん大きな立体)。
  1マスの立方体を、ななめのマスの面で切った凸多面体を集め、となりと重なる面を消して外側の面だけを残す。
- 図の線は、向きの変わる辺(折れ目)を集め、見る向きに光線を出して前に面があるかで「見える線」「かくれ線」に分ける。
- STL は、T字のつなぎ目にも点を入れて三角形に分けるので、すき間のない形になる(単位 mm)。


## 保存データ

作品は共通スキーマ(`app: 'solid-maker'`)で IndexedDB に保存。`data` は
`size {W,D,H,cell}`・`views {front,top,side}`(マスの値 0〜5 を並べた文字列。下の段から)・`look`・`sheet`(図面に書くこと)・`reflect {self,learned,hard,use}`・`done {samples,print,pdf,stl}`。
最後に開いた作品は localStorage `solid-maker.last`。
