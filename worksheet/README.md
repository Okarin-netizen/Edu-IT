# 自習ワークシート

自習モードで進めるときに、教材といっしょに使うワークシート(生徒用)と、その答え(先生用)を作ります。

```
python3 worksheet/build.py   # → worksheet/dist/
```

ふつうは `python3 クラスルーム配布/まとめる.py` がこれを呼び、`生徒に配る/ワークシート/` と `先生用/全分野_ワークシートの答え.html` に入れます。生徒用サイト(`site/build.py`)は `ws/a.html`〜`ws/d.html` に置きます。

- 中身のもとは各分野の `eduit-info.js` の `jishu`(自習ガイドと同じ ねらい・目安の時間・手順・たしかめ問題)。自習ガイドを直したら、作り直すだけでワークシートもそろいます。教材の名前は各分野のメニューと同じところ(`extract.cjs`)から取ります。
- 手順の書く欄: ふつうの手順は2行、`reflect` の手順は「まとめ」として3行、記録を書き出して出すだけの手順(「ファイル」「先生の言う場所」を含む)は欄なしで「提出」の印。`level: 'advanced'` の手順は「発展」にまとめます。
- 書いたことはその端末の localStorage `eduit.ws.v1.<記号>`(組・番・名前は `eduit.ws.v1.who` で全部のワークシートに共通)に入ります。送信はしません。
- 印刷は A4 たて。1枚の教材が2ページに入るようにしています(D4 は手順が多く3ページ)。
