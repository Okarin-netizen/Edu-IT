# ワークシート(教科書の節ごとに1枚)

教科書の目次(学習コース)の節といっしょに使うワークシート(生徒用)と、その答え(先生用)を作ります。

```
python3 worksheet/build.py   # → worksheet/dist/
```

ふつうは `python3 クラスルーム配布/まとめる.py` がこれを呼び、`生徒に配る/ワークシート/` と `先生用/全分野_ワークシートの答え.html` に入れます。生徒用サイト(`site/build.py`)は `ws/g.html`・`ws/a.html`〜`ws/d.html`・`ws/z.html` に置きます。

- **1枚 = 教科書の1つの節**。ファイルは編ごとに6つ(G ガイダンス・A 1編・B 2編・C 3編・D 4編・Z 統合的な問題解決と学習を終えて)。付録の発展編の節は、その編のファイルの「発展」に入ります。各編の「学習のまとめ」の節にはワークシートはありません。
- 上のボタン(章ごとに節の番号)で節をえらびます。アドレスの `#a12` のように節の id でも開けます。学習コースの節の画面の「まとめ」から、その節のシートが開きます。「この節をひらく」は、学習コースのその節(`#s=節の id`)を開きます。
- 1枚の中身は、節の画面と同じ5つの手順です。
  1. **教科書をひらく**: ページ(`p`・`pnote`)、キーワード(`kw`)ごとに意味を書く欄、くらべる図(`fig`)と教材の画面をくらべる欄。もとは `T-textbook/course-data.js`。
  2. **まず考えよう**: `shared/eduit-frame.js` の `LETS`(問いと、うすい字のヒント)。
  3. **やってみる**: 各分野の `eduit-info.js` の `jishu.apps[記号].steps` のうち、`sec` にその節の id があるもの(教材の記号つき。1行の書く欄)。手順がない節は、使う教材の名前と3行の欄。
  4. **たしかめ**: `jishu.apps[記号].check` のうち、`sec` にその節の id があるもの。
  5. **まとめ**: 分かったこと(キーワードを使って)・◎○△ の自己評価・まだ分からないこと。
- 書いたことはその端末の localStorage `eduit.ws.v2.<節の id>`(組・番・名前は `eduit.ws.v1.who` で全部のシートに共通)に入ります。送信はしません。
- ふりがな: 手順・問題の文に、その文が来た分野の表(各 `eduit-info.js` の `jishu.ruby`。`shared/jishu-ruby.py` で作る)でふりがなを付けます。上の「ふりがな」で消せます(localStorage `eduit.ws.ruby`)。
- 印刷は **B5 たて**。ほとんどの節は B5 の2ページ(両面1枚)に入ります(手順が10ある 1編1章2 だけ3ページ)。
- 教科書の文や図は写しません。使うのは語(キーワード)・ページ・図の番号だけです。
