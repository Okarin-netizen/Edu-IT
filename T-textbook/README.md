# T 教科書の順に進む学習コース(と M・F・Z)

教科書の節の順に、どの教材のどのタブを使えばよいかを1ページにならべた **学習コース** と、
コースの中で使う3つの新しい教材を置いています。教科書の本文・図は写さず、言葉はすべて自分で書いています。

| 記号 | ファイル | 使うところ | 色 |
|---|---|---|---|
| T | `index.html`(学習コース) | ガイダンスから「学習を終えて」までの65節。節ごとにカード(教科書の場所・ねらい・「ひらく ▶」・ワークシート・たしかめの1問・「できた」) | 灰青 |
| M | `M-mimawari/`(身の回りの技術さがし) | A〜D 各編のはじめ。身の回りの製品の工夫を見つけ、4つの視点で調べる | 赤紫 |
| F | `F-korekara/`(これからの技術ラボ) | A〜C 各編の最後と、4分野をまとめた未来の提案。これからの技術を4つの視点で評価する | あい色 |
| Z | `Z-owari/`(学習を終えて) | 3年の最後。3年間のふりかえり、技術のつながり、これからの自分 | こげ茶 |

4編の「これからの情報の技術」は、すでにある D8 生成AIのしくみラボで学びます(F の「④ 未来を提案」では情報の技術もえらべます)。

## ファイル

```
T-textbook/
├─ index.html       学習コース(1ページ)
├─ course-data.js   コースの中身: COURSE_APPS(記号 → 配るファイル・開く場所)と COURSE(編ごとの節)
├─ common/          M・F・Z・コースで共通の部品
│   ├─ t-core.js    TCore.init: タブ・保存・ふりがな・クイズ・えらぶボタン・自己評価・書き出し
│   ├─ t-core.css   見た目(G-guidance の形をもとにした t- の部品)
│   └─ t-ruby.js    ふりがなの辞書(window.T_RUBY)
├─ M-mimawari/ F-korekara/ Z-owari/   各教材(index.html と eduit-info.js)
├─ eduit-info.js    コースの版・更新履歴
├─ docs/先生用ガイド.html
├─ build.py         1ファイル版を作る → dist/
└─ dist/
```

- 保存: コース `eduit.course.v1`(できた・たしかめの答え)、M `eduit.m.v1`・F `eduit.f.v1`・Z `eduit.z.v1`、表示の設定 `eduit.t.prefs`。
  Z は ガイダンス(`eduit.g.v1`)で書いた「3年間の目標」も読んで出す(同じ端末・同じ場所で開いたとき)。
- 書き出し: `{ schema: 'eduit-textbook/1', app: 'M'|'F'|'Z', student, score, data }`。振り返り一覧(`teacher-tools/furikaeri-ichiran/parse.js` の `parseT`)で読める。
- 自習ガイドは各教材の `eduit-info.js` の `jishu.apps.M` など。「この場所へ」は `[data-tab="a"]` などのタブをクリックする。タブの名前を変えたら `where` も直す。
- ふりがなは `common/t-ruby.js` の長い言葉から順に当てる。文を足したら、その漢字の言葉も足す(送りがなで読みが変わる言葉は「下げ」「下が」のように送りがなまで入れる)。

## コースのリンク

`course-data.js` の `go` に `[記号, タブの名前, (必要なら)アドレスの # のあと]` を書きます。
開くファイルは `index.html` の `var FILES = {…}`、ワークシートは `var WS = {…}` で決まります。

- リポジトリの中で開くとき: `../クラスルーム配布/生徒に配る/` のファイルを開く(先に `まとめる.py` を実行しておく)。
- 配るファイル(`build.py`): 同じフォルダのファイルと `ワークシート/` を開く。自習モードなら `?jishu=on` を付けて開く。
- 生徒用サイト(`site/build.py`): `a.html`・`ws/a.html` などの公開用の名前に置きかえる。
- 配るファイルの名前を変えたら、`index.html` の `FILES`・`WS` と `site/build.py` の `PAGES`・`WS` をいっしょに直す。

## 作り直す

```
python3 T-textbook/build.py          # dist/ だけ
python3 クラスルーム配布/まとめる.py   # 生徒に配る/(コース・M・F・Z)・自習用・振り返りなし・ワークシート・先生用ガイドまで
```
