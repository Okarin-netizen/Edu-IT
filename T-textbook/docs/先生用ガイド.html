先生用ガイド

教科書の順に進む学習コース 先生用ガイド

中学校 技術・家庭(技術分野) 1年〜3年 ・ 生徒に配るファイル: 教科書の順に進む_学習コース.html・M_身の回りの技術さがし.html・F_これからの技術ラボ.html・Z_学習を終えて.html

教科書の目次から節をえらぶと、左に教材、右に「この節の進め方」が出る学習コースと、これまでの教材がなかった節のための3つの教材のガイドです。コースから、G・A〜D の教材のそのタブを直接開けるので、生徒は教科書を見ながら「次に何をするか」を迷わずに、1人でも進められます。生徒用サイトの入り口も、この目次1つです。

新しい3つの教材は、どれか1つの分野に入らないので、ガイダンス(G)と同じように番号のない記号にしています。M 身の回りの技術さがし(各編1章のはじめと終わり)、F これからの技術ラボ(1編〜3編の3章の終わり)、Z 学習を終えて(3年生の最後)です。

1. 配り方と開き方

Classroom で配る

  1. クラスルーム配布/生徒に配る/ の中のファイルを、フォルダごと(または同じ場所にまとめて)配ります。コースのリンクは、同じフォルダにある G・A〜D の統一版、M・F・Z、ワークシート/ を開きます。コースだけを別の場所に置くと、リンク先が見つかりません。
  2. 生徒は端末にダウンロードしてから開きます(ドライブの画面の中では HTML は動きません)。
  3. M・F・Z は、コースを使わずに1つずつ配っても使えます。

生徒用サイトで開く

生徒用サイト(https://okarin-netizen.github.io/Edu-IT/)のトップが、この教科書の目次です。入り口はこの1つだけです(前の版の「授業で使う」jugyo.html・「自習で使う」jishu.html は、トップへ移るようにしました)。ワークシートは ws/a.html などです。

目次の画面

  • 上の切りかえで「ひとりで進む」と「授業で使う」をえらびます。ひとりで進むときは、節の画面の右に「この節の進め方」が出ます。授業で使うときは進め方を出さず、教材だけを大きく開きます(上の「◀ 前」「次 ▶」で節を移ります)。
  • いちばん上の「つづきから」で、前に開いた節にもどれます。その下の帯は「できた節 / 節の数」です。
  • 編のボタン(ガイダンス・1編〜4編・統合的な問題解決・学習を終えて・付録 発展編)で編をえらぶと、章ごとに節がならびます。節の行には、教科書のページと ✓ が出ます。
  • 目次のいちばん下の「教材の一覧」は、先生が「A4 を開いて」のように教材を指定するときに使います。

節の画面

  • 上のバーは1段で、「◀ 目次」・節の番号と名前・教科書のページ・「表示」(ふりがな・文字の大きさ・くっきり・使い方)です。
  • 左に教材が開きます。教材には、その節で使うタブだけが出ます(「ほかのタブも見る」で全部出せます)。
  • 右(スマホは下)に「この節の進め方」の5つの手順が出ます。教科書をひらく(ページ・キーワード・くらべる図)→ まず考えよう(教科書のレッツスタートにあたる問い)→ やってみる(教材の手順。「この場所へ ▶」でそのタブへ移る)→ たしかめ(全部正解で ✓)→ まとめ(分かったことを1文。書くと節に ✓)。
  • 「まとめ」から、その節のワークシート(紙・タブレットに書いて残す1枚)を開けます。
  • キーワード・図の番号・ページは、教科書の語と番号だけを使っています。教科書の文や図は使っていません。

振り返りを隠すとき

生徒に配る/振り返りなし/ の M・F・Z では「振り返り」のタブが出ず、書き出すファイルにも振り返りは入りません。コースには振り返りの欄はありません。

2. 教材の一覧(基本編・発展編)

教科書の順に進む学習コース(教科書の目次)

ガイダンス(5節)→ 1編(12節)→ 2編(13節)→ 3編(17節)→ 4編(20節)→ 統合的な問題解決(2)→ 学習を終えて(1)の、70節です。各編のさいごの「学習のまとめ」では、その分野の基本編のたしかめ問題をまとめて解けます(ワークシートはありません)。コースのいちばん下の「付録 発展編」には、基本のあとで深める教材(A7・D7 ⑤・B5 ④・C2 ④ など)をまとめています。節の名前とねらいは、教科書の文を写さずに短く書き直しています。どの節でどの教材を使うかは、各分野のメニューの「教科書 〇編〇章 〇」と同じ対応です。発展の教材やタブは「(発展)」と書いています。

M 身の回りの技術さがし

タブ教科書生徒がすること
はじめに各編1章 18つの工夫が A〜D のどの分野の技術かを答える。家の中や通学路で見つけた技術を、分野ごとに1つずつ書く
① 材料と加工1編1章 1・4「どんな工夫?」4問(段ボール・ペットボトルの底・いすの横木・アルミ缶)。たためるいすの4つの工夫を、4つの視点(社会からの要求・安全性・環境への負荷・経済性)に分ける。自分で見つけた製品の問題・工夫・大事な視点を書く
② 生物育成2編1章 1・6「どんな工夫?」4問(ビニルハウス・うね・マルチ・養殖の記録)。イチゴの高設栽培の工夫を4つの視点に分ける。自分で見つけた例を書く
③ エネルギー変換3編1章 1・10「どんな工夫?」4問(電気ポット・アース線・変速機・洗濯機)。扇風機の工夫を4つの視点に分ける。自分で見つけた例を書く
④ 情報4編1章 1(と1章のまとめ)「どんな工夫?」4問(改札・炊飯器・自動販売機・動画の画質)。スマートフォンでの支払いの工夫を4つの視点に分ける。自分で見つけた例を書く
振り返り―3項目の自己評価と、技術を見る目が変わったところ・調べたい製品
記録―組・番号・名前、進み具合、書き出し・印刷・はじめから

F これからの技術ラボ

タブ教科書生徒がすること
はじめに各編3章技術を評価するとは何か、4つの視点と最適化、めざす社会(循環型・自然共生・脱炭素・超スマート)を読む
① 材料と加工1編3章 2CLT・バイオマスプラスチック・3Dプリンタ・炭素繊維強化プラスチック・リサイクルのカードを読み、「どの技術?」5問。1つをえらび、4つの視点に 1〜5 の点をつけ、よいところ・心配なところ・これからの使い方を書く
② 生物育成2編3章 2スマート農業・植物工場・陸上養殖・新しい品種づくり・天敵を利用した害虫対策で、同じように「どの技術?」と評価
③ エネルギー変換3編3章 2再生可能エネルギー・蓄電池・燃料電池(水素)・電気自動車・スマートグリッドで、同じように「どの技術?」と評価
④ 未来を提案各編3章・統合的な問題解決社会の問題(高齢化と人手不足・食料・温暖化とエネルギー・災害・ごみと資源)をえらび、①〜③ と情報の技術から使う技術をえらんで、解決策・心配なことと対策を書く。(発展)ちがう立場から見直す
振り返り―3項目の自己評価と、これからの技術とのかかわり方・気になった技術
記録―組・番号・名前、進み具合、書き出し・印刷・はじめから

4編の「これからの情報の技術」は、すでにある D9 生成AIのしくみラボで学びます(F には入れていません)。

学習コースから開くと、M・F はその分野だけが出ます(たとえば 1編の節からは「はじめに・① 材料と加工・振り返り・記録」の4つのタブ。F の ④ 未来を提案は、統合的な問題解決の節から ④ だけで開きます)。操作に慣れない生徒が、ほかの分野のタブへ行って迷わないようにするためです。M の「どの技術の工夫?」(4分野をまたぐ8問)は、分野だけのときは出ません。記録も分野ごとに分かれ、書き出したファイルは振り返り一覧で「M 身の回りの技術さがし ① 材料と加工」のように分野ごとに出ます。配った M・F のファイルを直接開いたときは、今までどおり全部の分野が出ます。

Z 学習を終えて

タブ教科書生徒がすること
はじめに学習を終えて4つの分野と統合的な問題解決をふりかえる。同じ端末で G を使っていれば、ガイダンスで書いた「技術だと思ったもの」「3年間の目標」などが出る
① ふりかえりチェック学習を終えて10項目の自己評価(◎○△)と、いちばん成長したこと・のばしたいこと。この10項目は教科書のチェック項目の文ではなく、この教材のために書いたもの
② 技術のつながり統合的な問題解決植物工場・火星探査ロボット・自動水やり・電動アシスト自転車・陸上養殖・太陽光パネルの家に使われている分野を全部えらんで答え合わせ(6問)。自分で見つけた例を書く
③ 技術とわたしたち学習を終えて使う人・作る人・えらぶ人の3つの立場を知り、5つの場面でよいかかわり方をえらぶ。立場を1つえらび、これからのかかわり方を書く
④ これからのわたし―ガイダンスの目標を見返し、目標はどうだったか・生活に生かしたいこと・技術でかなえたい夢を書く
振り返り―3項目の自己評価と、後輩へのひとこと・心に残っていること
記録―組・番号・名前、進み具合、書き出し・印刷・はじめから

M・F・Z は、どれも全員が学ぶ内容です(基本編・発展編には分けていません。F の ④ の「ちがう立場から見直す」だけ発展です)。

3. 単元での使い方

  • 各編のはじめ(導入の1時間): M のその分野のタブを開き、「どんな工夫?」で身の回りの技術に目を向けます。「問題解決の工夫を読みとこう」と「書いてみよう」は、1章の終わり(問題解決の工夫の節)にまわしてもかまいません。
  • 各編の3章の終わり: F のその分野のタブで、新しい技術を評価します。班で別々の技術をえらばせ、点数と理由を発表し合うと、同じ技術でも見方で点が変わることが伝わります。
  • 3年生の終わり: F の ④ で技術を組み合わせた提案をし、Z で3年間をふりかえります(1〜2時間)。
  • 授業: 「授業で使う」にして今日の節を開き、教材を大きく見せます。説明のあとで、ワークシートの「教科書をひらく」「まとめ」を書かせると、教科書と教材がつながります。
  • 欠席・自習の時間: 「ひとりで進む」で、目次の順に節を進めさせます。進め方の5つの手順と、節ごとのワークシートで、1人でも最後まで進められます。

4. 記録の保存と提出

  • 目次の ✓・進め方の印・たしかめの答え・まとめは、その端末のブラウザの中(localStorage eduit.course.v1)に保存されます。目次のいちばん下の「記録を書き出す」でファイルにできます。
  • ワークシートに書いたことは localStorage eduit.ws.v2.節の id に入ります。出すときは「印刷」で紙か PDF にします。
  • M・F・Z で書いたこと・答えは、localStorage eduit.m.v1・eduit.f.v1・eduit.z.v1 に自動で保存されます。
  • 提出は、M・F・Z の「記録」タブの「記録を書き出す(ファイル)」で作る JSON ファイル(M_技術さがし_…・F_これからの技術_…・Z_学習を終えて_…)です。先生用の「振り返り一覧」に読みこむと、分野「M」「F」「Z」として、書いたこと・自己評価・正解数が一覧になります。
  • 「はじめから(記録を消す)」で、その端末の記録を消せます。端末を共有するときは、提出のあとで消すよう伝えてください。

5. 授業で使うときの注意

  • 教科書の図や文章は使っていません。節の名前・ねらい・問い・製品の例は、この教材のために書いたものです。教科書の写真や本文と合わせて使ってください。
  • F の点数(1〜5)は、生徒が自分の考えでつけるもので、正しい答えは1つではありません。「なぜその点にしたか」を言えることを大事にしてください。新しい技術の説明は、研究や開発が進むと変わることがあります。
  • Z の「ガイダンスで書いたこと」は、G を使ったのと同じ端末・同じブラウザ・同じ開き方(ダウンロードしたファイルか生徒用サイトか)のときだけ出ます。端末が変わっているときは、G で書き出したファイルや紙のワークシートを見せてください。
  • 名前などの個人情報は、先生の指示がないときは入れないよう伝えてください。

6. こまったとき

節を開いても、左に教材が出ない
目次と G・A〜D・M・F・Z のファイル、ワークシート/ が同じフォルダにあるか確かめてください。ダウンロードしたときに名前が変わっていると(「(1)」が付くなど)開けません。生徒用サイトなら、そのまま開けます。
使いたいタブが教材に出ていない
節の画面の教材には、その節で使うタブだけが出ます。上の「ほかのタブも見る」を押すと、全部のタブが出ます。
前に入れた ✓ が消えた
ちがうブラウザ・シークレットウィンドウ・ちがう開き方で開くと、記録は別になります。前と同じ開き方で開いてください。
「自習ガイド」「自習用」のファイルがない
前の版の自習モードは、なくしました。ひとりで進めるときは、目次を「ひとりで進む」にして節を開くと、右に「この節の進め方」が出ます。
