# 実装計画 I1「デジタル化ラボ」

## 1. 概要
- **教科書・指導要領との対応**: 情報の技術 3章「情報のデジタル化」。指導要領 内容の取扱い『情報のデジタル化の方法と情報の量』
- **ねらい**: アナログ→デジタル(標本化・量子化・符号化)の仕組みと、情報量・画質・音質の関係を体験で理解する。
- **形態**: PWA(Service Worker+IndexedDB)の単一Webアプリ。外部通信なし、オフライン完結。共通基盤は [README.md](README.md) を参照。
- **関連**: I2、I4

## 2. 機能要件
### MVP
1. 画像: 解像度(画素数)と階調(ビット数)を変えて見た目と容量(計算式つき)を表示。モノクロ→グレー→カラーへ
2. 音: 波形を標本化周波数・量子化ビット数で離散化し、WebAudioで再生して聞き比べる(低標本化→こもる)
3. 2進数変換パズル(10進⇔2進、文字コードの体験)
4. 圧縮体験: ランレングス圧縮を手作業→自動でやってみて、圧縮率を比較
5. 容量計算ドリル(画像・音・動画の概算)
### 発展
- マイク入力で自分の声を録音して標本化(許可があれば)
- 色の混合(RGB)とカラーピッカー

## 3. 技術設計
- Canvas ImageData、WebAudio API
- 圧縮はRLEなど簡易アルゴリズムのみ
- 画像素材はアプリ内生成または生徒自撮り(端末内のみ)

## 4. 画面構成
- 画像 / 音 / 2進数 / 圧縮 / ドリル

## 5. 受け入れ基準・テスト
- 画素数×ビット数の容量が理論値と一致
- 音の再生がオフラインで動作

## 6. リスクと対策
- マイク使用時はプライバシー注意を表示、録音は保存しない設定を既定に
