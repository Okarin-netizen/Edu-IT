# 生成AIのしくみラボ

作成：羽生市立南中学校 技術 岡田

中学校技術・家庭科（技術分野）D「情報の技術」向けの体験教材です。文章をつくる生成AIと画像をつくる生成AIのしくみを、ブラウザの中で動く小さな模型で体験し、ハルシネーション（もっともらしいまちがい）と個人情報の注意まで学びます。

## すぐに使う

`dist/genai-lab.html` をダブルクリックしてブラウザで開くだけです。1つのファイルなので、USBメモリや Classroom で配れます。インターネット接続は不要です（本物の生成AIのサービスにはつながりません）。

## 中身

| ステップ | 内容 | 目安 |
|---|---|---|
| はじめに | 学習データ → 学習 → 生成の流れ。先生用の授業の進め方の例 | 5分 |
| 1 つぎの言葉あて | 文の続きを予想し、「たくさんの文章ではこう続く」割合（例）とくらべる | 10分 |
| 2 言葉のかけら（トークン） | 入れた文をトークンに分け、番号のならびにする | 5分 |
| 3 ミニ文章AIを動かす | n-gram の模型で1語ずつ文を作る。学習データ（昔話・学校生活・日本のいちばん）、前の言葉を何語見るか、ランダムさ（温度）を変える。学習データに文を足せる | 15分 |
| 4 もっともらしいまちがい | 事実だけを学習したAIが、事実でない文を作るのをたしかめる。AIチャットの答え（例）からまちがいをさがす | 15分 |
| 5 ノイズをまぜる（学習） | 絵にノイズをまぜる。ノイズまじりの絵からもとの絵を当てる練習（AIの学習と同じ） | 10分 |
| 6 ノイズから絵をつくる | ことば（プロンプト）をえらび、ノイズから20ステップで絵にする。AIの予想と、お手本にしている学習した絵の重さを表示。2つのことばをまぜられる | 15分 |
| 7 個人情報が出てしまう？ | Aさんが入れた架空の個人情報が、Bさんへの答えにそのまま出てくるのを体験。送る前チェック | 15分 |
| 8 クイズとふりかえり | 8問のクイズと、ふりかえり（端末の中だけに保存）。組・番号を入れて記録を JSON/CSV に書き出す、またはコピーして提出 | 10分 |

2時間（1〜4／5〜8）で行う想定です。1時間のときは 1・3・4・6・7 を中心にします。

## 模型について

- 文章AIは、前の1〜2語だけを見て続きを選ぶ n-gram（エヌグラム）です。本物の生成AIはずっと長い前の文を見て予想しますが、「つぎの言葉を確率で選ぶ」考え方は同じです。
- 画像AIは、拡散モデルの考え方（ノイズを少しずつ取りのぞく）を、学習した 16×16 の絵6枚でまねたものです。ノイズを取るときは、学習した絵のうち今の絵に近いものほど重く見て「もとの絵」を予想します。学習データが少ないので、学習した絵とほぼ同じ絵が出やすく、「似すぎ・著作権」の話につなげられます。
- つぎの言葉あての割合は説明のための例です。人名・学校名・住所・電話番号はすべて架空です（電話番号は 0000 をふくむ実在しない番号）。個人情報の体験は「えらぶだけ」で、自由に入力する場所はありません。

## 開発者向け

```
npm test        # 文章AI・画像AIの模型とデータの点検（Node.js 20以上）
npm run build   # dist/genai-lab.html を作り直す
npm run e2e     # 1ファイル版をブラウザで開いて確かめる（playwright が必要）
npm run serve   # http://localhost:8080/information-apps/genai-lab/ で確認（共通の枠 ../../shared/ を読むため、リポジトリのいちばん上から配る）
```

画面の右上の「ふりがな」でむずかしい言葉にふりがなが付き、「大きな文字」で文字が大きくなります。メニューには、開いたステップに ✓ が付きます。

中学生目線レビューと改善の記録は `../reviews/2026-10-15_生成AIのしくみラボ_中学生目線レビュー/` にあります。

構成: `js/lm.js`（文章AIの模型とトークン分け）、`js/img.js`（画像AIの模型）、`js/data.js`（文・絵・問題）、`js/app.js`（画面）、`css/style.css`。色・ヘッダー・フッターは4分野共通の枠（`shared/`）を使います。
