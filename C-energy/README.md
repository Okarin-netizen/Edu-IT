# C エネルギー変換の技術(C1〜C8)

中学校技術「C エネルギー変換の技術」の学習アプリです。インターネットなしで、ブラウザだけで動きます。
7つのアプリを1つのファイルにまとめた「エネルギー変換の技術 教材集」として配ります。

## アプリ(番号の順 = 教科書の順)

| 記号 | アプリ | 基本編で使うところ | 発展編で使うところ |
|---|---|---|---|
| C1 | エネルギー変換ゲーム | ステージ1〜7(懐中電灯・自転車のライト・クレーン・火力発電所・再生可能エネルギー・町の電源・たこ足配線) | ステージ8 蓄電池・自由(自由に実験しよう)・💴 発電方法の値段くらべ |
| C2 | 風力発電の羽根ラボ(教科書 3編1章2) | ① 発電機のしくみ ② 羽根を変えて発電量をくらべる ③ いちばん効率のよい羽根をめざす(チャレンジ・ランキング) | ④ 発電方法くらべ ⑤ 風の強さが変わる日の発電量 |
| C3 | 直流・交流と送電ラボ(教科書 3編1章3) | ① 直流と交流 ② 送電・配電の道すじ ③ 高い電圧で送るわけ ④ 周波数 50Hz・60Hz | ⑤ 損失の計算(P=VI、損失=I²R) |
| C4 | 電気回路ラボ | 課題1〜4 豆電球・スイッチ・直列・並列、課題5 モーターを逆に回そう、課題6・7 ヒューズ・ブレーカー、安全体験 | 課題8・9 電流計・電圧計、課題10 電池の持ち、課題11 LEDと抵抗、電気料金 |
| C5 | 機構ラボ | 機械のつくり・回転を伝える・運動を変える・設計課題1〜9 | 設計課題10〜12(2段歯車・力持ちの巻き上げ機・ねじジャッキ)・ブラックボックス |

基本編・発展編の分け方のもとは `eduit-info.js` の `levels` です(この表と先生用ガイドの表は、それに合わせて書いています)。
アプリの中のステージ・課題・タブは「基本編 → 発展編」の順に並んでいます。
記号の番号は教科書の順です(第1.9版 2026-10-23 で付け直した。前の C6→C2・C7→C3・C2→C4・C3→C5・C4→C6・C5→C7)。C1 は部品をつないでエネルギー変換の流れをつかむ教材、C2・C3 は発電と送電を数字を変えてくわしく試す教材として分けています。

## 画面

- メニュー: 上のバーに「C エネルギー変換の技術 教材集」と「ふりがな」「文字 中」「使い方」「先生用」(4分野共通)。「基本編」「発展編」のタブがあり、基本編の上に「おすすめの順番: C1 → C4 → … → C8」。カードは4分野共通の形(`EduitFrame.card`。記号・名前・説明・使うところ・タグ・進み具合・「ひらく ▶」)。
- アプリ: 上のバーに「◀ メニュー」「C4 電気回路ラボ」のような記号つきの名前、C1〜C8 を切りかえるボタン、「🖥️ 全画面」「ⓘ このアプリについて」。
- 先生用(記録の書き出し・読み込み・アプリごとの消去)は、メニューの「🧑‍🏫 先生用」から開きます。

## 作り直しかた

`C1/`〜`C8/` や `build/`・`eduit-info.js` を直したら、リポジトリのいちばん上のフォルダで次を実行します(Python 3 だけで動きます)。

```
python3 C-energy/build/build.py
```

`dist/energy-apps.html`・`dist/energy-apps.zip`・`docs/tsukaikata.html`・`docs/先生用ガイド.html` が作り直されます。
版を上げるときは、先に `eduit-info.js` の version・updated・history を書きかえ、`build/help.py` の更新履歴(先生用ガイドの「更新履歴」の章)にも同じ内容を足します。
テストはありません。作り直したら `dist/energy-apps.html` をブラウザで開いて確かめます。

## 保存のしくみ

- 学習の記録は、ブラウザに `energyApps.C1.v1`〜`energyApps.C8.v1` の名前で保存されます。
- C5 設計図・C6 点検表・C7 回路設計シートの「💾 ファイルに保存」は、`C5-kikou-…json`・`C6-tenken-…json`・`C7-sekkei-…json`(schema `energyApps.artifact`、`app` は `C5`・`C6`・`C7`)です。C2・C3 の「💾 記録」の「💾 ファイルに保存」は `C2-fuuryoku-…json`・`C3-souden-…json`(同じ schema、`app` は `C2`・`C3`。やったこと・振り返りなど)です。C8 は `C8-mondai-note-…json`(同じ schema、`app` は `C8`、`data.note` がノートの中身)です。C8 の中身は4分野共通の `shared/mondai-note/` で、`build.py` が統合版に入れます。先生用の振り返り一覧で読めます。
- 先生用の「全アプリの記録をファイルに書き出す」は、`energy-apps-kiroku-…json`(schema `energyApps.backup`、`data` の中に上の保存名)です。
- 第1.4版(2026-10-16)で記号を E1〜E5 から C1〜C7 に変えたので、それより前の版の記録・ファイルは読みこめません。
- 配布ファイル名 `energy-apps.html` と zip の中のフォルダ名 `energy-apps/` は、配布ずみのものと合わせるため変えていません。
