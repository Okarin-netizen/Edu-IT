# C エネルギー変換の技術(C1〜C5)

中学校技術「C エネルギー変換の技術」の学習アプリです。インターネットなしで、ブラウザだけで動きます。
5つのアプリを1つのファイルにまとめた「エネルギー変換の技術 教材集」として配ります。

## アプリ(番号の順 = おすすめの順)

| 記号 | アプリ | 基本編で使うところ | 発展編で使うところ |
|---|---|---|---|
| C1 | エネルギー変換ゲーム | ステージ1〜7(懐中電灯・自転車のライト・クレーン・火力発電所・再生可能エネルギー・町の電源・たこ足配線) | ステージ8 蓄電池・ステージ9 自由実験・💴 発電方法の値段くらべ |
| C2 | 電気回路ラボ | 課題1〜4 豆電球・スイッチ・直列・並列、課題5 モーターを逆に回そう、課題6・7 ヒューズ・ブレーカー、安全体験 | 課題8・9 電流計・電圧計、課題10 電池の持ち、課題11 LEDと抵抗、電気料金 |
| C3 | 機構ラボ | 回転を伝える・運動を変える・設計課題1〜9 | 設計課題10〜12(2段歯車・力持ちの巻き上げ機・ねじジャッキ)・ブラックボックス |
| C4 | 保守点検ラボ | 部品図鑑・機械を見る・クイズ・ゆるみ・摩耗・点検表づくり | なし |
| C5 | 回路設計シート | ① 課題・構想 ② 回路図 ③ 部品表・手順 ④ 評価、課題 懐中電灯・2部屋の明かり・安全な扇風機 | 課題 LEDライト・LED常夜灯・自由設計、④ 評価の実測とのくらべ |

基本編・発展編の分け方のもとは `eduit-info.js` の `levels` です(この表と先生用ガイドの表は、それに合わせて書いています)。
アプリの中のステージ・課題・タブは「基本編 → 発展編」の順に並んでいます。

## 画面

- メニュー: 上のバーに「C エネルギー変換の技術 教材集」と「❓ 使い方」「🧑‍🏫 先生用」「🖥️ 全画面」。「基本編」「発展編」のタブがあり、基本編の上に「おすすめの順番: C1 → C2 → C3 → C4 → C5」。カードは4分野共通の形(`EduitFrame.card`。記号・名前・説明・使うところ・タグ・進み具合・「ひらく ▶」)。
- アプリ: 上のバーに「◀ メニュー」「C2 電気回路ラボ」のような記号つきの名前、C1〜C5 を切りかえるボタン、「🖥️ 全画面」「ⓘ このアプリについて」。
- 先生用(記録の書き出し・読み込み・アプリごとの消去)は、メニューの「🧑‍🏫 先生用」から開きます。

## フォルダの中身

| 場所 | 中身 |
|---|---|
| `C1/`〜`C5/` | 各アプリの元ファイル(C1 エネルギー変換ゲーム・C2 電気回路ラボ・C3 機構ラボ・C4 保守点検ラボ・C5 回路設計シート)。1つずつブラウザで開いても動きます |
| `eduit-info.js` | 版・更新日・更新履歴・基本編と発展編の分け方(4分野共通の枠が読む) |
| `dist/` | 配布用の完成ファイル。`energy-apps.html`(C1〜C5 が入った1ファイル)と `energy-apps.zip`(html・使い方・先生用ガイド・README.txt) |
| `docs/` | 先生用の文書。`先生用ガイド.html`(4分野で同じ章立ての先生用ガイド)と `tsukaikata.html`(使い方 生徒向け・先生用。印刷できる)。どちらも build.py が作る |
| `build/` | 作る道具。`build.py`・`help.py`(使い方・先生用ガイドの本文)・`shell.html`(統合版の枠・メニュー)・`tsukaikata.tpl.html`・`sensei-guide.tpl.html`(先生用ガイドのひな形)・`README.txt`(zip に入れる説明のひな形) |
| `review/` | レビュー結果と改善計画(その時の記録なので、古い記号 E1〜E5 のまま) |

## 作り直しかた

`C1/`〜`C5/` や `build/`・`eduit-info.js` を直したら、リポジトリのいちばん上のフォルダで次を実行します(Python 3 だけで動きます)。

```
python3 C-energy/build/build.py
```

`dist/energy-apps.html`・`dist/energy-apps.zip`・`docs/tsukaikata.html`・`docs/先生用ガイド.html` が作り直されます。
版を上げるときは、先に `eduit-info.js` の version・updated・history を書きかえ、`build/help.py` の更新履歴(先生用ガイドの「更新履歴」の章)にも同じ内容を足します。
テストはありません。作り直したら `dist/energy-apps.html` をブラウザで開いて確かめます。

## 保存のしくみ

- 学習の記録は、ブラウザに `energyApps.C1.v1`〜`energyApps.C5.v1` の名前で保存されます。
- C3 設計図・C4 点検表・C5 回路設計シートの「💾 ファイルに保存」は、`C3-kikou-…json`・`C4-tenken-…json`・`C5-sekkei-…json`(schema `energyApps.artifact`、`app` は `C3`・`C4`・`C5`)です。先生用の振り返り一覧で読めます。
- 先生用の「全アプリの記録をファイルに書き出す」は、`energy-apps-kiroku-…json`(schema `energyApps.backup`、`data` の中に上の保存名)です。
- 第1.4版(2026-10-16)で記号を E1〜E5 から C1〜C5 に変えたので、それより前の版の記録・ファイルは読みこめません。
- 配布ファイル名 `energy-apps.html` と zip の中のフォルダ名 `energy-apps/` は、配布ずみのものと合わせるため変えていません。
