====================================
作成: 技術　岡田

■ はじめかた
  energy-apps.html をブラウザ(Chrome・Edge など)で開いてください。
  インターネットは不要です。

■ 入っているファイル
  energy-apps.html … アプリ本体(C1〜C5 がこの1つに入っています)
  tsukaikata.html  … 使い方(生徒向け・先生用)。ブラウザで開いて読む・印刷できます
  先生用ガイド.html … 先生用ガイド(配り方・教材の一覧・単元での使い方・記録の保存と提出など。4分野で同じ章立て)
  README.txt       … このファイル

■ 5つのアプリ
  C1 エネルギー変換ゲーム … 部品をつないで、エネルギーの変わり方と効率を体験
  C2 電気回路ラボ         … 回路をつくって、電流・電圧・安全を確かめる
  C3 機構ラボ             … 歯車・ベルト・リンクで、動きと速さの変わり方を調べる
  C4 保守点検ラボ         … 共通部品と、点検・手入れのしかたを学ぶ
  C5 回路設計シート       … 目的に合った回路を設計し、製作と評価まで記録する

■ 使い方のポイント
  ・メニューのカードをタップしてアプリを開きます。カードには進み具合が出ます。
    基本編の上の「おすすめの順番」(C1 → C2 → … → C5)の順に進めましょう。
  ・アプリの中では、上の「◀ メニュー」でメニューにもどり、右のボタン
    (C1 エネルギー、C2 電気回路 など)でほかのアプリに移れます。
  ・どのアプリも、右上の「❓ 使い方」で説明を見られます。
  ・効果音は、はじめは出ません(🔇)。音を出すときは 🔇 をタップして 🔊 にします。
  ・タブレットは横向きでも縦向きでも使えます。
  ・Chromebook・パソコンでは、タップはクリック、なぞるはドラッグでできます。
    「🖥️ 全画面」をおすと、ブラウザのタブやアドレスバーが消えて画面が広く使えます。
  ・C3 の設計図、C4 の点検表、C5 の設計シートは「💾 ファイルに保存」で
    ファイルにでき、「📂 ファイルを読みこむ」で開き直せます。「🖨️ 印刷」もできます。

■ 注意
  ・Google ドライブなどのプレビュー画面では動きません。ダウンロードしてから開いてください。
  ・Chromebook では、zip を「ファイル」アプリで開き、中の energy-apps フォルダを
    「マイファイル」(ダウンロードなど)にコピーしてから、energy-apps.html をダブルクリックして開きます。
    毎回同じ場所のファイルを開くと、記録が続きから使えます。
  ・学習の記録は、開いた端末のブラウザの中に自動で保存されます。
    (第1.4版で記号を E1〜E5 から C1〜C5 に変えたので、それより前の版の記録・保存したファイルは読みこめません)
  ・くわしくは tsukaikata.html を見てください(改善内容は「先生用」の更新履歴にあります)。

■ 安全と個人情報・ライセンス・更新履歴
  アプリのメニューのいちばん下、またはアプリ画面の上のバーの
  「ⓘ このアプリについて」で見られます。
  ・インターネットに接続しません。学習の記録は、開いた端末のブラウザの中だけに保存されます。
  ・回路はシミュレーションです。実際の配線・通電・はんだづけは、必ず先生の指導のもとで行います。
  ・学習のためであれば、だれでも無料で使用・コピー・配布できます。販売はできません。
    直して配るときは、直したことと、もとの作者(技術　岡田)を書いてください。
