エネルギー変換 学習アプリ(E1〜E5)
====================================
作成: 羽生市立南中学校　技術　岡田
第{{VERSION}}版({{UPDATED}} 更新)

■ はじめかた
  energy-apps.html をブラウザ(Chrome・Edge など)で開いてください。
  インターネットは不要です。

■ 入っているファイル
  energy-apps.html … アプリ本体(E1〜E5 がこの1つに入っています)
  tsukaikata.html  … 使い方(生徒向け・先生向け)。ブラウザで開いて読む・印刷できます
  README.txt       … このファイル

■ 5つのアプリ
  E1 エネルギー変換ゲーム … 部品をつないで、エネルギーの変わり方と効率を体験
  E2 電気回路ラボ         … 回路をつくって、電流・電圧・安全を確かめる
  E3 機構ラボ             … 歯車・ベルト・リンクで、動きと速さの変わり方を調べる
  E4 保守点検ラボ         … 共通部品と、点検・手入れのしかたを学ぶ
  E5 回路設計シート       … 目的に合った回路を設計し、製作と評価まで記録する

■ 使い方のポイント
  ・トップ画面のカードをタップしてアプリを開きます。カードには進み具合が出て、
    1つでも進んだアプリは「▶ つづきから」になります。
  ・アプリの中では、上の「🏠 トップ」でトップにもどり、となりのボタン
    (⚡ E1 エネルギー、🔌 E2 電気回路 など)でほかのアプリに移れます。
  ・どのアプリも、右上の「❓ 使い方」で説明を見られます。
  ・効果音は、はじめは出ません(🔇)。音を出すときは 🔇 をタップして 🔊 にします。
  ・タブレットは横向きでも縦向きでも使えます。
  ・Chromebook・パソコンでは、タップはクリック、なぞるはドラッグでできます。
    「🖥️ 全画面」をおすと、ブラウザのタブやアドレスバーが消えて画面が広く使えます。
  ・E3 の設計図、E4 の点検表、E5 の設計シートは「💾 ファイルに保存」で
    ファイルにでき、「📂 ファイルを読みこむ」で開き直せます。「🖨️ 印刷」もできます。

■ 注意
  ・Google ドライブなどのプレビュー画面では動きません。ダウンロードしてから開いてください。
  ・Chromebook では、zip を「ファイル」アプリで開き、中の energy-apps フォルダを
    「マイファイル」(ダウンロードなど)にコピーしてから、energy-apps.html をダブルクリックして開きます。
    毎回同じ場所のファイルを開くと、記録が続きから使えます。
  ・学習の記録は、開いた端末のブラウザの中に自動で保存されます。
    (2026-10-14 の改善でも保存の形は変えていないので、前の記録をそのまま使えます)
  ・くわしくは tsukaikata.html を見てください(改善内容は「先生向け」にあります)。

■ 安全と個人情報・ライセンス・更新履歴
  アプリのトップ画面のいちばん下、またはアプリ画面の上のバーの
  「ⓘ このアプリについて」で見られます。
  ・インターネットに接続しません。学習の記録は、開いた端末のブラウザの中だけに保存されます。
  ・回路はシミュレーションです。実際の配線・通電・はんだづけは、必ず先生の指導のもとで行います。
  ・学習のためであれば、だれでも無料で使用・コピー・配布できます。販売はできません。
    直して配るときは、直したことと、もとの作者(羽生市立南中学校　技術　岡田)を書いてください。
