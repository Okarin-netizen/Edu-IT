## 2. 方針
1. **A はすべて直す**(内容の誤り・不具合・安全の記述)。
2. **縦向き(幅900px以下)でも使えるレイアウト**にする。作業エリア(盤面・図)を全幅にし、部品パレットは上の横帯、情報パネルは下へ回す。横向き(1180×820)の見た目は大きく変えない。
3. **アプリ共通のルール(下の3章)にそろえる**。アプリを行き来しても同じ操作は同じ名前・同じ場所にする。
4. **読みがな**: 全文の総ルビ切替は今回は入れず、各アプリの難しい用語(レビューで挙がった語)に初出で `<ruby>` の読みと短い言いかえを付ける。図(SVG/canvas)の中は( )で読みを付けるか、言いかえる。
5. B はできるだけ直す。C は手間の小さいものを直す。
6. 計画書にあって未実装の大きな機能(PWA/IndexedDB、総ルビ切替、E1の劣化イベント、X1連携、実体配線図)は今回の対象外。
7. 保存データ(localStorage のキーと形式)は変えない。今までの学習記録はそのまま使えるようにする。

## 3. アプリ共通のルール

| 項目 | ルール |
|---|---|
| 使い方ボタン | 全アプリ「❓ 使い方」(文字つき)、ヘッダー右側。モーダル見出しは「❓ ○○の使い方」。 |
| 使い方モーダルの閉じるボタン | 初回の自動表示は「はじめる」、ボタンから開いたときは「わかった」。 |
| もどす・消す | 「↩ もどす」(1手もどす)、自由に作る画面は「🗑 ぜんぶ消す」、課題の中は「↺ 最初から」。どちらも確認モーダル(「やめる」/「消す」、もどせるときは「↩ もどすで元にもどせます」と書く)。 |
| その他の言葉 | 閉じるは「とじる」。保存は「💾 ファイルに保存」、読込は「📂 ファイルを読みこむ」、印刷は「🖨️ 印刷」(アイコンだけのボタンにしない)。保存・読込のあとは「保存しました」「読みこみました」と画面に出す。 |
| ヘッダーの色 | 全アプリ紺 #1d3557。下に4pxのアプリ色の線(E1 #1e6fd9/E2 #d9480f/E3 #2b7a4b/E4 #c8620e/E5 #5f3dc4。トップ画面のカードと同じ)。 |

| 効果音 | ヘッダー右端の 🔊/🔇。**最初はOFF**(授業で30台が同時に鳴るため)。E5 は音なしのままでよい。 |
| 文字の大きさ | 本文15px以上、補足13px以上、12px未満は使わない(図の中も、画面に出たときの大きさで)。 |
| タッチ目標 | ボタン・チップ・入力欄は高さ44px以上。消すボタンはほかのボタンと離す。 |
| 縦向き | タブは折り返さない(`white-space:nowrap`、縦向きは短い名前)。作業エリアは全幅。 |
| クリアしたとき | 「🎉 クリア!」と次にすることのボタンを出す(E5 の条件クリアも同じ)。 |

## 4. アプリごとの改善項目(番号はレビューの番号)

### E1 エネルギー変換ゲーム
- A1 縦向きレイアウト(盤面全幅、パレットは上の横帯、メーターは下)。
- A2 線を消せるように(線の判定を部品より優先、線の中点に44pxの「×」、部品カードに「この部品の線を消す」)。B13 も同時に解決。
- A3 自由ステージの3軸評価を見直し(安全・廃棄物の考え方を入れ、原子力だけで全部100にならない)。「3つすべてを高くするのはむずかしい」に。
- B1 盤面の文字を大きく/B2 線が部品の下に隠れない描き方/B4 パレットが全部見える/B5 結果画面のボタンを常に表示、ふりかえりを上に/B6 蓄電池があるときの夜の理由文/B7 乾電池は「直列につないだことにしている」と明記/B8 サンキー図の交差/B9 理由文をまとめる/B10 ステージ7の段差を小さく/B11 1500Wは定格(ブレーカーと区別)/B14 効率メーターの色。
- C: C1〜C20 のうち小さいもの(アイコン重複、表記ゆれ、ステージ8の単位、「熱が熱になって」、もどすボタン、サンドボックス→「自由に実験」、ステージ4・5の★3をすこしゆるめる 等)。

### E2 電気回路ラボ(回路コアを持つ)
- A1 縦向きレイアウト/A2 電気料金の縦向き/A3 電池どうしのショートを警告(回路コア。E5 にも入る)/A4 並列の電源電流の表示。
- B1 導線は「点→点のタップ」でも引ける/B2 えらぶモードでは導線を引かない/B3 置いたあとのツール/B4 ぜんぶ消すの確認/B5 最初に課題1へ案内・進み具合/B6〜B8 課題9・課題6の判定/B9 課題5〜7に図のヒント/B10 読みがな/B11 文字とボタンの大きさ/B12 安全体験の縦向き/B13 漏電遮断器のカードの色/B14 ゲージの目盛り/B15 時間を分でも表示。
- C: 💥のくり返し、交換時の原因文、記号(電源装置=E5とそろえる)、電子レンジ1400W、アースの説明、色とアイコンの意味、折り返し、`PARTS.breaker` をコア側で持つ(C17) 等。

### E3 機構ラボ(機構コアを持つ)
- A1 回転カウンターが動くように/A2 ブラックボックスの歯数を整数・8以上に/A3 印刷でメモ欄・表が切れない/A4 スライダクランクの「組み立てられない」判定/A5 リンクの説明の矛盾と rockercrank の表示(機構コア。E4 にも入る)。
- B1 読みがな/B2 課題文を常に表示/B3 はじめからの確認・もどす/B4 使えないボタンの理由を表示/B5 手で回す向き/B6 縦向き/B7 設計図のボタンを下に固定/B8 右パネル/B9 課題の並び(易→難)/B10 速さボタンの表記/B11 入力=緑・出力=橙に統一/B12 段階ヒント。
- C: 機構コアの部品データ(平ベルトの「扇風機の首ふり部」を削除、点検ポイントを「〜していないか」の形に、変化点のリンク判定)、表記ゆれ、負の回転数、NaN、等。

### E4 保守点検ラボ
- A1 点検項目を消したら記録の列も消す(確認つき)/A2 部品あてクイズの問題文を区別できるものに/A3 軸継手の使用例/A4 平ベルトの使用例(機構コアは E3 と同じに)/A5 「機械を見る」の縦向き・印の大きさ・ラベルの重なり/A6 「よく調べる」まで原因を選べない/A7 チェーンの絵のはみ出し。
- B1 読みがな/B2 正解だけ長い選択肢をなくす/B3 扇風機の注油は説明書を確認/B4 へたり/B5 ゆるみシミュ「弱い」/B6 チェーンの目安20mm/B7 読みこみボタン・保存メッセージ/B8 印刷に空欄列/B9 消す操作の確認/B10 クイズの途中を残す/B11 文字/B12 ボタン/B13 転がり・滑り軸受、平座金、Vベルト。
- C: 表記ゆれ、不自然な誤答、安全の表記(ペダルは大人と)、点検表の名前の区別、等。

### E5 回路設計シート
- A1 スワイプ後に部品が勝手に置かれる不具合/A2 縦向きレイアウト/A3 LEDの電圧不足を正しく指摘/A4 導線の切れ目を正しく指摘/A5 製作手順に「先生に点検してもらう」とはんだごての安全。
- B1 読みがな(アノード等)/B2 スイッチのタップ(E2 と同じに)/B3 条件クリアの案内/B4「計算した値」/B5 評価の◎の判定/B6 扇風機の4V/B7 電池の持ちの目安/B8 印刷で名前が切れない/B9 手順一覧のスクロール/B10 保存・読込の説明と確認/B11 記号を E2 とそろえる/B12 条件の表示。
- C: ボタンの大きさ、文字、アイコン、タブ番号、🖨️💾に文字、メッセージ、等。

### 統合版・トップ画面・使い方
- 縦向きでボタンが折れない(X6)/上のアプリ切りかえに短い名前(X7)/トップのカードに進み具合と「つづきから」(X8)。
- 使い方(生徒向け・先生向け)・README を今回の変更に合わせて直す(使い方ボタン、効果音が最初はOFF、縦向きにも対応 など)。
- build.py をアプリの変更に合わせて直し、統合版と zip を作り直す。

## 5. 進め方
- 改善作業は Claude(opus、effort medium)の作業役6つで並行して行う: E1/E2/E3/E4/E5/統合版。
- 回路コア(E2 と E5)と機構コア(E3 と E4)は、E2・E3 の担当が直し、最後に同じ内容を E5・E4 に入れる(統合版はコアを1回だけ読むため、中身を完全に同じにする)。
- それぞれ横 1180×820・縦 820×1180 のタッチ操作で確認し、全ステージ・全課題がクリアできること、コンソールエラーがないことを確かめる。
- 最後に統合版と zip を作り直し、全体を通して確認する。

## 6. 結果(2026-10-14 改善済み)
- A(誤り・不具合)は全アプリで直した。B もすべて対応、C はほぼすべて対応(直さなかったものは下)。
- 共通ルール(3章)は全アプリに反映。効果音は最初OFF(E2 は前の設定も1回だけOFFにもどる。E1・E3・E4 は前にONにした設定はそのまま)。
- 縦向き 820×1180 で、E1・E2・E3・E4・E5 とも作業エリアがほぼ全幅になり、図の中の文字も12px以上。
- 内容: E1 の評価を4軸(環境・経済・安定・安全/廃棄物)にし、どの構成でも4つとも100にはならない(約1万通りを総当たりで確認)。E2 の回路コアに「電池どうしのショート」の判定を足し、E5 の自動チェックでも使う。E3 の機構コアのデータ(平ベルトの使用例・点検ポイント・リンクの判定)を直し、E4 にも同じものを入れた。E4 の部品あてクイズは手書きの問題に、事例クイズの誤答は正解と同じくらいの長さに書き直した。E5 の製作手順に「先生に点検してもらう」とはんだごての安全を入れた。
- ステージ・課題の変更: E1 ステージ4の★3を「CO₂ 170以下」、ステージ5の★2を「費用18以下」にゆるめた。ステージ7は送電線と家・工場への線を置いた状態から始まる。E2 課題9は抵抗の初期値10Ωで「60Ω以上」を条件に追加。E3 の設計課題はやさしい順に並べかえ(記録はそのまま)。
- 統合版: トップのカードに進み具合と「▶ つづきから」、上のアプリ切りかえに短い名前。使い方(生徒向け・先生向け)と README を更新し、先生向けに改善内容を追記。
- 確認: 横 1180×820・縦 820×1180 のタッチ表示で、各アプリと統合版のエラー0件。全ステージ・全課題がクリアできること、保存→再読み込み、E3・E4 の印刷(統合版でも)を確認。
- 直さなかったもの: 総ルビ切替、PWA/IndexedDB、E1 のロスの帯を部品の真下に出す描き方、E3 のラックの目盛りの並び(今の読み方で正しい)、E3 のベルトを足すと同じ軸の部品が自動で増える作り。iPad などの実機での確認はまだ。
