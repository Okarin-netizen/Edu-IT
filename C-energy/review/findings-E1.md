# E1「エネルギー変換ゲーム」レビュー結果

**総評1(良い点)**: 「部品を置いて→つなぐ→スイッチON」の流れがわかりやすく、変換のたびに「♨熱 −◯」が出ることやサンキー図で「ロスが出る」ことが目で見てわかります。全9ステージ(自由を含む)は★3まで実際にクリアでき、失敗理由の文(「いちばんロスが大きいのは…」)も具体的です。
**総評2(一番の問題)**: 縦向き(820×1180)では盤面が約0.5倍に縮み、部品名が約6.7px、数値が約5.5pxになって読めません。縦向きの授業ではほぼ使えない状態です。
**総評3**: そのほかの大きな問題は2つです。となり合う部品どうしの線をタップで消せない不具合と、自由ステージで原子力だけを使うと「環境・経済・安定」の評価が3つとも100になり、画面の文「3つすべてが100になる方法はありません」と食い違うことです。あわせて、ルビがないこと、横向きでも盤面の文字が小さいこと(9〜11px)、線が別の部品の下を通って隠れることが、学習のさまたげになります。

確認方法: Playwright(Chromium、hasTouch/isMobile、1180×820 と 820×1180)で、タップ・CDPのタッチドラッグ操作と `EnergyApps.E1._test` を使って全ステージを確かめました。コンソールエラーはありませんでした。

## 他アプリ比較用のUI事実

- ヘッダー(紺 #1d3557、58px): 「⚡ エネルギー変換ゲーム」(縦向きで非表示)/「☰ ステージ」/「ステージN:題名」+小見出し/「🎯 目標」/「💡 ヒント」/「❓ 遊び方」/「🔊/🔇」。
- ヘルプ: 「❓ 遊び方」。ステージ1の目標画面にも「❓ 遊び方を見る」。
- モーダルの閉じる文言(×なし。Escで閉じる): 目標「はじめる」、遊び方「わかった」、ステージ選択・ヒント「とじる」、クリア「もう一度くふうする」/「次のステージへ ▶」、失敗「💡 ヒント」/「直してみる」、削除確認「やめる」/「消す」。
- 主ボタンの色: 青 #1e6fd9。実行ボタンはオレンジ #f08c00「⚡ スイッチON(ためす)」。削除系は淡い赤 #fde2e2。
- 効果音: ヘッダー右端「🔊/🔇」、初期ON、保存あり。
- 進み方: 9ステージ、ロックなし。ステージを開くと目標モーダル。ヒントは押すたびに1つずつ(最大3)。
- クリア演出: 「🎉 クリア!」+★アニメ+和音、★条件、数値表、サンキー図、(7・自由)3軸評価、「🤔 ふりかえり」3択。
- 保存・印刷: ボタンなし。localStorage 自動保存。「ぜんぶ消す」→確認「ぜんぶ消しますか?」(やめる/消す)。
