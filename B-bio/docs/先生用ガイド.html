1. 配り方と開き方

配り方

  1. B_生物育成_統一版.html を各端末に配布します(Google ドライブ・Classroom・USB など)。zip で配るときは、展開(すべて展開)した中の 生物育成教材集.html が同じファイルです(元のファイル名は B-bio/dist/生物育成教材集.html)。
  2. 生徒は端末に保存したファイルをブラウザで開きます。以後はオフラインで動きます。
  3. 初回に、メニュー上部が「✅ このタブレットに保存できます」になっていることを確認してください。

端末ごとの開き方

端末開き方と注意
Chromebook「ファイル」アプリでダウンロード済みの HTML をダブルタップ → Chrome で開く。推奨環境です。
Windows タブレットエクスプローラーで HTML を開く(Edge / Chrome)。
Android タブレット「Files」アプリで zip を展開し、HTML を Chrome で開く。端末によっては保存が残らない開き方があるため、下の「保存テスト」を必ず行ってください。
iPad「ファイル」アプリのプレビューではプログラムが動きません。校内 Web サーバーなどに置いて Safari で開くか、HTML を実行できるアプリを使ってください。

保存テスト(授業前に1台で): B2 で数日育てる → ブラウザを閉じる → もう一度ファイルを開き、「つづきから」で続きが出れば OK です。

2. 教材の一覧(基本編・発展編)

メニューの教材は「基本編」「発展編」のタブに分かれています。学習指導要領と教科書の内容から、全員が学ぶタブを基本編、教科書の「発展」「コラム」にあたるタブ(B1 の予測、B2 の「くらべる」、B3 の水質の数値・生態系と産業、B4 の地域・休業日の再計算と書き出し)を発展編にしています。カードの「使うところ」に、その編で使うタブの名前が出ます。どのタブがどちらの編かは、先生用フォルダの 全分野_基本編と発展編.html にまとめています。

各教材のねらいと時間の目安

教材指導要領・教科書との対応ねらい目安
B1 育成日誌＋成長予測B(2)ア・イ 育成計画・育成・評価実際の栽培・飼育の観察記録をデータ化し、グラフ・積算温度・成長曲線で読み取り、評価・改善につなげる。作物・動物・水産生物を記録できる。栽培期間中の毎回5〜10分＋まとめ1時間
B2 育成環境コントローラ体験B(1)ア 育成環境の調節方法温度・光・水・養分を調節すると成長が変わることを、30日の仮想栽培と条件比較(1条件だけ変える)で理解する。2〜3時間
B3 動物飼育・水産ミニシミュレータB(1)ア 動物・水産生物の育成環境水温・水質・えさ・密度・清潔さの調節と、様子(食欲・動き・体色)からの状態判断。生態系への配慮。2〜3時間
B4 栽培暦ビルダーB(2)イ 育成計画を立てる収穫日からの逆算、地域の気温帯・休業日による補正で計画を立て、実績とのずれを評価する。1〜2時間

3. 単元での使い方

単元での使い方の例

  1. 導入・知識(B2・B3): 育成環境と成長の関係をシミュレーションで体験する。B2 の「天気の番号」をクラスで同じにすると、全員同じ条件で比較・発表ができます。
  2. 計画(B4): 育てる作物を決め、収穫日から逆算して作業日を決める。学校の休業日を入れておきます。
  3. 育成・記録(B1): 実際の栽培中、観察のたびに記録する。B4 の計画を参考に、B1 の計画にも同じ作物と開始日を入れます。
  4. 評価・改善(B1・B4): 計画と実際のずれ、予測と実際の違いから改善案を考える。
  5. まとめ: 各教材の振り返りを提出させる。

生徒用の「おすすめの順番」(メニュー・使い方)も、この順(① B2・B3 → ② B4 → ③ B1 → ④ 振り返り)にそろえ、メニューのカードに「おすすめ①〜③」の印を付けています。

コスト(お金と手間)

B3 はえさ・水替え・そうじ・温度などの世話の回数や量に応じて、えさ代・電気代・治療費と世話の時間を毎日計算し、結果でお手本の世話と比べます(世話を減らして弱らせると治療費がかかる仕組み)。B2 は操作ごとの費用と作業時間を集計し、「くらべる」で A・B の費用も比べます。B4 は計画の下書きに、種苗費・肥料代・資材費と作業時間、収穫の価値の目安を出します。金額はすべて学習用のおおよその目安です。

生き物が死んでしまう場合

B3 では、健康度が20未満の「とても弱った状態」が続くと、数が少しずつ減り(死んだ分はふやせません)、健康度が0になるか1匹だけで弱った状態が3日続くと死んでしまい、飼育はそこで終わります。結果画面に「命を落とすことにつながったおもな原因」が出るので、グラフ・日誌と合わせて振り返らせてください。最初の設定のまま何も見直さないと、金魚は12日目ごろに死んでしまいます。

命を扱う内容なので、事前に声かけをお願いします。

シミュレーション(B2・B3)は簡易モデルです。本物の作物や生き物の観察・記録(B1)と比べて考えるよう声をかけてください。

4. 記録の保存と提出

保存

  • 記録は端末のブラウザ内(localStorage、B1 の写真は IndexedDB)に保存され、外部には送信されません。保存名は教材ごとに b1_〜b4_ で始まり、互いに上書きしません。
  • 同じ端末でも、別のブラウザ・シークレットモード・別のファイルの場所から開くと記録は引き継がれません。
  • 端末を複数の生徒で使う場合、B1 は「名前(班名)」ごとに記録を分けられます。B2〜B4 は端末につき1人分なので、班で1台にするか、使い終わったら下の「すべて消す」を使ってください。
  • ふりがな・文字の大きさは、4教材とメニューで共通の設定です(保存名 hub_ruby・hub_fs)。上のバーの「ふりがな」「A−」「A＋」で変えると、開いているすべての教材にすぐ反映されます。「すべて消す」をしても、この2つの設定は残ります。

振り返りの回収

  • どの教材にも「振り返り」タブがあり、先頭に組・番号・名前、記述の問い、自己評価(◎ よくできた/○ できた/△ もう少し)があります。本文は自動保存され、「最後に保存 hh:mm」が出ます(B1 で以前に付けた★は ◎○△ に変換されます)。
  • 提出方法は「テキストで書き出す(.txt)」「コピー(Classroom の回答欄に貼る)」「印刷・PDF」から指示してください。
  • メニューのカードに、振り返りの書きぐあい(✅ 書いた=記述欄すべて記入 / 📝 書きかけ / ✏️ まだ)が出るので、机間指導で確認できます。
  • 印刷・PDF では、記述欄の文章は枠で切れずに全文が出ます(例文は印刷されません。空欄は「(未記入)」)。

提出されたファイルを見る

4分野共通の 全分野_振り返り一覧.html に、B1「すべて書き出す」・B3「すべてのデータを書き出す」・B4 のバックアップのファイル(JSON)を読み込むと、ほかの分野と同じように振り返りと自己評価を一覧にできます(B2 の振り返りは .txt なので読み込めません)。

評価

観点別評価との対応の目安: 自己評価や問いのうち「関係を理解できた」→知識・技能、「原因を考え改善できた」→思考・判断・表現、「すすんで試した・生活や社会に生かそうとした」→主体的に学習に取り組む態度。

まとめて書き出す・消す

メニュー下の「先生用」から、4教材の記録をまとめて書き出し(バックアップ)・読み込み・削除できます。「すべて消す」は、共用の端末を次の人に渡すときに使います。

B1 の写真はまとめた書き出しに入らないため、B1 の「❓使い方」タブの「すべて書き出す(写真つき)」を使ってください。

5. 授業で使うときの注意

安全・倫理への配慮

  • B3 は、生き物の命を軽く扱わないよう淡い表現にしています。実際の飼育・観察とつなげて扱ってください。
  • 飼育した生き物を川や池に放さない(外来種・生態系への配慮)、農薬は使用基準を守る、について B1・B3 の中でも注意を表示しています。
  • 教科書の図や文章は転載していません。数値は授業用の目安です。

実機で確認してほしいこと(授業前に1台で)

  • テキストやバックアップを書き出したとき、ファイル名が日本語のまま保存されるか(テスト用ブラウザでは「download」という名前になることがありました)。
  • メニューの中で開いた教材で、「コピー」ボタンが使えるか(Classroom などに貼りつけられるか)。
  • B1 の写真で、カメラの起動・写真の選択ができるか。

6. こまったとき

「⚠️ 保存できません」と出る
シークレットモード、または保存を許可しない開き方です。通常のブラウザでファイルを開き直してください。
記録が消えた
別のブラウザ・別の場所のファイルで開いていないか確認してください。ブラウザのデータ削除や端末の初期化でも消えるため、学期の区切りでバックアップを取ることをすすめます。
書き出したファイルが見つからない
端末の「ダウンロード」フォルダに保存されます。
印刷すると教材全体が出る
振り返りタブの「印刷」ボタンを使うと、振り返りだけが印刷されます。

第1.0版でのおもな変更点

  • 設定の共通化: ふりがな・文字の大きさを教材集全体で1つの設定にしました。メニューの中で教材を開いたときは、教材側の見出しを省き、設定ボタンは上のバーに集めています(教材の表示範囲が広がります)。
  • B4: 作業を「人がする作業」と「観察(開花・発芽の確認・出穂など)」に分けました。観察は休業日に合わせて動かしません。休みに合わせた調整で収穫を前に動かすことはありません。目標の収穫日に間に合わないときは警告を出します。
  • B3: ★の基準をきびしくしました。手本どおりに世話をすると★3、水替えなし・そうじなし・えさのかたより・過密のどれかを続けると★2以下、何もしないと★1〜2になります。
  • 振り返りの形(組・番号・名前、◎○△、自動保存)と、タブの見た目を4教材でそろえました。
