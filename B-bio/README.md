# B 生物育成の技術(B1〜B5)

インターネットなしで動く、1ファイルの HTML 教材です。

| 教材 | 内容 |
|---|---|
| B1 | 育成環境コントローラ体験 |
| B2 | 動物飼育・水産ミニシミュレータ |
| B3 | 栽培暦ビルダー |
| B4 | 育成日誌＋成長予測 |
| B5 | 植物工場の自動化(センサとプログラムで照明・水やり・温度を自動に。露地栽培とくらべる・スマート農業) |

番号の順 = おすすめの順です(メニューのカードもこの順)。第1.4版で番号を付け直しました(前の B2→B1、B3→B2、B4→B3、B1→B4)。前の版で保存した記録・書き出したファイルは読みこめません。

## フォルダ

```
B-bio/
├─ B1/ 〜 B5/       教材の元ファイル(b1.html〜b5.html)
├─ eduit-info.js     版・更新履歴・作成者など(共通の枠に入る)
├─ dist/             配布用の完成ファイル(作ったものだけ。手で直さない)
│    生物育成教材集.html … メニュー＋B1〜B5 が入った1ファイル(生徒に配る)
│    先生用ガイド.html   … 印刷用の先生用ガイド
│    生物育成教材集.zip  … 上の2つ＋はじめにお読みください.txt
├─ docs/             先生用の文書
│    先生用ガイド.html   … 先生用ガイドの元(メニューの「先生用」と dist の先生用ガイドに入る)
├─ build/            作る道具
│    rebuild.js          … dist を作りなおす
│    menu.html           … メニューの元
│    はじめにお読みください.txt … zip に入れる説明({version}・{updated} は自動で入る)
│    common/             … 共通部品(ふりがな・文字の大きさ・印刷)と用語辞書
└─ review/           レビュー(findings/)と改善計画.md
```

## 作りなおし方

リポジトリのいちばん上のフォルダで:

```
node B-bio/build/rebuild.js
```

B1〜B5・menu.html・docs/先生用ガイド.html・eduit-info.js・shared/ の共通の枠を直したら、これを実行して dist/ を作りなおします。
何回実行しても同じ中身になります。zip を作るのに `zip` コマンドを使います。

ふりがなの辞書を直したときは、先に `node B-bio/build/common/build-dict.js` を実行します(くわしくは build/common/README.md)。
