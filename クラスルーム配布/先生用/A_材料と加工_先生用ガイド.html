材料と加工の技術 先生用ガイド

中学校 技術・家庭(技術分野) 内容A「材料と加工の技術」 ・ 生徒に配るファイル: A_材料と加工_統一版.html

8つの学習アプリ(A1〜A8)と、先生用の提出ファイル一覧ビューアを1つにまとめた教材集です。インターネットへの接続やインストールは不要です。10インチの Chromebook(1280×800)で使いやすいように作っています。

1. 配り方と開き方

A. 1つのファイルで配る(おすすめ)

  1. A_材料と加工_統一版.html を Classroom・Google ドライブ・USB メモリなどで配ります。メニュー・8つのアプリ・先生用ビューア・このガイドが1つのファイルに入っています(元のファイル名は A-materials/dist/材料と加工_教材アプリ.html)。
  2. 生徒は端末にダウンロードしてからダブルクリックで開きます(ドライブの画面の中では HTML は動きません)。

A7「第三角法 立体メーカー」だけを配るときは、生徒に配るフォルダの「1つずつ配るとき」にある A7_第三角法_立体メーカー.html を使います。

1ファイル版では、アプリとしてのインストール(C の方法)と、ネットから新しい版を自動で受け取ることはできません。直したときは、新しいファイルを配り直してください。

B. フォルダのまま配る

  1. zip ファイルを Chromebook の「ファイル」アプリでダブルクリックし、中のフォルダ A-materials と shared(4分野共通の画面の枠)を、同じ場所の「マイファイル」(ダウンロードなど)にコピーします。
  2. フォルダ A-materials の中の index.html をダブルクリックすると、Chrome でメニューが開きます。

C. 学校の Web サーバーなどに置く(アプリとしてインストールできる)

  1. フォルダ A-materials と shared を、https で見られる場所(学校のサーバー、GitHub Pages など)の同じ階層にそのまま置きます。
  2. 生徒は一度だけネットにつないで、その URL の index.html を開きます。開いたアプリは自動で端末に保存され、そのあとは機内モードでも使えます。
  3. Chrome のアドレスバーの「インストール」から、アプリとしてホーム画面に追加することもできます。

保存のしくみはどの方法も同じで、作品はその端末の Chrome の中に残ります。同じ端末で A と B をどちらも端末のファイルとして開いたときは、保存した作品は共通になります(C の方法で Web から開いたときは別の保存場所になります)。混乱しないよう、クラスではどれか1つに決めて使うのがおすすめです。

画面の上のバー

メニューの上のバーの左には「A 材料と加工の技術 教材集」、右には「ふりがな」「文字 中」「使い方」「先生用」が出ます(4分野で同じ並び・同じ表記です)。アプリを開いたときの上のバーは4分野で同じ形です(C エネルギー変換と同じ)。左から「◀ メニュー」、A1〜A8 の切りかえ(開いているアプリは「A2 木材」のように名前も出て、下に色の線が付きます。押すとそのアプリへ移ります)、右に「ふりがな」「文字 中」「くっきり」(と、アプリによって「使い方」)「全画面」「ⓘ このアプリについて」です。アプリの中のタブは、その下の白い帯に丸いボタンでならびます(開いているタブは茶色で塗られます)。ボタンは次のとおりです。

  • ふりがな: ふりがな(総ルビ)の表示・非表示を切りかえます。はじめは表示しません(4分野で同じ)。設定はすべてのアプリで共通です。
  • 文字: 文字の大きさを 小・中・大・特大 に切りかえます。
  • くっきり(アプリの中だけ): 色のコントラストを強くします(見えにくい生徒向け)。
  • 使い方(メニュー): 生徒向けの使い方(はじめかた・上のバーのボタン・記録の出し方)を小さな画面で出します。
  • 先生用(メニューだけ): メニューのいちばん下の「先生用」(提出ファイル一覧ビューア・このガイド)を開いて、そこへ移ります。
  • 全画面(アプリの中だけ): ブラウザのタブやアドレスバーを消して、画面を広く使います。もう一度押すともどります。全画面にできない端末(iPhone など)では出ません。
  • ⓘ このアプリについて(アプリの中だけ): 作った人・安全と個人情報・ライセンス・更新履歴を出します(画面のいちばん下のリンクと同じ)。

メニューの並び

メニューは上から、基本編・発展編のタブ(アプリのカード) → 保存したデータ(組・番号・名前、書き出し・読み込み、データの管理)→ 先生用 の順です。カードには、記号・絵・名前・説明・「使うところ」(その編で使うタブ)・「ひらく ▶」が出ます。カードのどこを押しても開きます。基本編のカードの上には「おすすめの順番: A1 → A2 → A3 → A4 → A5 → A6」の1行が出ます。

アプリの中のタブには ①②③ の番号が付いています。基本編で使うタブが先、発展編のタブがそのあとです。「まとめ・記録」「記録」「ふりかえり」のタブには番号がなく、いつも最後にあります。

自習で進めるとき(自習モード)

自習・家庭学習・欠席した生徒など、先生の説明なしで進めるときのための表示です(ふだんの授業では出ません)。

  • 先生の説明なしで生徒が1人で進めるときは、自習モードにします。各教材の右はしに「自習ガイド」のボタンが出て、押すと右(スマホは下)にパネルが開きます。パネルには、その教材のねらいと時間の目安、上から順にやる進め方(どのタブで何をするか・「ヒント」・その場所へ移る「この場所へ」・「できた」の印)、たしかめ問題(3〜4問。答えるとその場で正誤と解説が出る)が出ます。発展編の手順は「発展(基本が終わった人)」にまとめてあります。はじめて開いた教材ではパネルが開いた状態で出ます。
  • メニューでは、基本編の上に「ひとりで進めるとき(自習モード)」の進め方が出て、カードに「自習 進め方 3/6・たしかめ 2/3」のような進み具合が出ます。手順が全部できて、たしかめ問題に全部正解すると「✓ クリア」になります。
  • Classroom で配るとき: 生徒に配る/自習用/ の中の、同じ名前のファイルを配ります(中身は同じで、自習ガイドが出ます)。1つずつ配るときのファイルも 自習用/1つずつ配るとき/ にあります。
  • 生徒用サイトで使うとき: トップの入り口で「自習で使う」をえらぶよう知らせます(直接開くときは https://okarin-netizen.github.io/Edu-IT/jishu.html)。ここから開いた教材は自習モード(?jishu=on)で開き、自習ワークシートもここにあります。「授業で使う」(jugyo.html)から開くと、自習ガイドは出ません(?jishu=off)。
  • 「できた」の印とたしかめ問題の答えは、その端末のブラウザの中だけに保存されます(提出するファイルには入りません)。振り返りを隠す設定といっしょに使うと、振り返りの手順は出ません。
  • A6 の「② 作業前チェック」「⑤ 実技の評価」は工作室での実際の作業で使います。自習では ① → ④ → ③ の順に進め、②・⑤ は説明を読むだけにするよう、画面とガイドに書いています。① の手順を最後まで読むと「記録」に残るので、自習でも記録を書き出せます。
  • A8 の「② 評価、改善・修正」は製作品ができてから使います。まだのときは「はじめの目標」だけ入れるよう書いています。
  • A3 は、基本編のタブ(①〜③)に振り返りを書く欄がありません(振り返りは発展の「④ 設計課題」の中)。基本編だけのときは、たしかめ問題で確かめます。
  • A1 の「ファイルに書き出す」で出るのは「保存する」を押したワークシートだけです。ガイドでは、書き出す前に「保存する」を押すよう書いています。

振り返りを隠すとき

振り返りを Google フォームなど別の方法で集めるときは、教材の中の振り返り(タブ・欄・印)を出さないようにできます。

  • Classroom で配るとき: 生徒に配る/振り返りなし/ の中の、同じ名前のファイル(A_材料と加工_統一版.html)を配ります。中身は同じで、振り返りだけが出ません。1つずつ配るときのファイルも 振り返りなし/1つずつ配るとき/ にあります。
  • 生徒用サイトで使うとき: アドレスの最後に ?furikaeri=off を付けて開くよう、生徒に知らせます(例: https://okarin-netizen.github.io/Edu-IT/?furikaeri=off)。一度開くと、その端末で覚えています。?furikaeri=on を付けて開くと元にもどります。
  • 隠しても、それまでに書いた振り返りは消えません(書き出すファイルの形も変わりません)。

この分野で出なくなるもの: A3 設計課題の「ふりかえり」の欄、A4「記録」タブの下の「ふりかえり」(タブの名前は「記録」になります)、A5・A7 の「ふりかえり」タブ、A8 の「振り返り」タブ、メニューのカードの「使うところ」の「ふりかえり」。A1「④ 理由を書く」、A2「まとめ・記録」、A6「⑤ 実技の評価」は学習の活動なので、そのまま出ます。

2. 教材の一覧(基本編・発展編)

3. 単元での使い方

基本編のカードは、番号の順(= メニューの「おすすめの順番」)に並んでいます。

  1. 材料を知る(A1・A2): 使用目的と条件から材料を選び、木材の性質を確かめる。
  2. じょうぶな構造(A3 の ①〜③): 断面の形・枠と筋かい・接合方法と強さの関係を調べる。
  3. 図に表す(A4): 三面図・等角図の読み方とかき方を練習する。
  4. 構想と製作の準備(A5・A6): 木取りと部品の構想を立て、工具の手順と安全を確かめる。

A8 問題解決ノートは、教科書の2章「1 問題の発見と課題の設定」「5 問題解決の評価、改善・修正」と3章「1 材料と加工の技術の最適化」で使います。製作の始めに「① 問題の発見」で、「こうだったらいいのに」「不便だな」を付箋に書いて集め(社会・安全・環境・経済の観点のアイコンを付ける)、「問題?課題?」クイズで2つのちがいを確かめてから、自分の課題を1つ決めます。製作のあとで「② 評価、改善・修正」を開き、機能・構造・材料・加工・費用・安全性・環境への配慮の観点で5段階に評価して、はじめの目標とレーダーチャートでくらべ、よかった点・改善・修正の方法を書きます。3章では「③ 技術の最適化」で、飲み物の容器・学校の椅子・買い物の袋の3つの案を、観点の重みや制約条件を変えてくらべ、「いちばんよい案」が入れかわることを確かめます(点は考えるための目安です)。「記録」の「印刷する」で、ノートを A4 の問題解決シートとして印刷できます。書いていない欄は線だけになるので、白紙のシートとして配ることもできます。同じノートは B・C・D の分野にも入る予定です(観点と例は分野ごとに変わります)。

まず考えよう: 教科書の節の入り口(レッツスタートにあたる所)に、身近な問いを1つ出しています(A1 の一覧、A4 の ① 三面図の読み方、A5 の部品、A6 の工具、A8 の評価)。ヒントは押すと開きます。問いの文は教材オリジナルです。学習コース(T)の各節にも同じ問いが出ます。授業のはじめに近くの人と話し合わせてから、操作に入ると使いやすいです。

A4 の ① では、小テストの前に「第三角法のきまり」のカード(例の立体・等角図・三面図と、正面図・平面図・右側面図の置き場所)が出ます。まだ1問も答えていないときは開いた状態です。

発展編は、基本編を終えた生徒や選択の課題に使います(A3 の ④ 設計課題、A7 で自分の構想を図面と 3D の形にする など)。

4. 記録の保存と提出

保存

  • 生徒が作ったもの・記録は、その端末の Chrome の中に自動で保存されます(ほかの端末とは共有されません)。外部には送られません。
  • Chrome の閲覧履歴の削除で「Cookie と他のサイトデータ」を消したときも、保存した作品は消えます。大切な記録は書き出しておくよう伝えてください。
  • 第2.4版で記号が M1〜M7 から A1〜A7 に変わりましたが、保存の名前と書き出すファイルの形は変わっていません。前の版で保存・書き出した作品や記録も、そのまま読めます。

提出

  • メニューの「保存したデータ」で組・番号・名前を入れてから「すべてファイルに書き出す」を押させ、できたファイル(JSON 形式)を Classroom などで提出させます。ファイル名にも組・番号・名前が入ります。各アプリの「ファイルに書き出す」でも、そのアプリの分だけ出せます。
  • 書き出したファイルは、メニューや各アプリの「ファイルから読み込む」で端末にもどせます。

提出されたファイルを見る

  1. 4分野共通の 全分野_振り返り一覧.html で、ほかの分野と同じように振り返りと自己評価を一覧にできます。
  2. アプリごとの内容(選んだ材料・理由など)まで見るときは、メニューのいちばん下の「先生用」を開き、「提出ファイル一覧ビューア」を使います(生徒の画面では、ふだんは閉じてあります)。ファイルをまとめて選ぶか、提出ファイルの入ったフォルダを選びます。「生徒ごと」「アプリごと」で一覧にでき、「表を CSV で保存」もできます。

ビューアは読み込んだ内容を端末に保存しません。画面を閉じると一覧は消えます(生徒のファイルはそのまま残ります)。

記録を消す

各アプリの画面のいちばん下にある「保存データの管理(削除)」で、作品を1件ずつ、またはそのアプリの分をすべて消せます。メニューの「保存したデータ」の中の「データの管理(削除)」では、すべてのアプリの分をまとめて消せます(生徒がまちがえて押さないよう、ふだんは閉じてあります)。どれも確認のあとで消え、もとには戻せません。端末を次の学年に引きつぐときなどに使ってください。

5. 授業で使うときの注意

  • 材料の強さ・たわみ・収縮などの数値は、文献の代表値を丸めた目安です。実物の観察や実験と合わせて使ってください。
  • 工具の安全トレーナーは、作業前の確認のためのものです。実技の指導の代わりにはなりません。
  • アプリの図と文章は独自に作ったもので、教科書の図・文章は使っていません。
  • アプリは外部と通信しません。生徒の情報がインターネットに送られることはありません。
