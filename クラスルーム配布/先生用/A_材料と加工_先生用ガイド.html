材料と加工の技術 先生用ガイド

中学校 技術・家庭(技術分野) 内容A「材料と加工の技術」 ・ 生徒に配るファイル: A_材料と加工_統一版.html

7つの学習アプリ(A1〜A7)と、先生用の提出ファイル一覧ビューアを1つにまとめた教材集です。インターネットへの接続やインストールは不要です。10インチの Chromebook(1280×800)で使いやすいように作っています。

1. 配り方と開き方

A. 1つのファイルで配る(おすすめ)

  1. A_材料と加工_統一版.html を Classroom・Google ドライブ・USB メモリなどで配ります。メニュー・7つのアプリ・先生用ビューア・このガイドが1つのファイルに入っています(元のファイル名は A-materials/dist/材料と加工_教材アプリ.html)。
  2. 生徒は端末にダウンロードしてからダブルクリックで開きます(ドライブの画面の中では HTML は動きません)。

A7「第三角法 立体メーカー」だけを配るときは、生徒に配るフォルダの「1つずつ配るとき」にある A7_第三角法_立体メーカー.html を使います。

1ファイル版では、アプリとしてのインストール(C の方法)と、ネットから新しい版を自動で受け取ることはできません。直したときは、新しいファイルを配り直してください。

B. フォルダのまま配る

  1. zip ファイルを Chromebook の「ファイル」アプリでダブルクリックし、中のフォルダ A-materials と shared(4分野共通の画面の枠)を、同じ場所の「マイファイル」(ダウンロードなど)にコピーします。
  2. フォルダ A-materials の中の index.html をダブルクリックすると、Chrome でメニューが開きます。

C. 学校の Web サーバーなどに置く(アプリとしてインストールできる)

  1. フォルダ A-materials と shared を、https で見られる場所(学校のサーバー、GitHub Pages など)の同じ階層にそのまま置きます。
  2. 生徒は一度だけネットにつないで、その URL の index.html を開きます。開いたアプリは自動で端末に保存され、そのあとは機内モードでも使えます。
  3. Chrome のアドレスバーの「インストール」から、アプリとしてホーム画面に追加することもできます。

保存のしくみはどの方法も同じで、作品はその端末の Chrome の中に残ります。同じ端末で A と B をどちらも端末のファイルとして開いたときは、保存した作品は共通になります(C の方法で Web から開いたときは別の保存場所になります)。混乱しないよう、クラスではどれか1つに決めて使うのがおすすめです。

画面の上のバー

メニューの上のバーの左には「A 材料と加工の技術 教材集」と出ます。アプリを開くと、左に「◀ メニュー」、その右に「A2 木材の繊維・収縮ラボ」のように記号と名前が出ます。右のボタンは次のとおりです。

  • ふりがな: ふりがな(総ルビ)の表示・非表示を切りかえます。設定はすべてのアプリで共通です。
  • 文字: 文字の大きさを 小・中・大・特大 に切りかえます。
  • くっきり: 色のコントラストを強くします(見えにくい生徒向け)。
  • 先生用(メニューだけ): メニューのいちばん下の「先生用」(提出ファイル一覧ビューア・このガイド)を開いて、そこへ移ります。

メニューの並び

メニューは上から、基本編・発展編のタブ(アプリのカード) → 保存したデータ(組・番号・名前、書き出し・読み込み、データの管理)→ 先生用 の順です。カードには、記号・絵・名前・説明・「使うところ」(その編で使うタブ)・「ひらく ▶」が出ます。カードのどこを押しても開きます。基本編のカードの上には「おすすめの順番: A1 → A2 → A3 → A4 → A5 → A6」の1行が出ます。

アプリの中のタブには ①②③ の番号が付いています。基本編で使うタブが先、発展編のタブがそのあとです。「まとめ・記録」「記録」「ふりかえり」のタブには番号がなく、いつも最後にあります。

2. 教材の一覧(基本編・発展編)

メニューのアプリは「基本編」「発展編」のタブに分かれています。学習指導要領と教科書の内容から、全員が学ぶタブを基本編、教科書の「発展」「コラム」にあたるタブ(A3 の ④ 設計課題、A7 第三角法 立体メーカーなど)を発展編にしています。1つのアプリが両方に出ることもあり、カードの「使うところ」にその編で使うタブの番号と名前が出ます。アプリの番号の順(A1 → A7)が、おすすめの順です。どのタブがどちらの編かは、先生用フォルダの 全分野_基本編と発展編.html にもまとめています。

3. 単元での使い方

基本編のカードは、番号の順(= メニューの「おすすめの順番」)に並んでいます。

  1. 材料を知る(A1・A2): 使用目的と条件から材料を選び、木材の性質を確かめる。
  2. じょうぶな構造(A3 の ①〜③): 断面の形・枠と筋かい・接合方法と強さの関係を調べる。
  3. 図に表す(A4): 三面図・等角図の読み方とかき方を練習する。
  4. 構想と製作の準備(A5・A6): 木取りと部品の構想を立て、工具の手順と安全を確かめる。

発展編は、基本編を終えた生徒や選択の課題に使います(A3 の ④ 設計課題、A7 で自分の構想を図面と 3D の形にする など)。

4. 記録の保存と提出

保存

  • 生徒が作ったもの・記録は、その端末の Chrome の中に自動で保存されます(ほかの端末とは共有されません)。外部には送られません。
  • Chrome の閲覧履歴の削除で「Cookie と他のサイトデータ」を消したときも、保存した作品は消えます。大切な記録は書き出しておくよう伝えてください。
  • 第2.4版で記号が M1〜M7 から A1〜A7 に変わりましたが、保存の名前と書き出すファイルの形は変わっていません。前の版で保存・書き出した作品や記録も、そのまま読めます。

提出

  • メニューの「保存したデータ」で組・番号・名前を入れてから「すべてファイルに書き出す」を押させ、できたファイル(JSON 形式)を Classroom などで提出させます。ファイル名にも組・番号・名前が入ります。各アプリの「ファイルに書き出す」でも、そのアプリの分だけ出せます。
  • 書き出したファイルは、メニューや各アプリの「ファイルから読み込む」で端末にもどせます。

提出されたファイルを見る

  1. 4分野共通の 全分野_振り返り一覧.html で、ほかの分野と同じように振り返りと自己評価を一覧にできます。
  2. アプリごとの内容(選んだ材料・理由など)まで見るときは、メニューのいちばん下の「先生用」を開き、「提出ファイル一覧ビューア」を使います(生徒の画面では、ふだんは閉じてあります)。ファイルをまとめて選ぶか、提出ファイルの入ったフォルダを選びます。「生徒ごと」「アプリごと」で一覧にでき、「表を CSV で保存」もできます。

ビューアは読み込んだ内容を端末に保存しません。画面を閉じると一覧は消えます(生徒のファイルはそのまま残ります)。

記録を消す

各アプリの画面のいちばん下にある「保存データの管理(削除)」で、作品を1件ずつ、またはそのアプリの分をすべて消せます。メニューの「保存したデータ」の中の「データの管理(削除)」では、すべてのアプリの分をまとめて消せます(生徒がまちがえて押さないよう、ふだんは閉じてあります)。どれも確認のあとで消え、もとには戻せません。端末を次の学年に引きつぐときなどに使ってください。

5. 授業で使うときの注意

  • 材料の強さ・たわみ・収縮などの数値は、文献の代表値を丸めた目安です。実物の観察や実験と合わせて使ってください。
  • 工具の安全トレーナーは、作業前の確認のためのものです。実技の指導の代わりにはなりません。
  • アプリの図と文章は独自に作ったもので、教科書の図・文章は使っていません。
  • アプリは外部と通信しません。生徒の情報がインターネットに送られることはありません。
