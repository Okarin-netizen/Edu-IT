1. 配り方と開き方

配り方

  1. B_生物育成_統一版.html を各端末に配布します(Google ドライブ・Classroom・USB など)。zip で配るときは、展開(すべて展開)した中の 生物育成教材集.html が同じファイルです(元のファイル名は B-bio/dist/生物育成教材集.html)。
  2. 生徒は端末に保存したファイルをブラウザで開きます。以後はオフラインで動きます。
  3. 初回に、メニュー上部が「✅ このタブレットに保存できます」になっていることを確認してください。

端末ごとの開き方

端末開き方と注意
Chromebook「ファイル」アプリでダウンロード済みの HTML をダブルタップ → Chrome で開く。推奨環境です。
Windows タブレットエクスプローラーで HTML を開く(Edge / Chrome)。
Android タブレット「Files」アプリで zip を展開し、HTML を Chrome で開く。端末によっては保存が残らない開き方があるため、下の「保存テスト」を必ず行ってください。
iPad「ファイル」アプリのプレビューではプログラムが動きません。校内 Web サーバーなどに置いて Safari で開くか、HTML を実行できるアプリを使ってください。

自習で進めるとき(自習モード)

自習・家庭学習・欠席した生徒など、先生の説明なしで進めるときのための表示です(ふだんの授業では出ません)。

  • 先生の説明なしで生徒が1人で進めるときは、自習モードにします。各教材の右はしに「自習ガイド」のボタンが出て、押すと右(スマホは下)にパネルが開きます。パネルには、その教材のねらいと時間の目安、上から順にやる進め方(どのタブで何をするか・「ヒント」・その場所へ移る「この場所へ」・「できた」の印)、たしかめ問題(3〜4問。答えるとその場で正誤と解説が出る)が出ます。発展編の手順は「発展(基本が終わった人)」にまとめてあります。はじめて開いた教材ではパネルが開いた状態で出ます。
  • メニューでは、基本編の上に「ひとりで進めるとき(自習モード)」の進め方が出て、カードに「自習 進め方 3/6・たしかめ 2/3」のような進み具合が出ます。手順が全部できて、たしかめ問題に全部正解すると「✓ クリア」になります。
  • Classroom で配るとき: 生徒に配る/自習用/ の中の、同じ名前のファイルを配ります(中身は同じで、自習ガイドが出ます)。1つずつ配るときのファイルも 自習用/1つずつ配るとき/ にあります。
  • 生徒用サイトで使うとき: 入口ページの「ひとりで進めるとき(自習モード)」のボタンを押すか、アドレスの最後に ?jishu=on を付けて開くよう知らせます(例: https://okarin-netizen.github.io/Edu-IT/?jishu=on)。一度開くと、その端末で覚えています。?jishu=off を付けて開くと元にもどります。
  • 「できた」の印とたしかめ問題の答えは、その端末のブラウザの中だけに保存されます(提出するファイルには入りません)。振り返りを隠す設定といっしょに使うと、振り返りの手順は出ません。
  • B3 の「できた!」は、その日の日付で作業した記録になります。実際に育てていないときは押さないよう、ガイドに書いています。
  • B6 の「② 評価、改善・修正」は、育てた作物や生き物があることが前提です。まだのときは B1 の結果や B4 の記録を使ってよいと書いています。
  • B1・B4・B5 の振り返りの問いの一部は、発展編(B1 ③ くらべる・B4 予測・B5 ④ 評価)をした人向けです。基本編だけの生徒向けの書き方をヒントで補っています。

振り返りを隠すとき

振り返りを Google フォームなど別の方法で集めるときは、教材の中の振り返り(振り返りのタブ・欄、メニューのカードの「振り返り」の印など)を出さないようにできます。

  • Classroom で配るとき: 生徒に配る/振り返りなし/ の中の、同じ名前のファイル(B_生物育成_統一版.html)を配ります。中身は同じで、振り返りだけが出ません。1つずつ配るときのファイルも 振り返りなし/1つずつ配るとき/ にあります。
  • 生徒用サイトで使うとき: アドレスの最後に ?furikaeri=off を付けて開くよう、生徒に知らせてください(例: https://okarin-netizen.github.io/Edu-IT/?furikaeri=off)。一度開くと、その端末で覚えています。?furikaeri=on を付けて開くと元にもどります。
  • 隠しても、それまでに書いた振り返りは消えません。

画面のつくり

  • メニューの上のバー: 左に「B 生物育成の技術 教材集」、右に「ふりがな」「文字 中」(文字の大きさ)「使い方」「先生用」がならびます(4分野で同じ並び・同じ表記です)。「先生用」はメニューの下の先生用のところへ移ります。教材を切りかえるボタン「B1 環境」「B2 飼育」「B3 栽培暦」「B4 日誌」「B5 工場」「B6 ノート」は、教材を開いたときに上のバーに出ます。
  • メニュー: 「基本編」「発展編」のタブの中に、B1〜B6 のカードが番号順にならびます(教科書の章ごとに見出しで区切られ、B6 は2章「技術による問題解決」、B5 は3章「社会の発展と技術」の見出しの下)。基本編の上に「おすすめの順番: B1 → B2 → B3 → B4 → B5 → B6」の1行が出ます。カードには記号・名前・説明・使うところ・目安の時間・振り返りの書きぐあいがあり、カードのどこを押しても教材が開きます。
  • メニューの下: 基本編・発展編のカード → 「💾 記録(書き出し・データの管理)」 → 「👩‍🏫 先生用(ガイド)」の順です。
  • 教材を開いたとき: 上のバーの左に「◀ メニュー」と「B1 育成環境コントローラ体験」のような記号と名前が出ます。教材の中のタブは、基本編のタブ → 発展編のタブの順で、学ぶ中身のタブに ①②③… の番号が付いています(「はじめに」「振り返り」には番号がなく、振り返りはいつも最後)。B4 はタブに番号のない絵のタブで、育てているあいだ必要な画面を行き来します。

保存テスト(授業前に1台で): B1 で数日育てる → ブラウザを閉じる → もう一度ファイルを開き、「つづきから」で続きが出れば OK です。

2. 教材の一覧(基本編・発展編)

メニューの教材は「基本編」「発展編」のタブに分かれています。学習指導要領と教科書の内容から、全員が学ぶタブを基本編、教科書の「発展」「コラム」にあたるタブ(B1 の「③ くらべる」と費用、B2 の水質の数値・診断クイズ「生態系と産業」、B3 の地域・休業日の再計算とカレンダーの書き出し、B4 の「予測」、B5 の「④ 全部を自動に」「⑤ スマート農業」、B6 の「③ 技術の最適化」)を発展編にしています。カードの「使うところ」に、その編で使うタブの名前が出ます。どのタブがどちらの編かは、先生用フォルダの 全分野_基本編と発展編.html にまとめています。

3. 単元での使い方

単元での使い方の例

  1. 導入・知識(B1・B2): 育成環境と成長の関係をシミュレーションで体験する。B1 の「はじめに」で選ぶ「天気の番号」をクラスで同じにすると、全員同じ条件で比較・発表ができます。
  2. 問題の発見・課題の設定(B6「① 問題の発見」): 育てる前に、身の回りや社会の「こうだったらいいのに」「不便だな」を付箋に集め、自分の課題を1つ決める。
  3. 計画(B3): 育てる作物を決め、収穫日から逆算して作業日を決める。学校の休業日を入れておきます。
  4. 育成・記録(B4): 実際の栽培中、観察のたびに記録する。B3 の計画を参考に、B4 の計画にも同じ作物と開始日を入れます。
  5. 評価・改善(B3・B4): 計画と実際のずれ(B3 の「④ 記録と評価」)、予測と実際の違い(B4 の「予測」)から改善案を考える。収穫のあとに B6「② 評価、改善・修正」で、観点ごとに5段階で評価して改善・修正の方法を書く。
  6. これからの技術(B5): 統合的な問題解決の例「露地栽培と植物工場」として、センサとプログラムで育成環境の調節を自動にし、収量・費用・環境などの折り合いを考える。情報の技術(D 計測・制御)を学んだあとに使うと、つながりが分かりやすくなります。B6「③ 技術の最適化」(発展)で、社会の生物育成の技術も折り合いをつけて最適化されていることを確かめる。
  7. まとめ: 各教材の振り返りを提出させる。

教材の番号は、この順(おすすめの順番)と同じです。生徒のメニューでは、基本編の上に「おすすめの順番: B1 → B2 → B3 → B4 → B5 → B6」の1行が出て、カードもこの順にならびます。生徒用の「使い方」のページも同じ順で説明しています。

B5 植物工場の自動化の進め方

B5 は、教科書の統合的な問題解決「露地栽培と植物工場 日本の農業を救うのは?」の流れ(問題の発見・課題の設定 → 構想 → 制作 → 評価・改善)に合わせています。B1 は人が環境を選んでくらべる教材、B5 はセンサとプログラムで自動化する教材です。基本編は「① くらべる」(露地栽培と植物工場を1m² あたりで比べ、8問の仕分けクイズ)、「② 照明を自動に」(教科書のプログラム「ずっと / もし 明るさ < 50 なら LED を ON / でなければ OFF」から始め、夜も点灯したままになることに気づかせ、「かつ 時刻が〜」の条件を足す)、「③ 水やりを自動に」(連休中にしおれないよう、土の水分のしきい値を決める。「人が水やり」と比べられる)です。発展編の「④ 全部を自動に」では、ヒーター・冷房のブロックを足して35日育て、点数(収量35・品質25・費用20・環境10・安全10)とランキング、評価のレーダーチャートで、季節による電気代と収量の折り合いを考えます。「⑤ スマート農業」では、4つの棚のセンサのデータ(遠隔監視)から異常のある棚と対策を選ぶチャレンジ(3問・6点)と、④の結果の散布図から重みを決めて「AI のおすすめ」と自分の選択を比べます。天気の番号をクラスでそろえると、同じ条件で比べて発表できます。

B6 問題解決ノートの進め方

B6 は、教科書の2編2章「1 問題の発見と課題の設定」「4 問題解決の評価、改善・修正」と3章「1 生物育成の技術の最適化」で使います。4分野(A〜D)で同じ形のノートで、観点と例が分野ごとに変わります。番号は B6 ですが、育てる前と収穫のあとの2回に分けて開きます。育てる前に「① 問題の発見」で、「こうだったらいいのに」「不便だな」を付箋に書いて集め(社会・安全・環境・経済の観点のアイコンを付ける)、「問題?課題?」クイズで2つのちがいを確かめてから、自分の課題を1つ決めます(何を、どのように育てるか)。収穫のあとで「② 評価、改善・修正」を開き、品質・収量・費用・安全性・環境への配慮の観点で5段階に評価して、はじめの目標とレーダーチャートでくらべ、育成の過程(計画どおりに管理作業を進められたか など)も振り返って、よかった点・改善・修正の方法を書きます。3章では「③ 技術の最適化」(発展)で、レタスの育て方(露地栽培・ハウス栽培・植物工場)・魚をとどける方法(漁業・養殖・栽培漁業)・害虫の防ぎ方(農薬・防虫ネット・天敵)の3つの案を、観点の重みや制約条件を変えてくらべ、「いちばんよい案」が入れかわることを確かめます(点は考えるための目安です)。「記録」の「印刷する」で、ノートを A4 の問題解決シートとして印刷できます。書いていない欄は線だけになるので、白紙のシートとして配ることもできます。

コスト(お金と手間)

B1 は操作ごとの費用と作業時間を集計し(「② 結果・原因さがし」)、「③ くらべる」で A・B の費用も比べます。B2 はえさ・水替え・そうじ・温度などの世話の回数や量に応じて、えさ代・電気代・治療費と世話の時間を毎日計算し、結果でお手本の世話と比べます(世話を減らして弱らせると治療費がかかる仕組み)。B3 は計画の下書きに、種苗費・肥料代・資材費と作業時間、収穫の価値の目安を出します。金額はすべて学習用のおおよその目安です。

生き物が死んでしまう場合

B2 では、健康度が20未満の「とても弱った状態」が続くと、数が少しずつ減り(死んだ分はふやせません)、健康度が0になるか1匹だけで弱った状態が3日続くと死んでしまい、飼育はそこで終わります。結果画面に「命を落とすことにつながったおもな原因」が出るので、グラフ・日誌と合わせて振り返らせてください。最初の設定のまま何も見直さないと、金魚は12日目ごろに死んでしまいます。

命を扱う内容なので、事前に声かけをお願いします。

シミュレーション(B1・B2)は簡易モデルです。本物の作物や生き物の観察・記録(B4)と比べて考えるよう声をかけてください。

4. 記録の保存と提出

保存

  • 記録は端末のブラウザ内(localStorage、B4 の写真は IndexedDB)に保存され、外部には送信されません。保存名は教材ごとに b1_〜b6_ で始まり(B1 b1_*、B2 b2_*、B3 b3_state_v1・b3_reflection_v1、B4 b4_store・写真 b4_photos、B5 b5_state・b5_refl、B6 b6_note・b6_tab・b6_reflstat)、互いに上書きしません。
  • 第1.4版で教材の番号を付け直したため(前の B2→B1、B3→B2、B4→B3、B1→B4)、前の版で保存した記録や書き出したファイルは読みこめません。
  • 同じ端末でも、別のブラウザ・シークレットモード・別のファイルの場所から開くと記録は引き継がれません。
  • 端末を複数の生徒で使う場合、B4 は「名前(班名)」ごとに記録を分けられます。B1〜B3・B5・B6 は端末につき1人分なので、班で1台にするか、使い終わったら下の「すべて消す」を使ってください。
  • ふりがな・文字の大きさは、6教材とメニューで共通の設定です(保存名 hub_ruby・hub_fs)。上のバーの「ふりがな」と「文字 中」(押すたびに 小 → 中 → 大 → 特大)で変えると、開いているすべての教材にすぐ反映されます。「すべて消す」をしても、この2つの設定は残ります。

振り返りの回収

  • どの教材にも「振り返り」タブがあり、先頭に組・番号・名前、記述の問い、自己評価(◎ よくできた/○ できた/△ もう少し)があります。本文は自動保存され、「最後に保存 hh:mm」が出ます(B4 で以前に付けた★は ◎○△ に変換されます)。
  • 提出方法は「テキストで書き出す(.txt)」「コピー(Classroom の回答欄に貼る)」「印刷・PDF」から指示してください。
  • メニューのカードに、振り返りの書きぐあい(✅ 書いた=記述欄すべて記入 / 📝 書きかけ / ✏️ まだ)が出るので、机間指導で確認できます。
  • 印刷・PDF では、記述欄の文章は枠で切れずに全文が出ます(例文は印刷されません。空欄は「(未記入)」)。

提出されたファイルを見る

4分野共通の 全分野_振り返り一覧.html に、B2「すべてのデータを書き出す」(B2_データ_日付.json)・B3 のバックアップ(B3_バックアップ_日付.json)・B4「すべて書き出す」(B4_育成日誌_名前_日時.json)・B5「データで書き出す」(B5_データ_組-番号_名前_日付.json。振り返り・評価のレーダーチャート・④の最高点などが入る)・B6「データで書き出す」(B6_データ_組-番号_名前_日付.json。課題・評価・最適化・振り返りが入る)のファイル(JSON)を読み込むと、ほかの分野と同じように振り返りと自己評価を一覧にできます(B1 の振り返りは .txt なので読み込めません)。

評価

観点別評価との対応の目安: 自己評価や問いのうち「関係を理解できた」→知識・技能、「原因を考え改善できた」→思考・判断・表現、「すすんで試した・生活や社会に生かそうとした」→主体的に学習に取り組む態度。

まとめて書き出す・消す

メニューの下の「💾 記録(書き出し・データの管理)」から、6教材の記録をまとめて書き出し(バックアップ)・読み込み・削除できます。「すべて消す」は、共用の端末を次の人に渡すときに使います。

B4 の写真はまとめた書き出しに入らないため、B4 の「❓使い方」タブの「すべて書き出す(写真つき)」を使ってください。

5. 授業で使うときの注意

安全・倫理への配慮

  • B5 の重さ・電気代・水の量などの数値は授業用の簡単なモデルによる目安です。実際の植物工場では、設備費や人件費なども考える必要があることを補ってください。
  • B2 は、生き物の命を軽く扱わないよう淡い表現にしています。実際の飼育・観察とつなげて扱ってください。
  • 飼育した生き物を川や池に放さない(外来種・生態系への配慮)、農薬は使用基準を守る、について B2・B4 の中でも注意を表示しています。
  • 教科書の図や文章は転載していません。数値は授業用の目安です。

実機で確認してほしいこと(授業前に1台で)

  • テキストやバックアップを書き出したとき、ファイル名が日本語のまま保存されるか(テスト用ブラウザでは「download」という名前になることがありました)。
  • メニューの中で開いた教材で、「コピー」ボタンが使えるか(Classroom などに貼りつけられるか)。
  • B4 の写真で、カメラの起動・写真の選択ができるか。

6. こまったとき

「⚠️ 保存できません」と出る
シークレットモード、または保存を許可しない開き方です。通常のブラウザでファイルを開き直してください。
記録が消えた
別のブラウザ・別の場所のファイルで開いていないか確認してください。ブラウザのデータ削除や端末の初期化でも消えるため、学期の区切りでバックアップを取ることをすすめます。
書き出したファイルが見つからない
端末の「ダウンロード」フォルダに保存されます。
印刷すると教材全体が出る
振り返りタブの「印刷」ボタンを使うと、振り返りだけが印刷されます。
