中学校 技術・家庭(技術分野) 内容D「情報の技術」 ・ 生徒に配るファイル: D_情報の技術_統一版.html

1. 配り方と開き方

配り方

  1. D_情報の技術_統一版.html を、校内の共有フォルダ・USBメモリ・各端末にコピーします(元のファイル名は D-information/dist/情報の技術_体験教材集.html。zip の中では 情報の技術_体験教材集.html です。中身は同じです)。
  2. ブラウザ（Chrome・Edge など）で開きます。端末の種類による開き方のちがいは、下の「端末ごとの開き方」を見てください。

1つの教材だけを配りたいときは、1つずつ配るとき フォルダ(zip の中では「個別の教材」フォルダ)のファイルを使ってください。中身は教材集と同じです。

校内のWebサーバーに置いて使うこともできます（教材集のファイルを置くだけで動きます）。

端末ごとの開き方

配る前に、生徒と同じ端末で一度開いて確かめてください。

  • Chromebook：Google ドライブの画面でファイルを開くと「プレビュー」になり、教材は動きません。次の手順で開きます。
    1. Google ドライブ（またはクラスルーム）で、ファイルをダウンロードします。
    2. ランチャーから「ファイル」アプリを開き、「ダウンロード」フォルダの D_情報の技術_統一版.html をダブルクリックします。Chrome で開きます。
    3. 記録はその端末の Chrome に残ります。次の時間も同じ端末で開けば、続きから使えます。
    デジタル化ラボの録音では、Chrome がマイクを使ってよいか確認してくるので「許可」を押させます。
  • Windows：ファイルを端末か共有フォルダに置き、ダブルクリックで開きます。
  • iPad：「ファイル」アプリでファイルをタップすると「プレビュー」になり、教材が動かないことがあります。校内の Web サーバー（できれば https）にファイルを置き、Safari でその URL を開く方法をおすすめします。デジタル化ラボの録音も、https のページでないとマイクが使えません。

画面の使い方

  • メニューの上のバーの左に「D 情報の技術 教材集」、右に「ふりがな」「文字 中」(文字の大きさ)「使い方」「先生用」が出ます(4分野で同じ並び・同じ表記です)。「使い方」は生徒向けの使い方（はじめかた・上のバーのボタン・記録の出し方）を小さな画面で出します。「先生用」を押すと、メニューの下の先生用のところ（学習指導要領との対応など）へ移ります。
  • メニューの「基本編」「発展編」のタブを選び、カードから教材を選びます。カードには記号（D1〜D11）・名前・説明・「使うところ」（その編で使うページの名前）・「ひらく ▶」が出ます。カードのどこを押しても開きます。基本編の上には「おすすめの順番: D1 → D2 → … → D9 → D11」の1行が出ます。
  • メニューの下は、基本編・発展編のカード → 記録（「記録をまとめて書き出す」「はじめからやり直す」）→ 先生用 の順です。前回開いた教材は、メニューの上の「前回のつづき」から開けます。
  • 教材を開いたときの上のバーは4分野で同じ形です（C エネルギー変換と同じ）。左から「◀ メニュー」、D1〜D11 の切りかえ（開いている教材は「D1 CPU」のように名前も出て、下に色の線が付きます。ほかの教材は記号を押すと移れます）、右に「ふりがな」「文字 中」「🖥️ 全画面」「ⓘ このアプリについて」です。「◀ メニュー」でメニューに戻ります。
  • 教材の中のページは、上のバーのすぐ下の白い帯に、丸いボタンで横にならびます（前は画面の左のたてのメニューでした。開いているページは青で塗られ、終わったページには ✓ の印が付きます）。下へ読み進めると帯が隠れ、上へ戻すと出ます。
  • 教材の中のページには、基本編のページから順に ①②③… の番号が付いています。発展編のページは、そのあとの続きの番号です（例: 仮想CPUラボは ① 図解・② 手計算くらべ が基本編、③ 仮想CPUを動かす・④ 課題 が発展編）。「はじめに」「ふりかえり・記録」「理解度チェック」には番号を付けていません。
  • 切りかえても、開いていた教材の作業はそのまま残ります。ふりかえりの文は書いている途中で自動で保存されるので、ページを再読みこみしても消えません。再読みこみをしても、それぞれの教材はさいごに開いていたページから始まります（同じタブの中だけ）。
  • 上のバーの「ふりがな」「文字 中」は、11の教材とメニューにまとめてかかります。「ふりがな」で漢字の言葉に読みがなが付き、「文字 中」を押すと「文字 大」になって文字が大きくなります(もう一度押すと「中」にもどります)。プログラムを書く欄・入力欄・図の中の文字には、ふりがなは付きません。この設定は「はじめからやり直す」でも消えません。教材集の中では、各教材にもともとある「ふりがな」「文字 中」のボタンは、上のバーのボタンにまとめています（情報セキュリティ体験ラボの「やさしい日本語のまとめ」は教材の中に残ります）。

自習で進めるとき(自習モード)

自習・家庭学習・欠席した生徒など、先生の説明なしで進めるときのための表示です(ふだんの授業では出ません)。

  • 先生の説明なしで生徒が1人で進めるときは、自習モードにします。各教材の右はしに「自習ガイド」のボタンが出て、押すと右(スマホは下)にパネルが開きます。パネルには、その教材のねらいと時間の目安、上から順にやる進め方(どのタブで何をするか・「ヒント」・その場所へ移る「この場所へ」・「できた」の印)、たしかめ問題(3〜4問。答えるとその場で正誤と解説が出る)が出ます。発展編の手順は「発展(基本が終わった人)」にまとめてあります。はじめて開いた教材ではパネルが開いた状態で出ます。
  • メニューでは、基本編の上に「ひとりで進めるとき(自習モード)」の進め方が出て、カードに「自習 進め方 3/6・たしかめ 2/3」のような進み具合が出ます。手順が全部できて、たしかめ問題に全部正解すると「✓ クリア」になります。
  • Classroom で配るとき: 生徒に配る/自習用/ の中の、同じ名前のファイルを配ります(中身は同じで、自習ガイドが出ます)。1つずつ配るときのファイルも 自習用/1つずつ配るとき/ にあります。
  • 生徒用サイトで使うとき: トップの入り口で「自習で使う」をえらぶよう知らせます(直接開くときは https://okarin-netizen.github.io/Edu-IT/jishu.html)。ここから開いた教材は自習モード(?jishu=on)で開き、自習ワークシートもここにあります。「授業で使う」(jugyo.html)から開くと、自習ガイドは出ません(?jishu=off)。
  • 「できた」の印とたしかめ問題の答えは、その端末のブラウザの中だけに保存されます(提出するファイルには入りません)。振り返りを隠す設定といっしょに使うと、振り返りの手順は出ません。
  • D4 は、先生用の設定で隠したモジュールも、自習ガイドの手順には出ます(押すと「はじめに」が開くだけです)。モジュールを隠したときは、その手順はとばすよう伝えてください。自習ガイドでは、はじめに「事前テスト」をするよう書いています。
  • D6 には JSON の書き出しが2つあります。提出は「記録を書き出す(JSON)」で、作品タブの「ファイルに保存(.json)」は作品を別の端末へ移すためのものです(ガイドのヒントにも書いています)。
  • D9 の上のバーの進み具合は全部の8ステップで割るので、基本(①〜③)を全部やっても 38% と出ます。自習ガイドでは「基本は ①〜③」と書いています。
  • D10 ハッシュ化体験ラボは、教材全体が発展編です。

振り返りを隠すとき

振り返りを Google フォームなど別の方法で集めるときは、教材の中の振り返り（振り返りを書くページ・欄、記録の画面の振り返り、カードの「書いた」の印など）を出さないようにできます。

  • Classroom で配るとき：生徒に配る/振り返りなし/ の中の、同じ名前のファイルを配ります。中身は同じで、振り返りだけが出ません。1つずつ配るときのファイルも 振り返りなし/1つずつ配るとき/ にあります。
  • 生徒用サイトで使うとき：アドレスの最後に ?furikaeri=off を付けて開くよう、生徒に知らせます（例: https://okarin-netizen.github.io/Edu-IT/?furikaeri=off）。一度開くと、その端末で覚えています。?furikaeri=on を付けて開くと元にもどります。
  • 隠しても、それまでに書いた振り返りは消えません（記録の書き出しにもそのまま入ります）。

3. 単元での使い方

基本編のカードは、教科書の順（D1 仮想CPUラボ → D2 デジタル化ラボ → D3 ネットワーク通信シミュレータ → D4 情報セキュリティ体験ラボ → D5 ネット詐欺 追体験ラボ → D6 双方向コンテンツ制作スタジオ → D7 計測・制御シミュレータ → D8 火星探査ロボット・シミュレータ → D9 生成AIのしくみラボ → D11 問題解決ノート）です。番号の順がカードの順で、教科書の章ごとに区切って出ます。D10 ハッシュ化体験ラボは発展編だけです。4章のさいごには「学習のまとめ」(基本編の教材のたしかめ問題をまとめて解く)があります。授業の進め方に合わせて、どこから始めてもかまいません。

まず考えよう：教科書の節の入り口(レッツスタートにあたる所)に、身近な問いを1つ出しています(D2 のはじめに、D4 の ①、D6 の作品・エディタ・実行(エディタと実行は部品をまだ置いていないときだけ)、D8 の評価・振り返り、D9 の ①、D11 の評価)。ヒントは押すと開きます。問いの文は教材オリジナルです。学習コース(T)の各節にも同じ問いが出ます。授業のはじめに近くの人と話し合わせてから、操作に入ると使いやすいです。

時間の目安・何時間目・授業の計画表・学習指導要領との対応は、生徒の画面には出しません(このガイドの下の「教材ごとの進め方の例」と「2. 教材の一覧」にあります)。D7・D8 は、先生用ページ(教材の画面で teacher と打つ)にも計画表があります。

教材ごとの進め方の例

  • D1 仮想CPUラボ：基本編は1時間で「① 図解（25分）・② 手計算くらべ・ふりかえり・記録の書き出し（25分）」。② 手計算くらべは、課題をしていなくても取り組めます（使うプログラムは用意してあります）。発展編は「③ 仮想CPUを動かす・④ 課題」で、課題は1〜4が必修、5〜7が発展、8がチャレンジです。
  • D2 デジタル化ラボ：1時間目「はじめに・① 画像・② 音」、2時間目「③ 2進数・④ データ量の計算ドリル・ふりかえり」。⑤ 圧縮のしくみは発展で、早く終わった生徒や次の時間に使います。動画のデータ量は「発展」で、ドリルの「動画」のときだけ出ます（電卓を使ってよい）。
  • D3 ネットワーク通信シミュレータ：1時間目「① 組み立て・② Webページが届くまで」、2時間目「③ 故障・④ のぞき見・⑤ ドリル（発展）」。目安は ① 15〜20分・② 15分・③ 15分・④ 10〜15分・⑤ 15分です。ドリルの /25・/28 は「チャレンジ問題」で、クリアには関係ありません。
  • D4 情報セキュリティ体験ラボ：D4_情報セキュリティ体験ラボ_先生用ガイド.html（zip の中では「先生用ガイド_情報セキュリティ体験ラボ.html」）の6時間の計画のとおりです。暗号ラボは2回に分けて（1回目ステップ1〜3、2回目ステップ4〜7）行います。RSA の計算は「発展」です。
  • D5 ネット詐欺 追体験ラボ：① ワンクリック詐欺 〜 ⑤ にせの通販サイトの5つの詐欺（各10分）を体験し、⑥ まとめとふりかえり（10分）で共通の手口と自分の行動をまとめます。
  • D6 双方向コンテンツ制作スタジオ：ひな形（カウンター・クイズ・バグを直そう・アンケート集計）で操作としくみをつかみ、企画・改善メモを書いて制作し、友だちに使ってもらって改善します（くわしくは教材の README）。作品には、サーバーとのやりとり（server の命令）を1つ以上入れさせます（学習指導要領 D(2) のネットワークを利用した双方向性のため）。作品一覧で「📡 サーバーあり」と表示されます。
  • D7 計測・制御シミュレータ：1時間目「① 街灯・② 自動ドア（各20分）」、2時間目「③ 信号機（40分）」、3時間目「④ 押しボタン式信号機（25分）・⑤ 自由に作る（発展。10〜15分）」。

  • D10 ハッシュ化体験ラボ（発展編だけ）：1時間目「① ハッシュ値を作る 〜 ④ もとにもどせる？」、2時間目「⑤ パスワードの守り方・⑥ 改ざんを見つける・⑦ クイズとふりかえり」。1時間で行うときは、①・②・④・⑤・⑦ を中心にします。
  • D11 問題解決ノート：教科書の 4編2章・3章の「2 問題の発見と課題の設定」「5 問題解決の評価、改善・修正」と、4章1「情報の技術の最適化」で使います（4分野で同じ形のノートで、観点と例が情報の技術用になっています）。番号は D11 ですが、D6 双方向コンテンツ制作スタジオや D7 計測・制御シミュレータ・D8 火星探査ロボット・シミュレータの制作の前と制作のあとの2回に分けて開きます。制作の前に「① 問題の発見」で、「こうだったらいいのに」「不便だな」を付箋に書いて集め（社会・安全・環境・経済の観点のアイコンを付ける）、「問題?課題?」クイズで2つのちがいを確かめてから、自分の課題を1つ決めます。制作のあとで「② 評価、改善・修正」を開き、機能・使いやすさ・安全性・他者の権利・費用・環境への配慮の観点で5段階に評価して、はじめの目標とレーダーチャートでくらべ、制作の過程（設計どおりに作れたか・デバッグ・使う人の意見・著作物や個人情報）も振り返って、よかった点・改善・修正の方法を書きます。4章では「③ 技術の最適化」で、スマートフォンのロック（4けたの暗証番号・長いパスワード・生体認証）・車の運転（人が運転・運転支援・自動運転）・動画の配信（高画質・標準画質・低画質）の3つの案を、観点の重みや制約条件を変えてくらべ、「いちばんよい案」が入れかわることを確かめます（点は考えるための目安です）。「記録」の「印刷する」で A4 の問題解決シートとして印刷でき、書いていない欄は線だけになるので白紙のシートとしても配れます。

4. 記録の保存と提出

保存

  • 学習の記録は、その端末のブラウザの中にだけ保存されます（ほかの端末とは共有されません）。外部には送られません。
  • 第1.7版で記号と番号を付け直しましたが、保存の場所（保存名）は前の版と同じなので、前の版の記録もそのまま続きから使えます。書き出したファイルの中のページの名前は、新しい番号（「① 画像のデジタル化」など）になります。

提出

  • 提出させるときは、メニューの「記録をまとめて書き出す」で、組・番号・名前を1回入れて「JSONで書き出す（先生に出す）」を押させてください。11の教材の記録（進み具合・ふりかえり・作品の計画や改善メモ・もとのデータ）が1つの JSON ファイルになります（ファイルの中の app は「情報の技術 教材集」、kind は「記録まとめ」です）。ファイル名は「情報の技術_記録まとめ_3組7番_2026-10-13.json」のように、組・番号・日付が入ります。
  • 組か番号が空のときは書き出せません。まだ使っていない教材は「まだ記録なし」と表示されます。
  • 「CSVで書き出す（表計算ソフト用）」は、表計算ソフトで見るためのものです。提出は JSON にします。教材ごとの「ふりかえり・記録」からも、これまでどおり書き出せます。
  • Chromebook では、書き出したファイルは「ファイル」アプリの「ダウンロード」フォルダに入ります。クラスルームの課題に添付させると集めやすくなります。
  • 仮想CPUラボの記録には、課題ごとのプログラムと「答えの例を見たか」が入ります。情報セキュリティ体験ラボの判断ロールプレイは「最初に選んだ結末」と「いちばんよかった結末」が残ります。どちらも成績に使わないことを生徒に伝えてあります。

提出されたファイルを見る

  • 4分野共通の 全分野_振り返り一覧.html で、ほかの分野と同じように、提出された JSON のふりかえりを一覧にできます。
  • 情報セキュリティ体験ラボの完了人数や事前・事後テストの伸びは、ラボの先生用ページの「クラスの記録を集計する」で見られます（D4_情報セキュリティ体験ラボ_先生用ガイド.html の 4. を見てください）。

記録を消す

端末を共有している場合は、提出したあと、メニューのいちばん下の「はじめからやり直す」で「この端末の記録をすべて消す」を押すと、11の教材の記録がまとめて消えます（「記録をまとめて書き出す」の組・番号・名前も消えます。ふりがな・文字の大きさなどの表示の設定と、差し替えた問題データは残ります）。1つの教材だけ消すときは、その教材の「ふりかえり・記録」のページから消せます。

先生用ページの開き方

先生用ページは、生徒が開かないようにメニューには出していません。先生の端末で、ファイルのアドレスの最後に次の文字を足して開きます。

5. 授業で使うときの注意

  • デジタル化ラボの「聞きくらべ」：音が出ます。イヤホンを使うか、先生の画面で全員いっしょに聞き、生徒の端末は音を消してグラフを見させます。
  • 情報セキュリティ体験ラボの理解度チェック：事前テストと事後テストは、それぞれ最初の1回の点が記録に残ります（2回目からは練習）。事前テストのあとは点数だけが出て、答えと解説は事後テストのあとに見られます。先生用ページで、両方受けた生徒の伸びが見られます。
  • 相談窓口：情報セキュリティ体験ラボに相談窓口の電話番号が出ます（2026年10月13日に公式ページで確認）。年度ごとに確かめてください。変え方は、情報セキュリティ体験ラボの先生用ガイドにあります。
  • 双方向コンテンツ制作スタジオのアンケート作品：この教材のサーバーは端末ごとの模型なので、ほかの端末の答えは集まりません。クラスのアンケートは、班の中で1台の端末を回して答えてもらいます。
  • 双方向コンテンツ制作スタジオの作品の保存：作品は自動で保存されます。端末をかえるときや念のために残すときは「ファイルに保存（.json）」を使います。
  • 登場する会社名・アドレス・地名・学校名はすべて架空です。

6. こまったとき

Chromebook で開くと教材が動かない
Google ドライブの画面で開くと「プレビュー」になり、教材は動きません。ファイルをダウンロードしてから、「ファイル」アプリの「ダウンロード」フォルダでダブルクリックして開きます（1. の「端末ごとの開き方」）。
iPad で開くと教材が動かない
「ファイル」アプリでタップすると「プレビュー」になることがあります。校内の Web サーバー（できれば https）にファイルを置き、Safari でその URL を開いてください。
デジタル化ラボで録音できない
Chrome がマイクを使ってよいか確認してきたら「許可」を押させます。断ってしまったときのやり直し方は、デジタル化ラボの録音の前の説明にあります。iPad では、https のページでないとマイクが使えません。
前の時間の記録が見えない
記録はその端末のブラウザの中にだけ残ります。前と同じ端末・同じブラウザで開いているか確かめてください。
先生用ページが開かない
アドレスに # から後ろがすでに付いているときは、それを消してから #/security-lab/teacher などを足します（4. の「先生用ページの開き方」）。

第1.3版（2026年10月13日）

レビューで「直すともっとよくなる」とした所（30件）を直しました。授業で気をつけたい変更は次のとおりです。

  • デジタル化ラボ：データ量の計算ドリルのステップ2は、「いろいろ」で8問以上のときだけクリアになります（前にクリアした生徒の ✓ は残ります）。録音の前に「許可」を押すことと、断ってしまったときのやり直し方を書きました。
  • 仮想CPUラボ：手計算くらべの「昔のパソコン」の時間を、1命令に合図4回で計算するようにしたので、前の4倍の時間が出ます。答え合わせでまちがえた入力を、そのまま試せるボタンを付けました。
  • ネットワーク通信シミュレータ：店の名前を情報セキュリティ体験ラボとそろえて「クモストア（kumo-store.example）」にしました。図の文字を大きくしました。
  • 情報セキュリティ体験ラボ：練習は、モジュールを選んでから、1回10問までになりました。理解度チェックの問題は単元の順に出ます（点数のつけ方は同じです）。著作権クイズでは、△のときによりよい答えが出て、同じ場面をやり直せます。
  • 計測・制御シミュレータ：不合格になった時刻をグラフに赤い点線で出し、記録にセンサの値を書くようにしました。押しボタンを短く押しても、プログラムが気づくようにしました。
  • 双方向コンテンツ制作スタジオ：「バグを直そう」の見本に使い方の説明を入れ、「エディタで直す」でまちがいの行へ移るようにしました。デバッグとサーバーのページに、次にすることの案内を付けました。
  • 教材集：再読みこみしても、さいごに開いていたページから始まります。メニューのカードから学習指導要領の記号を外し、「先生へ」にまとめました。

第1.2版（2026年10月13日）

レビューで「多くの生徒がつまずく・迷う」とした所を直しました。

  • 教材集：上のバーに「ふりがな」「大きな文字」を付け、6教材にまとめてかかるようにしました。教材の切りかえボタンに名前を付け、上のバーを低くしました。6教材の記録を1つのファイルで出せる「記録をまとめて書き出す」を足しました。タブレットの縦向きで、教材の中のメニューが全部見えるようにしました。
  • 6教材すべて：記録を書き出すとき、組・番号が空なら書き出さず、書き出したらファイル名を表示するようにしました。答えをまちがえたときにもう一度選べるクイズを増やしました。時間の目安と、1時間ごとの進め方の例を付けました。
  • デジタル化ラボ：動画のデータ量を「発展」にし、聞きくらべに音のグラフと「何が起きているか」の説明を付けました。単位の決まり（8ビット＝1バイト、1KB＝1024バイト）を、はじめて出る所に書きました。
  • 仮想CPUラボ：課題を必修・発展・チャレンジに分け、ヒントが答えそのものにならないように直しました。「この答えをプログラム欄に入れる」ボタンをなくしました。✓ は、本当にできたときだけ付くようにしました（前に開いただけで付いた ✓ は消えます）。
  • ネットワーク通信シミュレータ：ドリルを授業で説明する範囲（/24）にし、2進数の読み方のカードを付けました。アニメーションの一時停止と「1つずつ進む」、機器を消すときの確認と「1つもどす」を足しました。届かないわけを、くわしく出すようにしました。
  • 情報セキュリティ体験ラボ：暗号ラボを2回に分け、RSA の計算を発展にしました。とても大きな数を「10の◯乗」と「宇宙の年齢の◯倍」で表すようにしました。先生用ページをメニューから外し、相談窓口を足しました。ふりがなの言葉を82語ふやしました。
  • 双方向コンテンツ制作スタジオ：ブロックを入れる場所が見えるようにし、「もし」の条件を3つの欄に分けました。ブロックと実行画面を並べて見られる表示と、「大きな文字」を足しました。
  • 計測・制御シミュレータ：ブロックを入れる場所と、ブロックを「もし」の中や外へ動かすボタンを付けました。テストのボタンをプログラムの上に置きました。模範プログラムを先生用ページへ移しました。場面4は、はじめのプログラムを少し進めた形にしました（場面4をすでに始めた生徒は、「はじめのプログラムにもどす」を押したときだけ変わります）。
