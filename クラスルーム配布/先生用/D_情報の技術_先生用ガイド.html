情報の技術 先生用ガイド

中学校 技術・家庭(技術分野) 内容D「情報の技術」 ・ 生徒に配るファイル: D_情報の技術_統一版.html

9つの体験教材を、「基本編」「発展編」に分けたメニュー付きの1つのHTMLファイルにまとめたものです。インターネットへの接続やインストールは不要で、外部のサイトには一切つながりません。入力した内容や学習の記録は、その端末のブラウザの中にだけ保存されます。

1. 配り方と開き方

配り方

  1. D_情報の技術_統一版.html を、校内の共有フォルダ・USBメモリ・各端末にコピーします(元のファイル名は D-information/dist/情報の技術_体験教材集.html。zip の中では 情報の技術_体験教材集.html です。中身は同じです)。
  2. ブラウザ（Chrome・Edge など）で開きます。端末の種類による開き方のちがいは、下の「端末ごとの開き方」を見てください。

1つの教材だけを配りたいときは、1つずつ配るとき フォルダ(zip の中では「個別の教材」フォルダ)のファイルを使ってください。中身は教材集と同じです。

校内のWebサーバーに置いて使うこともできます（教材集のファイルを置くだけで動きます）。

端末ごとの開き方

配る前に、生徒と同じ端末で一度開いて確かめてください。

  • Chromebook：Google ドライブの画面でファイルを開くと「プレビュー」になり、教材は動きません。次の手順で開きます。
    1. Google ドライブ（またはクラスルーム）で、ファイルをダウンロードします。
    2. ランチャーから「ファイル」アプリを開き、「ダウンロード」フォルダの D_情報の技術_統一版.html をダブルクリックします。Chrome で開きます。
    3. 記録はその端末の Chrome に残ります。次の時間も同じ端末で開けば、続きから使えます。
    デジタル化ラボの録音では、Chrome がマイクを使ってよいか確認してくるので「許可」を押させます。
  • Windows：ファイルを端末か共有フォルダに置き、ダブルクリックで開きます。
  • iPad：「ファイル」アプリでファイルをタップすると「プレビュー」になり、教材が動かないことがあります。校内の Web サーバー（できれば https）にファイルを置き、Safari でその URL を開く方法をおすすめします。デジタル化ラボの録音も、https のページでないとマイクが使えません。

画面の使い方

  • メニューの「基本編」「発展編」のタブを選び、カードから教材を選びます。カードの「使うところ」に、その編で使うページの名前が出ます。
  • 上のバーの左端の「◀ メニュー」（または教材集の名前）を押すとメニューに戻ります。ほかの教材へは、上のバーの右の教材の名前を押して切りかえます（はばがせまい画面では「教材をかえる ▾」を押すと名前の一覧が出ます）。
  • 切りかえても、開いていた教材の作業はそのまま残ります。ふりかえりの文は書いている途中で自動で保存されるので、ページを再読みこみしても消えません。再読みこみをしても、それぞれの教材はさいごに開いていたページから始まります（同じタブの中だけ）。
  • 上のバーの「ふりがな」「大きな文字」は、9つの教材とメニューにまとめてかかります。漢字の言葉に読みがなが付き、文字が大きくなります。プログラムを書く欄・入力欄・図の中の文字には、ふりがなは付きません。この設定は「はじめからやり直す」でも消えません。教材集の中では、各教材にもともとある「ふりがな」「大きな文字」のボタンは、上のバーのボタンにまとめています（情報セキュリティ体験ラボの「やさしい日本語のまとめ」は教材の中に残ります）。

2. 教材の一覧(基本編・発展編)

3. 単元での使い方

基本編のカードは、おすすめの順（デジタル化ラボ → 仮想CPUラボ → ネットワーク通信シミュレータ → 情報セキュリティ体験ラボ → ネット詐欺 追体験ラボ → 双方向コンテンツ制作スタジオ → 計測・制御シミュレータ → 生成AIのしくみラボ）にならんでいます。

教材ごとの進め方の例

  • デジタル化ラボ：1時間目「はじめに・画像・音」、2時間目「2進数・圧縮・ふりかえり」。データ量の計算ドリルは、次の時間のはじめや復習に使います。動画のデータ量は「発展」で、ドリルの「動画」のときだけ出ます（電卓を使ってよい）。
  • 仮想CPUラボ：1時間目「図解（20分）・ステップ実行（30分）」、2時間目「課題（30分）・手計算くらべ・ふりかえり・記録の書き出し（20分）」。課題は1〜4が必修です。2時間目の後半は、課題の途中でも全員が手計算くらべに移ります。
  • ネットワーク通信シミュレータ：1時間目「1 組み立て・2 Webページが届くまで」、2時間目「3 故障・4 のぞき見・5 ドリル」。ドリルの /25・/28 は「チャレンジ問題」で、クリアには関係ありません。
  • 情報セキュリティ体験ラボ：D4_情報セキュリティ体験ラボ_先生用ガイド.html（zip の中では「先生用ガイド_情報セキュリティ体験ラボ.html」）の7時間の計画のとおりです。暗号ラボは2回に分けて（1回目ステップ1〜3、2回目ステップ4〜7）行います。RSA の計算は「発展」です。デジタル化ラボとネットワーク通信シミュレータを先に使った場合は、「1 デジタル化と情報量」と「6 ネットワーク通信の模擬」を省いて5時間にできます（下の「内容が重なっている単元」を見てください）。
  • 双方向コンテンツ制作スタジオ：ひな形（カウンター・クイズ・バグを直そう・アンケート集計）で操作としくみをつかみ、企画・改善メモを書いて制作し、友だちに使ってもらって改善します（くわしくは教材の README）。作品には、サーバーとのやりとり（server の命令）を1つ以上入れさせます（学習指導要領 D(2) のネットワークを利用した双方向性のため）。作品一覧で「📡 サーバーあり」と表示されます。
  • 計測・制御シミュレータ：1時間目「場面1・2（各20分）」、2時間目「場面3（40分）」、3時間目「場面4（25分）・場面5（10〜15分）」。

内容が重なっている単元

情報セキュリティ体験ラボの次の2つの単元は、ほかの教材と内容が重なります。どちらも残してあり、教材集の中で開いたときだけ、単元のさいご（ふりかえりのあと）に「もっとくわしく学びたいとき」の案内とボタンが出ます。移った先のページの上と下に「← 情報セキュリティ体験ラボにもどる」が出て、押すと同じ単元にもどれます。

情報セキュリティ体験ラボの単元くわしく扱う教材使い分けの目安

4. 記録の保存と提出

保存

  • 学習の記録は、その端末のブラウザの中にだけ保存されます（ほかの端末とは共有されません）。外部には送られません。

提出

  • 提出させるときは、メニューの「記録をまとめて書き出す」で、組・番号・名前を1回入れて「JSONで書き出す（先生に出す）」を押させてください。9つの教材の記録（進み具合・ふりかえり・作品の計画や改善メモ・もとのデータ）が1つの JSON ファイルになります。ファイル名は「情報の技術_記録まとめ_3組7番_2026-10-13.json」のように、組・番号・日付が入ります。
  • 組か番号が空のときは書き出せません。まだ使っていない教材は「まだ記録なし」と表示されます。
  • 「CSVで書き出す（表計算ソフト用）」は、表計算ソフトで見るためのものです。提出は JSON にします。教材ごとの「ふりかえり・記録」からも、これまでどおり書き出せます。
  • Chromebook では、書き出したファイルは「ファイル」アプリの「ダウンロード」フォルダに入ります。クラスルームの課題に添付させると集めやすくなります。
  • 仮想CPUラボの記録には、課題ごとのプログラムと「答えの例を見たか」が入ります。情報セキュリティ体験ラボの判断ロールプレイは「最初に選んだ結末」と「いちばんよかった結末」が残ります。どちらも成績に使わないことを生徒に伝えてあります。

提出されたファイルを見る

  • 4分野共通の 全分野_振り返り一覧.html で、ほかの分野と同じように、提出された JSON のふりかえりを一覧にできます。
  • 情報セキュリティ体験ラボの完了人数や事前・事後テストの伸びは、ラボの先生用ページの「クラスの記録を集計する」で見られます（D4_情報セキュリティ体験ラボ_先生用ガイド.html の 4. を見てください）。

記録を消す

端末を共有している場合は、提出したあと、メニューのいちばん下の「はじめからやり直す」で「この端末の記録をすべて消す」を押すと、9つの教材の記録がまとめて消えます（「記録をまとめて書き出す」の組・番号・名前も消えます。ふりがな・文字の大きさなどの表示の設定と、差し替えた問題データは残ります）。1つの教材だけ消すときは、その教材の「ふりかえり・記録」のページから消せます。

先生用ページの開き方

先生用ページは、生徒が開かないようにメニューには出していません。先生の端末で、ファイルのアドレスの最後に次の文字を足して開きます。

ページ教材集で開くとき1つずつ配るファイルで開くとき
情報セキュリティ体験ラボの先生用ページ（使うモジュールの設定・問題データの差し替え・クラスの集計）D_情報の技術_統一版.html#/security-lab/teacherD4_情報セキュリティ体験ラボ.html#/teacher

  • ファイル名がちがうとき（zip の中の 情報の技術_体験教材集.html や「個別の教材」フォルダのファイルなど）も、足す文字は同じです。
  • アドレスに # から後ろがすでに付いているときは、それを消してから足します。
  • 計測・制御シミュレータは、教材を開いた状態で画面をクリックし（入力欄の外）、キーボードで teacher と打っても開きます。
  • 情報セキュリティ体験ラボの設定を変えた端末は、先生用ページの「標準に戻す」で元にもどせます。

5. 授業で使うときの注意

  • デジタル化ラボの「聞きくらべ」：音が出ます。イヤホンを使うか、先生の画面で全員いっしょに聞き、生徒の端末は音を消してグラフを見させます。
  • 情報セキュリティ体験ラボの理解度チェック：事前テストと事後テストは、それぞれ最初の1回の点が記録に残ります（2回目からは練習）。事前テストのあとは点数だけが出て、答えと解説は事後テストのあとに見られます。先生用ページで、両方受けた生徒の伸びが見られます。
  • 相談窓口：情報セキュリティ体験ラボに相談窓口の電話番号が出ます（2026年10月13日に公式ページで確認）。年度ごとに確かめてください。変え方は、情報セキュリティ体験ラボの先生用ガイドにあります。
  • 双方向コンテンツ制作スタジオのアンケート作品：この教材のサーバーは端末ごとの模型なので、ほかの端末の答えは集まりません。クラスのアンケートは、班の中で1台の端末を回して答えてもらいます。
  • 双方向コンテンツ制作スタジオの作品の保存：作品は自動で保存されます。端末をかえるときや念のために残すときは「ファイルに保存（.json）」を使います。
  • 登場する会社名・アドレス・地名・学校名はすべて架空です。

6. こまったとき

Chromebook で開くと教材が動かない
Google ドライブの画面で開くと「プレビュー」になり、教材は動きません。ファイルをダウンロードしてから、「ファイル」アプリの「ダウンロード」フォルダでダブルクリックして開きます（1. の「端末ごとの開き方」）。
iPad で開くと教材が動かない
「ファイル」アプリでタップすると「プレビュー」になることがあります。校内の Web サーバー（できれば https）にファイルを置き、Safari でその URL を開いてください。
デジタル化ラボで録音できない
Chrome がマイクを使ってよいか確認してきたら「許可」を押させます。断ってしまったときのやり直し方は、デジタル化ラボの録音の前の説明にあります。iPad では、https のページでないとマイクが使えません。
前の時間の記録が見えない
記録はその端末のブラウザの中にだけ残ります。前と同じ端末・同じブラウザで開いているか確かめてください。
先生用ページが開かない
アドレスに # から後ろがすでに付いているときは、それを消してから #/security-lab/teacher などを足します（4. の「先生用ページの開き方」）。
