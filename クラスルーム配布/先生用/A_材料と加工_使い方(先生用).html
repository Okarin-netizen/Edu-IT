材料と加工 教材アプリ 使い方(先生用)

技術分野「材料と加工の技術」の授業で使う、オフラインで動く6つの学習アプリと、先生用の提出ファイル一覧ビューアです。10インチの Chromebook(1280×800)で使いやすいように作っています。

アプリのメニューを開く ▶

1. 開き方

A. いちばん簡単な方法(Chromebook に置いて開く)

  1. zip ファイルを Chromebook の「ファイル」アプリでダブルクリックし、中のフォルダ materials-apps を「マイファイル」(ダウンロードなど)にコピーします。
  2. フォルダの中の index.html をダブルクリックすると、Chrome でメニューが開きます。
  3. メニューから使うアプリを選びます。インターネットにつながっていなくても動きます。

Google ドライブや Classroom で配るときは、zip のままではなくフォルダごと配り、生徒の端末にダウンロードしてから開かせてください(ドライブの画面の中では HTML は動きません)。

B. 学校の Web サーバーなどに置く方法(アプリとしてインストールできる)

  1. フォルダ materials-apps の中身を、https で見られる場所(学校のサーバー、GitHub Pages など)にそのまま置きます。
  2. 生徒は一度だけネットにつないで、その URL の index.html を開きます。開いたアプリは自動で端末に保存され、そのあとは機内モードでも使えます。
  3. Chrome のアドレスバーの「インストール」から、アプリとしてホーム画面に追加することもできます。

C. 1つのファイルで配る方法(1ファイル版)

  1. materials-apps_1file.html は、メニュー・6つのアプリ・先生用ビューア・この使い方を1つにまとめたファイルです。
  2. Classroom などでこのファイル1つを配り、生徒は端末にダウンロードしてからダブルクリックで開きます。

1ファイル版でできないこと: アプリとしてのインストール(B の方法)と、ネットから新しい版を自動で受け取ることはできません。直したときは、新しいファイルを配り直してください。 保存のしくみはフォルダ版と同じで、作品はその端末の Chrome の中に残ります。同じ端末で、1ファイル版とフォルダ版をどちらも端末のファイルとして開いたときは、保存した作品は共通になります(B の方法で Web から開いたときは別の保存場所になります)。混乱しないよう、クラスではどちらか一方に決めて使うのがおすすめです。

3. 画面の上のボタン

  • ◀ メニュー: アプリの一覧にもどります。
  • ふりがな: ふりがな(総ルビ)の表示・非表示を切りかえます。設定はすべてのアプリで共通です。
  • 文字: 文字の大きさを 小・中・大・特大 に切りかえます。
  • くっきり: 色のコントラストを強くします(見えにくい生徒向け)。

4. 作品の保存・提出・削除

  • 生徒が作ったもの・記録は、その端末の Chrome の中に自動で保存されます(ほかの端末とは共有されません)。
  • 提出させるときは、メニューの「保存したデータ」で組・番号・名前を入れてから「すべてファイルに書き出す」を押させ、できたファイル(JSON 形式)を Classroom などで提出させます。ファイル名にも組・番号・名前が入ります。各アプリの「ファイルに書き出す」でも、そのアプリの分だけ出せます。書き出したファイルは、メニューや各アプリの「ファイルから読み込む」で端末にもどせます。
  • データの削除: 各アプリの画面のいちばん下にある「保存データの管理(削除)」で、作品を1件ずつ、またはそのアプリの分をすべて消せます。メニューの「保存したデータ」の中の「データの管理(削除)」を開くと出る「データの削除」では、すべてのアプリの分をまとめて消せます(生徒がまちがえて押さないよう、ふだんは閉じてあります)。どれも確認のあとで消え、もとには戻せません。端末を次の学年に引きつぐときなどに使ってください。
  • Chrome の閲覧履歴の削除で「Cookie と他のサイトデータ」を消したときも、保存した作品は消えます。大切な記録は書き出しておくよう伝えてください。

5. 提出されたファイルを見る(先生用ビューア)

  1. メニューのいちばん下にある「先生用」を押して開き、その中の「提出ファイル一覧ビューア」を開きます(生徒の画面では、ふだんは閉じてあります)。
  2. 「ファイルを選ぶ」で生徒のファイルをまとめて選ぶか、「フォルダを選ぶ」で提出ファイルの入ったフォルダを選びます(ドラッグして置いてもよい)。Classroom の提出物は、ドライブからフォルダごとダウンロードしておくと便利です。
  3. 「生徒ごと」で、だれがどのアプリを出したか、ふりかえりを書いたか(✎)が一覧で見られます。「アプリごと」では、1つのアプリについて全員の選んだ材料・理由・感想などを並べて見られます。名前を押すと、その生徒の内容をくわしく見られます。
  4. 「表を CSV で保存」で、いま見ている表を Excel やスプレッドシートで開けるファイルにできます。

ビューアは読み込んだ内容を端末に保存しません。画面を閉じると一覧は消えます(生徒のファイルはそのまま残ります)。名前は、メニューから書き出したファイルなら入力された組・番号・名前、そうでなければファイル名から付けます。

6. 授業で使うときの注意

  • 材料の強さ・たわみ・収縮などの数値は、文献の代表値を丸めた目安です。実物の観察や実験と合わせて使ってください。
  • 工具の安全トレーナーは、作業前の確認のためのものです。実技の指導の代わりにはなりません。
  • アプリの図と文章は独自に作ったもので、教科書の図・文章は使っていません。
  • アプリは外部と通信しません。生徒の情報がインターネットに送られることはありません。

7. こまったとき

  • 画面が古いまま(B の方法で配ったとき): 一度ネットにつないで開き直すと新しい版になります。
  • 保存した作品が見えない: 前と同じ端末・同じ Chrome のユーザーで、同じ場所に置いたフォルダから開いているか確かめてください(置き場所が変わると、別の保存場所になります)。
  • 1ファイル版で書き出しや読み込みができない: ファイルを Google ドライブの画面の中で開いていないか確かめてください。端末にダウンロードしてから開きます。
  • 文字が画面に入りきらない: 画面の上の「文字」で小さくするか、Chrome の表示倍率(Ctrl と -)を変えてください。
