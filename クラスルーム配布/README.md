# クラスルーム配布用（生徒用と先生用を分けたもの）

技術分野の4つの分野の教材を、**生徒に配るもの**と**先生が使うもの**に分けて置いています。
どれも HTML ファイル1つで動き、インターネットは不要です。

```
クラスルーム配布/
├─ 生徒に配る/   … Classroom に「資料」として載せるのはここのファイル
└─ 先生用/       … 先生が読む手引き（生徒には配らない）
```

## 生徒に配る（`生徒に配る/`）

1つの分野につき **ファイル1つ** を配れば、メニューから全部の教材が使えます。

| 分野 | 配るファイル | 中に入っている教材 |
|---|---|---|
| A 材料と加工 | `A_材料と加工_教材アプリ.html` | M1 材料選択ナビ・M2 木材ラボ・M3 構造強化ラボ・M4 製図トレーナー・M5 木取り・M6 工具の安全・M7 第三角法 立体メーカー |
| B 生物育成 | `B_生物育成_教材集.html` | B1 育成日誌・B2 育成環境コントローラ・B3 動物飼育・水産・B4 栽培暦ビルダー |
| C エネルギー変換 | `C_エネルギー変換_学習アプリ.html` | E1 エネルギー変換ゲーム・E2 電気回路ラボ・E3 機構ラボ・E4 保守点検ラボ・E5 回路設計シート |
| D 情報 | `D_情報の技術_体験教材集.html` | デジタル化・仮想CPU・ネットワーク・情報セキュリティ・双方向コンテンツ・計測制御 |

**第三角法 立体メーカーだけ**を配りたいときは `A_第三角法_立体メーカー(単体).html` を配ります（中身は材料と加工の教材アプリの M7 と同じです）。

**生成AIのしくみラボ**は `D_生成AIのしくみラボ.html`、**ハッシュ化体験ラボ**は `D_ハッシュ化体験ラボ.html` を配ります（どちらも教材集とは別のファイルです）。

**情報の教材を1つだけ配りたいとき**は、`D_情報の技術_1つずつ配るとき/` の中のファイル（D1〜D6）を配ります。中身は教材集と同じです。

## Classroom で配るときの注意

1. `生徒に配る/` のファイルを Classroom の課題・資料に添付します。
2. 生徒は **端末にダウンロードしてから** ダブルクリックで開きます。
   Google ドライブの画面（プレビュー）の中では動きません。
3. 学習の記録は、その端末のブラウザの中だけに保存されます。毎回同じ場所のファイルを開くと続きから使えます。
4. 提出は、各教材の「書き出す」でできたファイルを Classroom に出させます。

### 生徒用ファイルの中にある「先生用」ボタンについて

先生用の機能（提出の集計など）は、別のファイルではなく**生徒用ファイルの中**に入っています。
先生も生徒と**同じファイルを開いて**、次の場所から使います（生徒の画面ではふだん閉じています）。

| 分野 | 場所 | できること |
|---|---|---|
| A | メニューのいちばん下の「先生用」 | 提出ファイル一覧ビューア（生徒が出したファイルをまとめて一覧にする・CSV 保存） |
| B | メニューの「👩‍🏫 先生用」 | 先生用ガイド、記録のまとめ書き出し・削除 |
| C | 「⚙️ 表示の設定(先生用)」 | 表示の設定 |
| D（セキュリティ） | アドレスの最後に `#/teacher` を付けて開く | クラスの記録の集計、使うモジュールの設定、問題の差し替え |

## 教材を直したあと

各分野のビルドで `dist/` を作り直したあと、次を実行するとこのフォルダが新しくなります。

```
python3 クラスルーム配布/まとめる.py
```

元のファイルは各分野の `dist/`（配布用）と `docs/`（先生用の文書）にあります。くわしくは `まとめる.py` に書いてあります（A は `A-materials/build/build-single.py` で1ファイルにしてから写します）。
