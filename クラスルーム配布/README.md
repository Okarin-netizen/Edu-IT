# クラスルーム配布用（生徒用と先生用を分けたもの）

技術分野の4つの分野の教材を、**生徒に配るもの**と**先生が使うもの**に分けて置いています。
どれも HTML ファイル1つで動き、インターネットは不要です。

```
クラスルーム配布/
├─ 生徒に配る/   … Classroom に「資料」として載せるのはここのファイル
└─ 先生用/       … 先生用ガイドと先生用の道具（生徒には配らない）
```

## 生徒に配る（`生徒に配る/`）

1つの分野につき **統一版のファイル1つ** を配れば、その分野の教材が全部使えます。
どの統一版も、メニューが **「基本編」「発展編」** のタブに分かれています。

- **基本編**: 学習指導要領にあり、どの教科書にものっている内容。全員が学ぶ。
- **発展編**: 教科書の「発展」「コラム」にあたる内容や、数値での設計・計算、新しい技術を使う内容。基本編が終わった生徒や選択の課題に。
- 1つの教材が両方の編に出ることもあります。カードの「使うところ」に、その編で使うタブ・ページの名前が出ます。
- 教材の記号は4分野とも **分野の文字 + 番号**(A1〜A8・B1〜B5・C1〜C7・D1〜D10)で、**番号の順 = おすすめの順 = メニューのカードの順** です。基本編の上に「おすすめの順番: A1 → A2 → …」が出ます。
- アプリの中のタブも「基本 → 発展」の順で、**①②③…の続き番号** です。基本編の「使うところ」が ①〜③ なら、発展編は ④ から始まります。授業では「① から ③ までやろう」のように番号で指示できます(「はじめに」「振り返り」「記録」のタブには番号がありません)。
- どの教材のどこがどちらの編かは、`先生用/全分野_基本編と発展編.html` に学習指導要領の項目と理由つきでまとめています。

| 分野 | 配るファイル(統一版) | 基本編 | 発展編 |
|---|---|---|---|
| A 材料と加工 | `A_材料と加工_統一版.html` | A1〜A6 の基本のタブ | A2・A3・A5 の発展のタブ、A7 第三角法 立体メーカー |
| B 生物育成 | `B_生物育成_統一版.html` | B1〜B5 の基本のタブ | B1 のくらべる、B2 の水質・生態系、B3 の再計算・書き出し、B4 の予測、B5 の全部を自動に・スマート農業 |
| C エネルギー変換 | `C_エネルギー変換_統一版.html` | C1〜C7 の基本のステージ・課題・タブ | C1 の蓄電池・自由実験、C2 の測定・LEDと抵抗・電気料金、C3 の数値の設計課題、C5 の抵抗値の課題、C6 の発電方法くらべ・風が変わる日、C7 の損失の計算・周波数 |
| D 情報 | `D_情報の技術_統一版.html` | D1〜D8・D10 の基本のページ | D1 の圧縮、D2 の仮想CPUの実行と課題、D3 の IPアドレス、D4 のハッシュ体験、D8 の生成AIのしくみ、D9 ハッシュ化体験ラボ、D10 の ④ 色センサ・⑤ 記録に挑戦 など |

D の統一版には、これまで別のファイルで配っていた **生成AIのしくみラボ・ネット詐欺 追体験ラボ・ハッシュ化体験ラボ** も入っています（10の教材）。
記号と番号をそろえたとき(A 第2.4版・B 第1.4版・C 第1.4版・D 第1.7版)、生物育成とエネルギー変換は記号の入った保存名も変えたので、それより前の版で使った記録は続きから使えません。材料と加工と情報の技術の記録は、そのまま続きから使えます。

**1つの教材だけを配りたいとき**は、`1つずつ配るとき/` の中のファイルを配ります（中身は統一版と同じです）。

- `A7_第三角法_立体メーカー.html` … A の A7 だけ（メニューへ戻るボタンは出ません）
- `D1_…` 〜 `D10_…` … 情報の技術の10の教材を1つずつ(番号は統一版の記号と同じ)

### 振り返りを隠すとき（`振り返りなし/`）

振り返りを Google フォームなど別の方法で集めるときは、教材の中の振り返り（タブ・欄・カードの印）を出さないようにできます。

- **Classroom で配るとき**: `生徒に配る/振り返りなし/` の中の、同じ名前のファイルを配ります（中身は同じで、振り返りだけが出ません）。1つずつ配るときのファイルは `振り返りなし/1つずつ配るとき/` にあります。
- **生徒用サイトで使うとき**: アドレスの最後に `?furikaeri=off` を付けて開くよう知らせます（例: `https://okarin-netizen.github.io/Edu-IT/?furikaeri=off`）。一度開くと、その端末で覚えています。`?furikaeri=on` を付けて開くと元にもどります。
- 隠しても、それまでに書いた振り返りは消えません。

## 先生用（`先生用/`）

ファイルの名前は **「分野_名前.html」** にそろえています。

- 分野ごとの説明は、どれも **`X_分野名_先生用ガイド.html`** という名前です。
  4つとも同じ章立て（1. 配り方と開き方 → 2. 教材の一覧（基本編・発展編）→ 3. 単元での使い方 → 4. 記録の保存と提出 → 5. 授業で使うときの注意 → 6. こまったとき → 7. 更新履歴）と、同じ見た目（`shared/eduit-guide.css`）です。印刷もできます。
- 4分野に共通の道具は **`全分野_名前.html`** です。

| 分野 | ファイル | 書いてあること |
|---|---|---|
| A 材料と加工 | `A_材料と加工_先生用ガイド.html` | 統一版（A1〜A8）の配り方、提出ファイルの集め方、先生用ビューアの使い方 |
| B 生物育成 | `B_生物育成_先生用ガイド.html` | 統一版（B1〜B5）の配り方、ねらいと時間の目安、振り返りの回収と評価 |
| C エネルギー変換 | `C_エネルギー変換_先生用ガイド.html` | 統一版（C1〜C7）の配り方、単元での順番、提出物と記録の管理 |
| D 情報 | `D_情報の技術_先生用ガイド.html` | 統一版（D1〜D10）の配り方、学習指導要領との対応、記録の提出 |
| D 情報 | `D4_情報セキュリティ体験ラボ_先生用ガイド.html` | D4 情報セキュリティ体験ラボのくわしいガイド（モジュール・集計・問題の差し替え） |
| 4分野共通 | `全分野_基本編と発展編.html` | 4分野の統一版の「基本編」「発展編」に入るタブ・ページの一覧（学習指導要領の項目・分けた理由つき）。印刷できます |
| 4分野共通 | `全分野_振り返り一覧.html` | 生徒が書き出した JSON をまとめて読み込み、振り返り・自己評価・提出状況を一覧にする（CSV 保存）。使い方は [`teacher-tools/furikaeri-ichiran/README.md`](../teacher-tools/furikaeri-ichiran/README.md) |

## Classroom で配るときの注意

1. `生徒に配る/` のファイルを Classroom の課題・資料に添付します。
2. 生徒は **端末にダウンロードしてから** ダブルクリックで開きます。
   Google ドライブの画面（プレビュー）の中では動きません。
3. 学習の記録は、その端末のブラウザの中だけに保存されます。毎回同じ場所のファイルを開くと続きから使えます。
4. 提出は、各教材の「書き出す」でできたファイルを Classroom に出させます。

### 生徒用ファイルの中にある「先生用」ボタンについて

先生用の機能（提出の集計など）は、別のファイルではなく**生徒用ファイルの中**に入っています。
先生も生徒と**同じファイルを開いて**、次の場所から使います（生徒の画面ではふだん閉じています）。
どの分野も、メニューの上のバーの右に **「先生用」** ボタンがあり、押すとその分野の先生用のところへ移ります。メニューの下の部分は、どの分野も「基本編・発展編 → 記録(書き出し・データの管理) → 先生用」の順です。

| 分野 | 場所 | できること |
|---|---|---|
| A | 上のバーの「先生用」(メニューのいちばん下の「先生用」が開く) | 提出ファイル一覧ビューア（生徒が出したファイルをまとめて一覧にする・CSV 保存） |
| B | 上のバーの「先生用」(メニューの下の「👩‍🏫 先生用」が開く) | 先生用ガイド、記録のまとめ書き出し・削除 |
| C | 上のバーの「🧑‍🏫 先生用」 | 使い方ページの先生用のタブ(全アプリの記録の書き出し・読みこみ・表示の設定) |
| D | 上のバーの「先生用」(メニューのいちばん下の「先生用」へ移る) | 学習指導要領との対応、記録のまとめ方 |
| D（D4 セキュリティ） | アドレスの最後に `#/teacher` を付けて開く | クラスの記録の集計、使うモジュールの設定、問題の差し替え |

## 教材を直したあと

各分野のビルドで `dist/` を作り直したあと、次を実行するとこのフォルダが新しくなります。

```
python3 クラスルーム配布/まとめる.py
```

元のファイルは各分野の `dist/`（配布用）と `docs/`（先生用の文書）、`teacher-tools/` にあります。くわしくは `まとめる.py` に書いてあります（A は `A-materials/build/build-single.py` で1ファイルにしてから写します）。
