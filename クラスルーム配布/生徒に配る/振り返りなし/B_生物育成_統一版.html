📖 この教材集きょうざいしゅうの使い方

「生物育成せいぶついくせいの技術ぎじゅつ」を学ぶための、4つのデジタル教材です。インターネットにつながっていなくても使えます。

1. 4つの教材でできること

教材やることこんなときに使う
B1 育成環境いくせいかんきょうコントローラ体験コンピュータの中で作物を30日育て、温度・光・水・肥料ひりょうを調節ちょうせつする環境と成長の関係を、ためしながら知りたいとき
B2 動物飼育しいく・水産すいさんミニシミュレータメダカ・金魚・ニワトリ・ウズラ・ウサギを30日育て、様子から状態を読み取る動物や魚を育てる技術を学ぶとき
B3 栽培暦さいばいごよみビルダー収穫しゅうかくしたい日から逆算ぎゃくさんして、作業の予定(カレンダー)をつくる育てはじめる前の計画づくり
B4 育成日誌いくせいにっし＋成長予測せいちょうよそく本物の作物や生き物の記録きろく(気温・水やり・草丈くさたけ・写真)をつけ、グラフや予測で成長を読み取る学校で実際に育てているあいだ、ずっと

💡 おすすめの順番は、番号の順(B1 → B2 → B3 → B4)です。① B1・B2 で育成いくせい環境かんきょうの調節ちょうせつを知る → ② B3 で計画けいかくを立てる → ③ B4 で育てながら記録きろくする → ④ 振ふり返かえりを書いて出す。メニューの「基本編」の上にも「おすすめの順番」が出ています。先生の指示しじがあれば、そちらにしたがおう。

2. ひらき方・もどり方

  1. メニューの教材カードの「ひらく ▶」をタップします。
  2. 教材の中では、上の緑のタブで画面を切りかえます。
    B1・B2・B3 は「① そだてる」「② 結果・原因さがし」のように、学ぶ中身のタブに番号がついていて、番号の順に進みます(「はじめに」と「振り返り」には番号がありません。振り返りはいつも最後です)。基本編のタブのあとに発展編のタブがならんでいます。
    B4 は「🏠ホーム」「✏️記録」「📈グラフ」などの絵のタブで、育てているあいだ、必要な画面を行き来します。
  3. メニューにもどるときは、いちばん上の「◀ メニュー」をタップします。
    書いている途中とちゅうの内容は消えません。
  4. 上のバーの「B1」〜「B4」で、ほかの教材へすぐ移れます。
  5. 上のバーの右の「ふりがな」でふりがなのあり・なし、「文字 中」で文字の大きさ(押すたびに 小 → 中 → 大 → 特大)を変えられます。文字の大きさ・ふりがなは、教材集ぜんぶで同じ設定になります。

3. それぞれの教材の進め方

B1 育成環境コントローラ体験

  1. はじめに:作物・場所・季節・天気の番号をえらぶ(番号は先生の指示どおりに)。
  2. ①そだてる:毎日の操作をえらんで「次の日へ」。30日育てる。
  3. ②結果・原因さがし:グラフとヒントから原因を考え、もう一度ちょうせん。
  4. ③くらべる(発展):条件を1つだけ変えて2つの環境を比べる。
  5. 振り返りを書く。

B2 動物飼育・水産ミニシミュレータ

  1. はじめに:育てる生き物をえらぶ。
  2. ①飼育シミュレーション:温度・えさ・水替みずかえなどを決めて「1日すすめる」。
  3. ②診断しんだんクイズ:生き物の様子から原因と対策を考える。
  4. ③飼育計画書:えさやり・水替え・観察・衛生えいせいの計画を立てる。
  5. 振り返りを書く。

B3 栽培暦ビルダー

  1. ①作物をえらぶ。
  2. ②計画をつくる:収穫したい日・地域・休業日を入れる。
  3. ③カレンダーで作業日をたしかめる。
  4. ④記録と評価:作業が終わったらチェックし、計画とのずれを書く。
  5. 振り返りを書く。

B4 育成日誌＋成長予測

  1. はじめに名前(または班の名前)を登録とうろくする。
  2. 🗓️計画:育てる生物・種まき日・場所・育成環境の調節方法を決める。
  3. ✏️記録:観察した日ごとに、天気・気温・水やり・草丈・写真を記録する。
  4. 📈グラフ・📷写真で成長の変化を読み取る。こまったら🩺診断。
  5. 📝評価を書く。
  6. 🔮予測(発展):これからの成長を予測する。
  7. 💭振り返りを書く。

4. 振り返りの書き方と出し方

どの教材にも、さいごに「振り返り」のタブがあります。授業の終わりに書きましょう。

  • 組・番号・名前をわすれずに書く。
  • 「よかった」だけでなく、数字やグラフ(例:「水やりを1日おきにしたら草丈が12cmから18cmになった」)を使って書く。
  • うまくいかなかったこと → 原因 → 次の改善の順で書くと、考えたことが伝わります。
  • 自己評価(◎ よくできた/○ できた/△ もう少し)もえらぶ。
  • 書いた文章は自動で保存されます。「最後に保存 ○:○○」と出ていればだいじょうぶ。
  • 書いた内容はタブレットに保存されます。提出ていしゅつは、先生の指示にしたがって「テキストで書き出す」「コピー」「印刷・PDF」のどれかを使います。

メニューのカードには、振り返りの書きぐあいが「✅ 書いた」(全部の問いに書いた)「📝 書きかけ」(とちゅう)「✏️ まだ」で表示されます。

5. 保存についての大切な約束

  • 記録はこのタブレットの、このブラウザの中に保存されます。ほかのタブレットには入っていません。
  • いつも同じタブレット・同じ方法でこのファイルをひらこう。
  • シークレットモード(プライベートブラウズ)では保存されません。
  • ブラウザの「閲覧履歴えつらんりれき・データを消す」をすると、記録も消えます。
  • メニューの上に「✅ このタブレットに保存できます」と出ていればだいじょうぶ。「⚠️」が出ていたら先生に知らせよう。

6. こまったときは

画面が動かない・おかしい
「◀ メニュー」にもどってから、もう一度教材をひらく。それでもだめなら、ページを再読さいよみこみする(記録は消えません)。
文字が小さい・ふりがなを消したい
いちばん上のバーの「文字 中」で文字の大きさ、「ふりがな」でふりがなのあり・なしを変えられます。どの教材を開いているときでも使えます。文字の大きさ・ふりがなは、教材集ぜんぶで同じ設定になります。
前に書いた記録がない
ちがうタブレット、またはちがうブラウザでひらいていないか確かめよう。B4は、登録した名前をえらび直してみよう。
まちがえて消してしまった
すぐに先生に相談しよう。バックアップがあれば、もとにもどせることがあります。

1. 配り方と開き方

配り方

  1. B_生物育成_統一版.html を各端末に配布します(Google ドライブ・Classroom・USB など)。zip で配るときは、展開(すべて展開)した中の 生物育成教材集.html が同じファイルです(元のファイル名は B-bio/dist/生物育成教材集.html)。
  2. 生徒は端末に保存したファイルをブラウザで開きます。以後はオフラインで動きます。
  3. 初回に、メニュー上部が「✅ このタブレットに保存できます」になっていることを確認してください。

振り返りを隠すとき

振り返りを Google フォームなど別の方法で集めるときは、教材の中の振り返り(振り返りのタブ・欄、メニューのカードの「振り返り」の印など)を出さないようにできます。

  • 生徒用サイトで使うとき: アドレスの最後に ?furikaeri=off を付けて開くよう、生徒に知らせてください(例: https://okarin-netizen.github.io/Edu-IT/?furikaeri=off)。一度開くと、その端末で覚えています。?furikaeri=on を付けて開くと元にもどります。

3. 単元での使い方

単元での使い方の例

  1. 導入・知識(B1・B2): 育成環境と成長の関係をシミュレーションで体験する。B1 の「はじめに」で選ぶ「天気の番号」をクラスで同じにすると、全員同じ条件で比較・発表ができます。
  2. 計画(B3): 育てる作物を決め、収穫日から逆算して作業日を決める。学校の休業日を入れておきます。
  3. 育成・記録(B4): 実際の栽培中、観察のたびに記録する。B3 の計画を参考に、B4 の計画にも同じ作物と開始日を入れます。
  4. 評価・改善(B3・B4): 計画と実際のずれ(B3 の「④ 記録と評価」)、予測と実際の違い(B4 の「予測」)から改善案を考える。
  5. まとめ: 各教材の振り返りを提出させる。

教材の番号は、この順(おすすめの順番)と同じです。生徒のメニューでは、基本編の上に「おすすめの順番: B1 → B2 → B3 → B4」の1行が出て、カードもこの順にならびます。生徒用の「使い方」のページも同じ順で説明しています。

コスト(お金と手間)

B1 は操作ごとの費用と作業時間を集計し(「② 結果・原因さがし」)、「③ くらべる」で A・B の費用も比べます。B2 はえさ・水替え・そうじ・温度などの世話の回数や量に応じて、えさ代・電気代・治療費と世話の時間を毎日計算し、結果でお手本の世話と比べます(世話を減らして弱らせると治療費がかかる仕組み)。B3 は計画の下書きに、種苗費・肥料代・資材費と作業時間、収穫の価値の目安を出します。金額はすべて学習用のおおよその目安です。

生き物が死んでしまう場合

B2 では、健康度が20未満の「とても弱った状態」が続くと、数が少しずつ減り(死んだ分はふやせません)、健康度が0になるか1匹だけで弱った状態が3日続くと死んでしまい、飼育はそこで終わります。結果画面に「命を落とすことにつながったおもな原因」が出るので、グラフ・日誌と合わせて振り返らせてください。最初の設定のまま何も見直さないと、金魚は12日目ごろに死んでしまいます。

命を扱う内容なので、事前に声かけをお願いします。

シミュレーション(B1・B2)は簡易モデルです。本物の作物や生き物の観察・記録(B4)と比べて考えるよう声をかけてください。

4. 記録の保存と提出

保存

  • 記録は端末のブラウザ内(localStorage、B4 の写真は IndexedDB)に保存され、外部には送信されません。保存名は教材ごとに b1_〜b4_ で始まり(B1 b1_*、B2 b2_*、B3 b3_state_v1・b3_reflection_v1、B4 b4_store・写真 b4_photos)、互いに上書きしません。
  • 第1.4版で教材の番号を付け直したため(前の B2→B1、B3→B2、B4→B3、B1→B4)、前の版で保存した記録や書き出したファイルは読みこめません。
  • 同じ端末でも、別のブラウザ・シークレットモード・別のファイルの場所から開くと記録は引き継がれません。
  • 端末を複数の生徒で使う場合、B4 は「名前(班名)」ごとに記録を分けられます。B1〜B3 は端末につき1人分なので、班で1台にするか、使い終わったら下の「すべて消す」を使ってください。
  • ふりがな・文字の大きさは、4教材とメニューで共通の設定です(保存名 hub_ruby・hub_fs)。上のバーの「ふりがな」と「文字 中」(押すたびに 小 → 中 → 大 → 特大)で変えると、開いているすべての教材にすぐ反映されます。「すべて消す」をしても、この2つの設定は残ります。

振り返りの回収

  • どの教材にも「振り返り」タブがあり、先頭に組・番号・名前、記述の問い、自己評価(◎ よくできた/○ できた/△ もう少し)があります。本文は自動保存され、「最後に保存 hh:mm」が出ます(B4 で以前に付けた★は ◎○△ に変換されます)。
  • 提出方法は「テキストで書き出す(.txt)」「コピー(Classroom の回答欄に貼る)」「印刷・PDF」から指示してください。
  • メニューのカードに、振り返りの書きぐあい(✅ 書いた=記述欄すべて記入 / 📝 書きかけ / ✏️ まだ)が出るので、机間指導で確認できます。
  • 印刷・PDF では、記述欄の文章は枠で切れずに全文が出ます(例文は印刷されません。空欄は「(未記入)」)。

提出されたファイルを見る

4分野共通の 全分野_振り返り一覧.html に、B2「すべてのデータを書き出す」(B2_データ_日付.json)・B3 のバックアップ(B3_バックアップ_日付.json)・B4「すべて書き出す」(B4_育成日誌_名前_日時.json)のファイル(JSON)を読み込むと、ほかの分野と同じように振り返りと自己評価を一覧にできます(B1 の振り返りは .txt なので読み込めません)。

評価

観点別評価との対応の目安: 自己評価や問いのうち「関係を理解できた」→知識・技能、「原因を考え改善できた」→思考・判断・表現、「すすんで試した・生活や社会に生かそうとした」→主体的に学習に取り組む態度。

まとめて書き出す・消す

メニューの下の「💾 記録(書き出し・データの管理)」から、4教材の記録をまとめて書き出し(バックアップ)・読み込み・削除できます。「すべて消す」は、共用の端末を次の人に渡すときに使います。

B4 の写真はまとめた書き出しに入らないため、B4 の「❓使い方」タブの「すべて書き出す(写真つき)」を使ってください。

5. 授業で使うときの注意

安全・倫理への配慮

  • B2 は、生き物の命を軽く扱わないよう淡い表現にしています。実際の飼育・観察とつなげて扱ってください。
  • 飼育した生き物を川や池に放さない(外来種・生態系への配慮)、農薬は使用基準を守る、について B2・B4 の中でも注意を表示しています。
  • 教科書の図や文章は転載していません。数値は授業用の目安です。

実機で確認してほしいこと(授業前に1台で)

  • テキストやバックアップを書き出したとき、ファイル名が日本語のまま保存されるか(テスト用ブラウザでは「download」という名前になることがありました)。
  • メニューの中で開いた教材で、「コピー」ボタンが使えるか(Classroom などに貼りつけられるか)。
  • B4 の写真で、カメラの起動・写真の選択ができるか。

6. こまったとき

「⚠️ 保存できません」と出る
シークレットモード、または保存を許可しない開き方です。通常のブラウザでファイルを開き直してください。
記録が消えた
別のブラウザ・別の場所のファイルで開いていないか確認してください。ブラウザのデータ削除や端末の初期化でも消えるため、学期の区切りでバックアップを取ることをすすめます。
書き出したファイルが見つからない
端末の「ダウンロード」フォルダに保存されます。
印刷すると教材全体が出る
振り返りタブの「印刷」ボタンを使うと、振り返りだけが印刷されます。
